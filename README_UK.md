# Fast Media Sorter for Windows

Fast Media Sorter for Windows (раніше FastMediaSorter LITE - у Microsoft Store і winget застосунок публікується під колишньою назвою) - це застосунок Windows Forms для швидкого сортування, перегляду та керування файлами зображень і відео. Бо папка з 4000 фотографій сама себе не розбере. Підтримує широкий спектр медіа-форматів та надає наступні можливості:

- Швидка навігація по великих папках із зображеннями та відео (навіть по непристойно великих)
- Режими слайд-шоу та випадкового перегляду файлів
- Відстеження нещодавніх файлів та папок, щоб не пригадувати, де ви спинилися
- Операції з файлами: переміщення, копіювання, перейменування та видалення
- Панель отримувачів поверх медіа: плаваючий список каталогів, призначених на гарячі клавіші - клік по рядку переміщує/копіює поточний файл туди (або видаляє), щоб сортувати однією рукою мишею (за замовчуванням вимкнено; вмикається в налаштуваннях)
- Панель зображень для швидкої візуальної навігації
- Автоматичний поворот фото за тегом EXIF Orientation - на випадок, якщо камеру тримали боком
- Якісне (бікубічне) масштабування - чіткіше при зменшенні великих зображень
- Необов'язковий напис поверх зображення: ім'я файлу та позиція (зручно в повноекранному режимі)
- Налаштовуваний інтервал слайдшоу
- Реєстрація застосунку переглядачем зображень та/або відеоплеєром за замовчуванням (для поточного користувача, без танців з правами адміністратора)
- Android Folder Share: перетворіть цей ПК на SFTP-сервер для власних папок з медіа та файлами й відкривайте їх з Android-застосунку - у домашній мережі або через інтернет, підключення за QR-кодом (вбудований копілот для мобільної версії)
- OCR і переклад тексту поверх зображення (локальні Ollama / LibreTranslate) - для картинок, що вперто говорять чужою мовою
- Налаштовані гарячі клавіші - тягнутися до миші вже немодно
- Багатомовна підтримка (англійська/російська; при першому запуску береться мова інтерфейсу Windows)
- Широка підтримка відеоформатів: усе (H.264/MP4, AVI, ZMBV, VP9, MKV, WMV, ..)
  відтворюється просто у вікні через вбудований рушій **LibVLC** - без зовнішніх
  кодеків, без полювання на плагіни й без залежності від того, чи є ще в системі
  Internet Explorer

## Мобільна версія 📱

Хочете сортувати медіа, не встаючи з дивана? Спробуйте **FastMediaSorter v2** - потужний Android-додаток з підтримкою локальних файлів, мережевих дисків (SMB, SFTP, FTP) та хмарних сховищ (Google Drive, OneDrive, Dropbox):

🔗 **[Сайт FastMediaSorter для Android](https://serzhyale.github.io/FastMediaSorter_mob_v2/index-uk.html)** · **[GitHub](https://github.com/SerZhyAle/FastMediaSorter_mob_v2)**

Встановити: **[Google Play](https://play.google.com/store/apps/details?id=com.sza.fastmediasorter)**, **[IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.sza.fastmediasorter)** або прямий **[APK зі сторінки релізів GitHub](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/releases)**.

Можливості включають:
- Єдиний інтерфейс для всіх джерел файлів (локальні, мережеві, хмарні)
- Вбудований медіа-плеєр та читалка EPUB
- Редагування зображень (поворот, віддзеркалення, фільтри, налаштування)
- Автоматичний переклад з підтримкою OCR
- Система обраного та PIN-захист
- Просунуті жести та навігація з клавіатури

**Десктоп як копілот:** Fast Media Sorter for Windows може виступати сервером для мобільного застосунку. Його функція **Android Folder Share** піднімає вбудований SFTP-сервер для ваших власних папок з медіа та файлами, і Android-застосунок звертається до цього ПК напряму - у домашній мережі або через інтернет - після одноразового підключення за QR-кодом. Спільним доступом керує окрема програма в треї - **Fast Media Sorter: Share Manager** (відкривається правим кліком по папці в переглядачі або з розділу Налаштування &rarr; Файли та система). Спільний доступ вмикається явно: увімкніть **функції сервера** (галочкою під час встановлення або кнопкою в Share Manager), щоб додати правило брандмауера Windows - до того застосунок працює лише як переглядач/сортувальник. Дивіться покроковий [посібник з публікації папок для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html).

## Використання

1. Виберіть папку з вашими медіа-файлами (так, саме ту).
2. Переміщайтесь по файлах за допомогою клавіатури, миші або екранних кнопок - як зручніше рукам.
3. Використовуйте панель та нещодавні файли для швидкого доступу.
4. Переміщуйте, копіюйте або видаляйте файли за потреби. Натиснули цифру - хаосу поменшало.
5. Насолоджуйтесь швидким та ефективним сортуванням медіа і, можливо, нарешті поверніть собі місце на диску.

## Дві програми, один застосунок

У пакеті їдуть **дві програми перегляду поруч, в одній папці**, і інсталятор ставить
обидві. Вибирати не потрібно: ярлик і файлові асоціації автоматично вказують на ту,
яка на вашій машині справді запуститься.

- **`FastMediaSorter_LITE.exe`** - основна програма, тепер 64-бітна, на .NET 10.
  Вона замінює попередню на місці й зберігає всі ваші налаштування. **Встановлювати
  нічого не треба** - рантайм .NET лежить усередині самої програми, тож колишнього
  рядка «потрібен .NET Framework 4.8» для неї більше немає. Потрібна Windows 10
  версії 1607 або новіша, Windows 11 чи Windows Server 2016+.
- **`FastMediaSorter_x86.exe`** - той самий переглядач у вигляді невеликої 32-бітної
  програми (~3 МБ) для Windows 7/8.1 та 32-бітних Windows, де сучасний рантайм
  просто не запрацює. Їй потрібен .NET Framework 4.8 - на тих версіях Windows він
  або вже є, або штатно довстановлюється. Це не урізана версія: OCR, переклад і
  роздача тек у ній теж є.

Це **один застосунок**, а не два конкуренти: одні налаштування, одне вікно. Запуск
однієї програми за відкритої другої просто винесе вже відкрите вікно вперед разом з
вашим файлом - жодного другого вікна й суперечки про те, чиї налаштування
збережуться. Суміжні бібліотеки (кодеки, моделі OCR та перекладу, роздача тек) у них
теж спільні - кожна сама бере ті, що пасують її розрядності.

### Що лагодить 64-бітна програма

- **Анімований WEBP тепер відкривається скрізь.** Програма декодує WEBP сама, а не
  покладається на кодек Windows «WebP Image Extensions», якого немає в серверних
  редакціях Windows - там анімований WEBP раніше просто не відкривався.
- **Відео завжди грає через вбудований рушій VLC.** Відправлений на спокій компонент
  Internet Explorer більше не використовується, тому відтворення однаково працює й
  там, де IE вже немає. (32-бітна програма зберігає класичний шлях.)

## Вимоги

Коротко: інсталятор розбирається з цим за вас (див. вище). Докладно:

| | `FastMediaSorter_LITE.exe` (основна, 64 біти) | `FastMediaSorter_x86.exe` (32 біти) |
|---|---|---|
| **Windows** | 10 версії 1607+, 11, Server 2016+ | 7, 8.1, 10, 11 - включно з 32-бітними |
| **Рантайм** | не потрібен - він усередині програми | .NET Framework 4.8 |

## Встановлення

### winget

```powershell
winget install --id SerZhyAle.FastMediaSorter
```

Пакет winget використовує Inno Setup installer у тихому per-user режимі, тому
під час встановлення не показує діалогів - просто мовчки робить свою справу.

### Реліз з GitHub

Завантажте актуальні файли зі
[сторінки релізів](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases):

- `FastMediaSorter-<version>-windows-x64-setup.exe` для найпростішого встановлення
- `FastMediaSorter-<version>-windows-x64.zip` як portable offline-пакет

Обидва файли містять **обидві програми** - імена файлів при цьому не змінилися.

У звичайному інтерактивному setup можна одразу зареєструвати програму для
поширених форматів зображень. На Windows 10/11 система може ще раз
попросити підтвердити вибір у розділі типових програм.

Обидва GitHub-релізи offline-ready: усередині вже є VLC runtime і OCR мовні
пакети, тому для відтворення медіа та OCR не потрібне перше дозавантаження з
мережі.

### Що входить у пакет (і чому він великий)

Основна програма - це один exe на ~110 МБ, бо несе всередині власний рантайм .NET.
Саме через цю вагу й не треба нічого встановлювати: рантайм їде разом із програмою,
а не вимагається від вашої машини. (32-бітна програма поруч важить ~3 МБ.) Майже
весь інший обсяг - це опційна **офлайн-начинка**, вкладена в пакет, щоб застосунок
працював без дозавантаження під час першого запуску:

- **Відео-кодеки (VLC)** (~100 МБ) - офлайн-відтворення AVI, MKV, VP9 та інших
  форматів, які вбудований програвач Windows розкодувати не може.
- **Моделі OCR та перекладу** (~45 МБ) - розпізнавання тексту на зображенні без
  звернення до мережі.
- **Компаньйон Android Folder Share** (~120 МБ) - self-contained застосунок на .NET,
  що містить власний рантайм (Windows не постачає потрібний йому сучасний .NET),
  для роздачі тек на телефон.

У пакет вкладені 64-бітні бібліотеки - для основної програми. 32-бітна програма
довантажує потрібні їй частини під час першого використання.

Інтерактивний інсталятор показує все це **вибірковими компонентами** з їхнім
розміром: зніміть непотрібне - і ці частини або завантажаться пізніше за потреби,
або функція просто не встановлюється. Встановлення «лише переглядач» («Компактна») -
лише частка повного пакета. (Тиха установка / winget завжди беруть повний набір.)

Примітка: машинний переклад усе ще залежить від вибраного провайдера - програма
щедра, але перекладати силою думки не вміє. Для Ollama потрібне окреме локальне
встановлення моделі, а хмарним сервісам потрібен доступ до мережі.
