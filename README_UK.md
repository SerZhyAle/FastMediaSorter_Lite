# FastMediaSorter LITE

FastMediaSorter LITE - це застосунок Windows Forms для швидкого сортування, перегляду та керування файлами зображень і відео. Підтримує широкий спектр медіа-форматів та надає наступні можливості:

- Швидка навігація по великих папках із зображеннями та відео
- Режими слайд-шоу та випадкового перегляду файлів
- Відстеження нещодавніх файлів та папок
- Операції з файлами: переміщення, копіювання, перейменування та видалення
- Панель зображень для швидкої візуальної навігації
- Налаштовані гарячі клавіші для ефективної роботи
- Багатомовна підтримка (англійська/російська)
- Широка підтримка відеоформатів: звичайний H.264/MP4 відтворюється просто у вікні,
  а все, що вбудований плеєр не може декодувати (AVI, ZMBV, VP9, MKV, WMV, …),
  автоматично відтворюється через вбудований рушій **LibVLC** — без зовнішніх
  кодеків і плеєрів

## Використання

1. Виберіть папку з вашими медіа-файлами.
2. Переміщайтесь по файлах за допомогою клавіатури, миші або екранних кнопок.
3. Використовуйте панель та нещодавні файли для швидкого доступу.
4. Переміщуйте, копіюйте або видаляйте файли за потреби.
5. Насолоджуйтесь швидким та ефективним сортуванням медіа!
