# FastMediaSorter LITE

FastMediaSorter LITE - це застосунок Windows Forms для швидкого сортування, перегляду та керування файлами зображень і відео. Бо папка з 4000 фотографій сама себе не розбере. Підтримує широкий спектр медіа-форматів та надає наступні можливості:

- Швидка навігація по великих папках із зображеннями та відео (навіть по непристойно великих)
- Режими слайд-шоу та випадкового перегляду файлів
- Відстеження нещодавніх файлів та папок, щоб не пригадувати, де ви спинилися
- Операції з файлами: переміщення, копіювання, перейменування та видалення
- Панель зображень для швидкої візуальної навігації
- Автоматичний поворот фото за тегом EXIF Orientation - на випадок, якщо камеру тримали боком
- Якісне (бікубічне) масштабування - чіткіше при зменшенні великих зображень
- Необов'язковий напис поверх зображення: ім'я файлу та позиція (зручно в повноекранному режимі)
- Налаштовуваний інтервал слайдшоу
- Реєстрація застосунку переглядачем зображень та/або відеоплеєром за замовчуванням (для поточного користувача, без танців з правами адміністратора)
- OCR і переклад тексту поверх зображення (локальні Ollama / LibreTranslate) - для картинок, що вперто говорять чужою мовою
- Налаштовані гарячі клавіші - тягнутися до миші вже немодно
- Багатомовна підтримка (англійська/російська; при першому запуску береться мова інтерфейсу Windows)
- Широка підтримка відеоформатів: звичайний H.264/MP4 відтворюється просто у вікні,
  а все, що вбудований плеєр не може декодувати (AVI, ZMBV, VP9, MKV, WMV, ..),
  автоматично відтворюється через вбудований рушій **LibVLC** - без зовнішніх
  кодеків і полювання на плагіни

## Використання

1. Виберіть папку з вашими медіа-файлами (так, саме ту).
2. Переміщайтесь по файлах за допомогою клавіатури, миші або екранних кнопок - як зручніше рукам.
3. Використовуйте панель та нещодавні файли для швидкого доступу.
4. Переміщуйте, копіюйте або видаляйте файли за потреби. Натиснули цифру - хаосу поменшало.
5. Насолоджуйтесь швидким та ефективним сортуванням медіа і, можливо, нарешті поверніть собі місце на диску.

## Встановлення

### winget

```powershell
winget install --id SerZhyAle.FastMediaSorter
```

Пакет winget використовує Inno Setup installer у тихому per-user режимі, тому
під час встановлення не показує діалогів - просто мовчки робить свою справу.

### Реліз з GitHub

Завантажте актуальні файли зі
[сторінки релізів](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases):

- `FastMediaSorter-<version>-windows-x64-setup.exe` для найпростішого встановлення
- `FastMediaSorter-<version>-windows-x64.zip` як portable offline-пакет

У звичайному інтерактивному setup можна одразу зареєструвати FastMediaSorter
LITE для поширених форматів зображень. На Windows 10/11 система може ще раз
попросити підтвердити вибір у розділі типових програм.

Обидва GitHub-релізи offline-ready: усередині вже є VLC runtime і OCR мовні
пакети, тому для відтворення медіа та OCR не потрібне перше дозавантаження з
мережі.

Примітка: машинний переклад усе ще залежить від вибраного провайдера - програма
щедра, але перекладати силою думки не вміє. Для Ollama потрібне окреме локальне
встановлення моделі, а хмарним сервісам потрібен доступ до мережі.
