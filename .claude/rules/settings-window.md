# Settings window (Table_Form) and Send-logs

> Area rules for the paths above (auto-loaded). Index and the always-on rules: CLAUDE.md.

**[Table_Form.vb](../../src/Table_Form.vb)** - **Settings window** ("Настройки" / "Settings"). **Two shells over the same five Designer pages**, and the count differs between them: the net48 fallback shows `Tab_Page_1..5` as five plain tabs, while the modern build rebuilds the window in [Table_Form.ModernLayout.vb](../../src/Table_Form.ModernLayout.vb) as a **sidebar-nav layout of eleven pages** - those same five plus six that exist only there (`General`, `Audio`, `Translation`, `Storage`, `About`, `Server and resources`, built by `BuildExtraModernSettingsPages`; `Resources` (ticket 118) embeds the same [Resource_List_Panel.vb](../../src/Resource_List_Panel.vb) the manager dialog hosts, and the window reports `ResourcesTouched`/`SettingsRemovedResourceIds` so `Main_Form.ApplyResourceChanges` can react after it closes).
- [Table_Form.SettingsGroups.vb](../../src/Table_Form.SettingsGroups.vb) assigns rows to independent collapsible groups and restores page/group/viewport context through stable ids; a moved row keeps its default and storage key.
- The modern shell creates page flows and placement metadata first. [Table_Form.LazyPages.vb](../../src/Table_Form.LazyPages.vb) builds each page's groups and editors on its first `Selecting`, including Resources, Storage and About; OCR controls are created only for OCR, Translation or Storage. Register a new editor factory with its existing group key, and wire its accessibility/summary handlers through `WireSettingsRows`. Search explicitly materializes unvisited pages without selecting them. Designer controls stay owned in the parked-control list until reparented or disposed; the net48 shell remains eager.
- No Share tab in either shell (Android Folder Share is the Companion app); only the `btn_Share_Manager` launcher ([Table_Form.ShareLauncher.vb](../../src/Table_Form.ShareLauncher.vb)) survives - on "Files and system" in net48, reparented onto the modern "Server and resources" page.
- Shared pages: the destination `Data_Grid_View` (DEL + 0..9) is sized to exactly its 11 rows, never stretched; `chb_perspectiva` > `chk_Dynamic_Perspective` > `chk_Animated_Perspective` are each greyed by the one above (the last two hidden on net48); the audio defaults are private fields of `Main_Form`, read via `CurrentVideoMuted`/`CurrentVideoVolumePercent`, written via `SetVideoAudioState`; `AdvanceAfterCopy` is modern-only.
- **About** (modern shell only) hosts **"Отправить логи автору"** ([Table_Form.SendLogs.vb](../../src/Table_Form.SendLogs.vb) + [src/Support/LogPackage.vb](../../src/Support/LogPackage.vb), whole-file `#If Not NETFRAMEWORK`; spec `SPECIFICATION_SEND_LOGS_TO_AUTHOR.md`): `current.log`, `companion.log`, their rolled-over `previous.log` / `companion.previous.log`, a generated `report.txt` and a machine-readable `environment.txt` go into a `%TEMP%` ZIP, a consent dialog lists what is in it, and the file is handed to the mail client via **Simple MAPI** ([src/Support/MailSender.vb](../../src/Support/MailSender.vb), linked into Companion; `mailto:` cannot carry an attachment). The author's address is the single literal `MailSender.AuthorAddress`.
  - **The app never opens a network connection for this** - that keeps the "no telemetry" claim on the privacy page true. No MAPI client: clipboard + `explorer /select` + a plain `mailto:`; no mail handler at all (`MailSender.HasMailHandler`): no blind `mailto:`, the archive path is printed.
  - The `[settings]` block is an **allow-list** (`SafeSettingNames` in `LogPackage.vb`), never a hive dump: only listed names go out with values, `RecentFolders`/`RecentMediaFiles` become counts, `MoveOn*` says only set/empty, `Share_RootParams` (per-share PINs + host paths) is never emitted in any form, everything else is one "N other values not sent" line - so a **new setting is withheld until it is added to the list on purpose**. Secrets (`*ApiKey`/`*Password`/`*Token`) show only `<hidden>`; the user-profile prefix becomes `<USER>` in `report.txt` and the log copies, **before** a log is cut (`CompactRedacted`, `DIAGNOSTIC-REPORT` 0.12 item C): a log over the 2 MB ceiling keeps its first 256 KB and its tail with a `[Diag] LOG TRUNCATED | ..` line between, and a source over 64 MB is omitted with `[Diag] LOG OMITTED | ..`. The archive is `fms-logs-<version>-yyyyMMdd-HHmmss.zip`; `previous.log` is looked for beside the log it rolled from (both programs use that name), never in another program's folder.
  - Also linked into the Share Manager (`Forms/SendLogsFlow.vb`), which packs the same archive: its sources are "the running program's own log, then the sibling's".
  - Sources (ticket 182): `LogPackage.PlanLogSources` is the pure source list (`exchange/*`, `share/*` beside `current.log` and `companion.log`): the first candidate that can be *opened* decides, never `File.Exists`; an unreadable source is named in the consent list and in `report.txt`'s `[log sources]`, never dropped. The `[hosting]` block (pure `src/Support/HostingReport.vb`, read-only probes injected through `HostingProbesLive.vb`) carries ports as numbers and socket scopes, never an address, login, hash, fingerprint or profile path. `HostingReport.BuildLiveStateLine` stays bounded. `publishing/installer/collect-host-state.ps1` is the read-only offline collector of the same kind of ZIP (never `exchange.json`, `tls\`, stores or tokens) and ships only behind the exchange gate (`#ifndef NoExchange`).
- **OCR и перевод / OCR & translation** (`Tab_Page_5`, built in code in [Table_Form.Ocr.vb](../../src/Table_Form.Ocr.vb)): unlike the rest of the form it builds once (`_ocrBuilt`) and edits the **live** `OcrTranslateSettings` via `Main_Form.EnsureOcrSettings()`/`OnOcrSettingsEditedFromSettingsWindow()`; `_ocrLoading` suppresses handler side-effects during populate; entering the tab clears the result cache (`Main_Form.ClearOcrResultCache()`).
- **Keys**: `KeyPreview` forwards only the paging keys in `IsForwardedToViewer` (arrows, PageUp/Down, Home/End) to `Main_Form.KeybUse`; **Escape is the window's own** and closes the settings window only (not while a grid cell is being edited or a drop-down is open). Never widen that list with a destructive key - D/Delete/X/Q/the slot digits once reached the viewer from here (`SettingsKeyForwardingTests`).
- Option toggles write straight to the `Common_Module` flags; the two that change painting (`chk_Hq_Scaling`, `chk_Show_Info_Overlay`) call `Main_Form.RepaintMedia()`.
- **A page switch and a group toggle hold one layout pass** (WINDOWS-UI section 5, amended 0.2). The group holds its own layout and its page's while it changes and raises `ExpansionChanged` after the pass; the page is sized in `ResizeModernPageItems` with the page and its group bodies suspended and released once, the shown page only (`LayoutModernSettingsPage`, never the all-pages `LayoutModernSettingsPages()` from a switch, a toggle, expand all or a content resize); anchors and scroll position are read after that layout. A `SuspendLayout` has its `ResumeLayout` in the same method; a change of many rows goes through `HoldSettingsPages`. Held by `SettingsLayoutPassTests` and, against another build, `tests/Integration/SettingsLayoutScenes`.
