Step by stepПошаговоПокроково

  1. In FastMediaSorter, click Share on the toolbar (or press Shift+S, or right-click the folder box). You can also open Settings (F2) → Share. В FastMediaSorter нажмите Поделиться на панели (или клавиши Shift+S, или правый клик по строке каталога). Также можно открыть Настройки (F2) → Поделиться. У FastMediaSorter натисніть Поділитися на панелі (або клавіші Shift+S, або правий клік по рядку каталогу). Також можна відкрити Налаштування (F2) → Поділитися.
  2. Add the folders to share (the current folder is offered first). Tick the ones you want visible on the phone. Добавьте папки для общего доступа (текущая предлагается первой). Отметьте галочками те, что должны быть видны на телефоне. Додайте папки для спільного доступу (поточна пропонується першою). Позначте галочками ті, що мають бути видимі на телефоні.
  3. Press Start sharing. FastMediaSorter shows the PC's address, a QR code and a Save .fmscfg button. Нажмите Начать общий доступ. FastMediaSorter покажет адрес ПК, QR-код и кнопку Сохранить .fmscfg. Натисніть Почати спільний доступ. FastMediaSorter покаже адресу ПК, QR-код і кнопку Зберегти .fmscfg.
  4. On the phone, open FastMediaSorter → Add resource → SFTP/FTP → Import from companion, then scan the QR code (or open the saved .fmscfg file). На телефоне откройте FastMediaSorter → Добавить ресурс → SFTP/FTP → Импорт из компаньона, затем отсканируйте QR-код (или откройте сохранённый файл .fmscfg). На телефоні відкрийте FastMediaSorter → Додати ресурс → SFTP/FTP → Імпорт із компаньйона, потім відскануйте QR-код (або відкрийте збережений файл .fmscfg).
  5. Done - the shared folders open on the phone. Sharing keeps running even after you close FastMediaSorter. Готово - общие папки открываются на телефоне. Доступ продолжает работать, даже когда FastMediaSorter закрыт. Готово - спільні папки відкриваються на телефоні. Доступ працює далі, навіть коли FastMediaSorter закрито.

Local network vs internetЛокальная сеть или интернетЛокальна мережа чи інтернет

🏠 Local networkЛокальная сетьЛокальна мережа

When the phone is on the same Wi-Fi as the PC, it just works - nothing to configure. This is the default and the most private option. Когда телефон в той же Wi-Fi, что и ПК, всё работает сразу - настраивать нечего. Это вариант по умолчанию и самый приватный. Коли телефон у тій самій Wi-Fi, що й ПК, усе працює одразу - налаштовувати нічого. Це варіант за замовчуванням і найприватніший.

🌍 InternetИнтернетІнтернет

To reach the folders when away from home, turn on Open internet access. FastMediaSorter tries to open the port automatically (UPnP); if your router does not allow that, forward one port manually. Чтобы попасть к папкам вне дома, включите Открыть доступ из интернета. FastMediaSorter попробует открыть порт автоматически (UPnP); если роутер не разрешает - пробросьте один порт вручную. Щоб потрапити до папок поза домом, увімкніть Відкрити доступ з інтернету. FastMediaSorter спробує відкрити порт автоматично (UPnP); якщо роутер не дозволяє - пробросьте один порт вручну.

Keep it safeБезопасностьБезпека

  • The QR code and the .fmscfg file contain the auto-generated password. Treat them as secrets - do not post them publicly. QR-код и файл .fmscfg содержат автоматически созданный пароль. Считайте их секретом - не публикуйте. QR-код і файл .fmscfg містять автоматично створений пароль. Вважайте їх секретом - не публікуйте.
  • Turn off internet access when you no longer need it. Выключайте доступ из интернета, когда он больше не нужен. Вимикайте доступ з інтернету, коли він більше не потрібен.
  • The connection is encrypted and the phone pins your PC's key on first use - a later "key changed" warning is meaningful. Соединение шифруется, а телефон запоминает ключ вашего ПК при первом подключении - позднее предупреждение "ключ изменился" важно. З'єднання шифрується, а телефон запам'ятовує ключ вашого ПК під час першого підключення - пізніше попередження "ключ змінився" важливе.

If the phone can't connectЕсли телефон не подключаетсяЯкщо телефон не підключається

  • Same network? The LAN path only works when the phone is on the same Wi-Fi as the PC. Одна сеть? Локальный путь работает только когда телефон в той же Wi-Fi, что и ПК. Одна мережа? Локальний шлях працює лише коли телефон у тій самій Wi-Fi, що й ПК.
  • Firewall: allow FastMediaSorter through the Windows Defender Firewall prompt the first time. Брандмауэр: при первом запуске разрешите FastMediaSorter в окне брандмауэра Windows. Брандмауер: під час першого запуску дозвольте FastMediaSorter у вікні брандмауера Windows.
  • CGNAT: some providers share one public address between many customers - port forwarding cannot help; use the local network, or ask for a public "white" IP. CGNAT: некоторые провайдеры делят один публичный адрес между многими - проброс портов не поможет; пользуйтесь локальной сетью или попросите публичный "белый" IP. CGNAT: деякі провайдери ділять одну публічну адресу між багатьма - проброс портів не допоможе; користуйтеся локальною мережею або попросіть публічну "білу" IP.
  • IP changed: home IPs rotate - reopen the share window to see the current address, or set up Dynamic DNS on the router. IP сменился: домашние адреса меняются - откройте окно общего доступа снова, чтобы увидеть текущий адрес, или настройте Dynamic DNS на роутере. IP змінився: домашні адреси змінюються - відкрийте вікно спільного доступу знову, щоб побачити поточну адресу, або налаштуйте Dynamic DNS на роутері.
