How to publish your folders for Android

Share folders from this PC with the FastMediaSorter app on your Android phone - over your home network, or over the internet. No cloud, no accounts: the phone connects straight to your PC over an encrypted SFTP connection. Sharing is handled by the companion Share Manager app that ships alongside the viewer. It is installed with the Full install type (the Compact type does not carry it) and works with the 64-bit viewer (FastMediaSorter_LITE.exe) on Windows 10 version 1607 or newer; the 32-bit viewer for Windows 7/8.1 does not offer it.

Windows PC + Android phone Same Wi-Fi = instant Writable by default; Read-only is a choice
Need the phone app? The Android app is a free viewer/sorter that imports these shares.

#Before you start

  • One administrator approval, one firewall rule. The first time, Enable server features.. asks Windows for administrator rights once (a UAC prompt) and adds a Windows Firewall rule for the sharing program only. You can tick this during installation instead. Until it is done nothing is shared. To take it back: Manager settings.. - Network - «Switch off server features..».
  • The internet path. When sharing starts, unless Local network only (no internet access) is ticked (Manager settings.. - Network; it is off by default), Share Manager asks the router to open the port (UPnP/NAT-PMP) and checks, through the external service check-host.net, whether that port is visible from the internet. Tick it to keep everything inside your local network.
  • What the phone may do. While sharing is on, the folders you ticked can be read over the network, and by default the phone can also add, rename and delete files in them. To make a folder browse-only, choose the real lock («Not writable at the server level») under Edit.
  • The QR code and the .fmscfg file are a key. They contain the auto-generated password (and the PIN, if one is set) - do not post them publicly. In the Share - access code window you can tick Keep the password out of the file/QR and pass it separately; whether the phone accepts a code without a password depends on the Android app version. Send by email.. warns the recipient in the message and leaves no copy of the file on the PC; a saved .fmscfg is readable by your Windows account only.
  • Stop when you are done. Press Stop sharing or quit Share Manager from the tray. The connection is encrypted and the phone pins your PC's key on first use - a later "key changed" warning is meaningful.

#Step by step

  1. In Fast Media Sorter & Sharing for Windows, right-click the folder box and choose Share this folder with Android.., or open Settings (F2) → Server and resources → Android / SFTP and press Manage SFTP. Either one opens the Share Manager companion app.
  2. The first time, Share Manager says Server features are off: press Enable server features.. and approve the administrator prompt (see Before you start). Until then nothing is shared; the viewer itself stays an ordinary local program.
  3. Share Manager opens with your folder already added and sharing started - the Android access panel shows the PC's address. Add more folders with Add folder.. and tick only the ones to show on the phone; use Edit to set a real read-only lock, a PIN, allowed media types, a destination for copies, and more.
  4. Press the big Share button. The Share - access code window shows a QR code and the buttons Show QR code, Save .fmscfg file.., Send by email.. and Copy login/password. (When you started from the folder right-click, this window opens for you automatically.)
  5. On the phone, open FastMediaSorter → Add resource → SFTP/FTP → Import from companion, then scan the QR code (or open the saved .fmscfg file).
  6. Done - the shared folders open on the phone. Sharing keeps running from the tray even after you close the viewer; closing the Share Manager window just hides it to the tray while a share is active.

#Local network vs internet

There is one QR code / one .fmscfg that carries every way to reach your PC - local Wi-Fi, IPv6 and the internet address. The phone tries them all and connects over whichever is reachable, preferring the fast local one. One scan works both at home and away - you no longer choose a "network" up front.

Local network

When the phone is on the same Wi-Fi as the PC, it just works - nothing to configure. This is the default and the most private option.

Internet

When sharing starts, Share Manager tries to open the port automatically (UPnP/NAT-PMP) and then checks from the outside whether it really answers (through check-host.net). Both are skipped when Local network only (no internet access) is ticked. The Via internet line shows the address honestly - or tells you it's behind CGNAT. If the port isn't open, use How to set up internet access for a per-router port-forward guide and Test internet access to verify. If your PC has IPv6, that address is added too and works even behind CGNAT.

Per-model, step-by-step port-forwarding guides: portforward.com (opens in a new tab).

Finds your PC automatically

On the same Wi-Fi the phone also discovers the PC by its host-key fingerprint. So even if the PC's local address changed since you scanned the code (a new lease, a reconnect), the phone reconnects on its own - no need to re-scan.

#If the phone can't connect

  • Same network? The LAN path only works when the phone is on the same Wi-Fi as the PC.
  • Is sharing running? The start/stop button should say Stop sharing. Reopen Share Manager to check the displayed address and status.
  • Firewall: the SFTP port must be allowed through Windows Firewall. The rule is added by Enable server features.. (or the installer checkbox) - see Before you start.
  • CGNAT: some providers share one public address between many customers - port forwarding cannot help. Use the local network, the IPv6 address (if both sides have IPv6), a VPN, or ask for a public "white" IP.
  • IP changed: home IPs rotate. On the same Wi-Fi the phone re-finds the PC by itself; from the internet, reopen Share Manager to see the current address, or set up Dynamic DNS on the router.

Where sharing settings live

Settings are in two windows. Manager settings holds the SFTP sharing group - the SFTP port, LAN-only policy and Hosting page, shown while that component is installed - beside general preferences, remote-account access, publishing and schedules. The installed local exchange server has its own settings window. The link at the lower left opens the other window without closing the current one. Opening settings starts no server. Earlier builds showed SFTP sharing in a window of its own.
