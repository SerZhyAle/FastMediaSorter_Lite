How to publish your folders for Android Как публиковать свои папки для Android Як публікувати свої папки для Android

Share folders from this PC with the FastMediaSorter app on your Android phone - over your home network, or over the internet. No cloud, no accounts: the phone connects straight to your PC over an encrypted SFTP connection. Sharing is handled by the companion Share Manager app that ships alongside the viewer. It is a 64-bit program, so folder sharing needs the 64-bit viewer (FastMediaSorter_LITE.exe) on Windows 10 version 1607 or newer; the 32-bit viewer for Windows 7/8.1 does not offer it. Делитесь папками этого ПК с приложением FastMediaSorter на телефоне Android - по домашней сети или через интернет. Без облака и аккаунтов: телефон подключается прямо к вашему ПК по зашифрованному соединению SFTP. Раздачей занимается отдельная программа Share Manager, которая идёт вместе с просмотрщиком. Она 64-битная, поэтому раздача папок работает с 64-битным просмотрщиком (FastMediaSorter_LITE.exe) на Windows 10 версии 1607 и новее; в 32-битном просмотрщике для Windows 7/8.1 её нет. Діліться папками цього ПК з застосунком FastMediaSorter на телефоні Android - домашньою мережею або через інтернет. Без хмари й акаунтів: телефон підключається прямо до вашого ПК зашифрованим з'єднанням SFTP. Роздачею опікується окрема програма Share Manager, що йде разом із переглядачем. Вона 64-бітна, тож роздача тек працює з 64-бітним переглядачем (FastMediaSorter_LITE.exe) на Windows 10 версії 1607 і новіше; у 32-бітному переглядачі для Windows 7/8.1 її немає.

#Step by stepПошаговоПокроково

  1. In Fast Media Sorter & Sharing for Windows, right-click the folder box and choose Share this folder with phone.. (or open Settings (F2) → Files and system and click Manage the SFTP server for the Android client..). Either one opens the Share Manager companion app. The first time, click Enable server features.. - it needs administrator rights once and adds a Windows Firewall rule (you can also tick this during installation). Until then the app is just a viewer/sorter. В Fast Media Sorter & Sharing for Windows щёлкните правой кнопкой по строке каталога и выберите Поделиться этой папкой с телефоном.. (или откройте Настройки (F2) → Файлы и система и нажмите Управление SFTP-сервером для андроид-клиента..). Любой из способов открывает отдельную программу Share Manager. В первый раз нажмите Включить функции сервера.. - нужны права администратора один раз, добавляется правило брандмауэра Windows (это же можно включить галочкой во время установки). До этого программа работает только как просмотрщик/сортировщик. У Fast Media Sorter & Sharing for Windows клацніть правою кнопкою по рядку каталогу й виберіть Поділитися цією папкою з телефоном.. (або відкрийте Налаштування (F2) → Файли та система і натисніть Керування SFTP-сервером для андроїд-клієнта..). Будь-який зі способів відкриває окрему програму Share Manager. Уперше натисніть Увімкнути функції сервера.. - потрібні права адміністратора один раз, додається правило брандмауера Windows (це ж можна ввімкнути галочкою під час встановлення). До того застосунок працює лише як переглядач/сортувальник.
  2. Share Manager opens with your folder already added and sharing started - the Android access panel shows the PC's address. Add more folders with Add folder.. and tick the ones to show on the phone; use Edit to set read-only, a PIN, allowed media types, a destination for copies, and more. Share Manager откроется с уже добавленной папкой, и раздача запустится - на панели Доступ с Android будет виден адрес ПК. Добавляйте другие папки кнопкой Добавить папку.. и отмечайте галочками те, что должны быть видны на телефоне; кнопка Редактировать задаёт "только чтение", PIN, разрешённые типы медиа, папку-приёмник для копий и другое. Share Manager відкриється з уже доданою папкою, і роздача запуститься - на панелі Доступ з Android буде видно адресу ПК. Додавайте інші папки кнопкою Додати папку.. і позначайте галочками ті, що мають бути видимі на телефоні; кнопка Редагувати задає "лише читання", PIN, дозволені типи медіа, папку-приймач для копій тощо.
  3. Press the big Share button. The access code window shows a QR code and the buttons Show QR code, Save .fmscfg file.., Send by email.. and Copy login/password. (When you started from the folder right-click, this window opens for you automatically.) Нажмите большую кнопку Поделиться. В окне кода доступа появятся QR-код и кнопки Показать QR-код, Сохранить файл .fmscfg.., Отправить по почте.. и Скопировать логин/пароль. (Если вы начали с правого клика по папке, это окно откроется само.) Натисніть велику кнопку Поділитися. У вікні коду доступу з'являться QR-код і кнопки Показати QR-код, Зберегти файл .fmscfg.., Надіслати поштою.. та Скопіювати логін/пароль. (Якщо ви почали з правого кліку по папці, це вікно відкриється саме.)
  4. On the phone, open FastMediaSorter → Add resource → SFTP/FTP → Import from companion, then scan the QR code (or open the saved .fmscfg file). На телефоне откройте FastMediaSorter → Добавить ресурс → SFTP/FTP → Импорт из компаньона, затем отсканируйте QR-код (или откройте сохранённый файл .fmscfg). На телефоні відкрийте FastMediaSorter → Додати ресурс → SFTP/FTP → Імпорт із компаньйона, потім відскануйте QR-код (або відкрийте збережений файл .fmscfg).
  5. Done - the shared folders open on the phone. Sharing keeps running from the tray even after you close the viewer; closing the Share Manager window just hides it to the tray while a share is active. Готово - общие папки открываются на телефоне. Раздача продолжает работать из трея, даже когда просмотрщик закрыт; закрытие окна Share Manager просто сворачивает его в трей, пока идёт раздача. Готово - спільні папки відкриваються на телефоні. Роздача працює далі з трея, навіть коли переглядач закрито; закриття вікна Share Manager просто згортає його в трей, поки триває роздача.

#Local network vs internetЛокальная сеть или интернетЛокальна мережа чи інтернет

There is one QR code / one .fmscfg that carries every way to reach your PC - local Wi-Fi, IPv6 and the internet address. The phone tries them all and connects over whichever is reachable, preferring the fast local one. One scan works both at home and away - you no longer choose a "network" up front. Один QR-код / один файл .fmscfg содержит все способы связаться с ПК: локальную Wi-Fi, IPv6 и адрес из интернета. Телефон пробует их все и подключается по тому, что доступен, предпочитая быстрый локальный. Одно сканирование работает и дома, и вне дома - выбирать "сеть" заранее больше не нужно. Один QR-код / один файл .fmscfg містить усі способи зв'язатися з ПК: локальну Wi-Fi, IPv6 та адресу з інтернету. Телефон пробує їх усі й підключається тим, що доступний, віддаючи перевагу швидкому локальному. Одне сканування працює і вдома, і поза домом - обирати "мережу" заздалегідь більше не потрібно.

Local networkЛокальная сетьЛокальна мережа

When the phone is on the same Wi-Fi as the PC, it just works - nothing to configure. This is the default and the most private option. Когда телефон в той же Wi-Fi, что и ПК, всё работает сразу - настраивать нечего. Это вариант по умолчанию и самый приватный. Коли телефон у тій самій Wi-Fi, що й ПК, усе працює одразу - налаштовувати нічого. Це варіант за замовчуванням і найприватніший.

InternetИнтернетІнтернет

When sharing starts, Share Manager tries to open the port automatically (UPnP) and then checks from the outside whether it really answers. The Via internet line shows the address honestly - or tells you it's behind CGNAT. If the port isn't open, use How to set up internet access for a per-router port-forward guide and Test internet access to verify. If your PC has IPv6, that address is added too and works even behind CGNAT. Когда раздача запускается, Share Manager пробует открыть порт автоматически (UPnP), а затем проверяет снаружи, действительно ли он отвечает. Строка Через интернет честно показывает адрес - или сообщает, что вы за CGNAT. Если порт не открыт, откройте Как настроить доступ через интернет - инструкцию проброса порта под ваш роутер, и Проверить доступ из интернета для проверки. Если у ПК есть IPv6, его адрес добавляется тоже и работает даже за CGNAT. Коли роздача запускається, Share Manager пробує відкрити порт автоматично (UPnP), а потім перевіряє ззовні, чи він справді відповідає. Рядок Через інтернет чесно показує адресу - або повідомляє, що ви за CGNAT. Якщо порт не відкрито, відкрийте Як налаштувати доступ через інтернет - інструкцію проброса порту під ваш роутер, і Перевірити доступ з інтернету для перевірки. Якщо ПК має IPv6, його адресу додано теж, і вона працює навіть за CGNAT.

Finds your PC automaticallyНаходит ваш ПК самЗнаходить ваш ПК сам

On the same Wi-Fi the phone also discovers the PC by its host-key fingerprint. So even if the PC's local address changed since you scanned the code (a new lease, a reconnect), the phone reconnects on its own - no need to re-scan. В той же Wi-Fi телефон дополнительно находит ПК по отпечатку его ключа. Поэтому даже если локальный адрес ПК изменился после сканирования кода (новая аренда, переподключение), телефон переподключится сам - пересканировать не нужно. У тій самій Wi-Fi телефон додатково знаходить ПК за відбитком його ключа. Тож навіть якщо локальна адреса ПК змінилася після сканування коду (нова оренда, перепідключення), телефон перепідключиться сам - пересканувати не потрібно.

#Keep it safeБезопасностьБезпека

  • The QR code and the .fmscfg file contain the auto-generated password. Treat them as secrets - do not post them publicly. (You can tick Do not include the password in the file/QR and pass it separately; whether the phone accepts a code without a password depends on the Android app version.) Send by email.. warns the recipient in the message and leaves no copy of the file on the PC; a saved .fmscfg is readable by your Windows account only. QR-код и файл .fmscfg содержат автоматически созданный пароль. Считайте их секретом - не публикуйте. (Можно поставить галочку Не включать пароль в файл/QR и передать его отдельно; примет ли телефон код без пароля, зависит от версии Android-приложения.) Отправить по почте.. предупреждает получателя в письме и не оставляет копию файла на компьютере; сохранённый .fmscfg доступен только вашей учётной записи Windows. QR-код і файл .fmscfg містять автоматично створений пароль. Вважайте їх секретом - не публікуйте. (Можна поставити галочку Не включати пароль у файл/QR і передати його окремо; чи прийме телефон код без пароля, залежить від версії Android-застосунку.) Надіслати поштою.. попереджає одержувача в листі й не залишає копії файлу на комп'ютері; збережений .fmscfg доступний лише вашому обліковому запису Windows.
  • Stop sharing when you no longer need it - press Stop sharing or quit Share Manager from the tray. Останавливайте раздачу, когда она больше не нужна - нажмите Остановить раздачу или выйдите из Share Manager через трей. Зупиняйте роздачу, коли вона більше не потрібна - натисніть Зупинити роздачу або вийдіть із Share Manager через трей.
  • The connection is encrypted and the phone pins your PC's key on first use - a later "key changed" warning is meaningful. Соединение шифруется, а телефон запоминает ключ вашего ПК при первом подключении - позднее предупреждение "ключ изменился" важно. З'єднання шифрується, а телефон запам'ятовує ключ вашого ПК під час першого підключення - пізніше попередження "ключ змінився" важливе.

#If the phone can't connectЕсли телефон не подключаетсяЯкщо телефон не підключається

  • Same network? The LAN path only works when the phone is on the same Wi-Fi as the PC. Одна сеть? Локальный путь работает только когда телефон в той же Wi-Fi, что и ПК. Одна мережа? Локальний шлях працює лише коли телефон у тій самій Wi-Fi, що й ПК.
  • Firewall: the SFTP port must be allowed through Windows Firewall. Enabling server features - the installer checkbox, or the one-time Enable server features button in Share Manager - adds that rule for you. Брандмауэр: порт SFTP должен быть разрешён в брандмауэре Windows. Включение функций сервера - галочкой в установщике или кнопкой Включить функции сервера в Share Manager - добавляет это правило автоматически. Брандмауер: порт SFTP має бути дозволений у брандмауері Windows. Увімкнення функцій сервера - галочкою в інсталяторі або кнопкою Увімкнути функції сервера у Share Manager - додає це правило автоматично.
  • CGNAT: some providers share one public address between many customers - port forwarding cannot help. Use the local network, the IPv6 address (if both sides have IPv6), a VPN/relay, or ask for a public "white" IP. CGNAT: некоторые провайдеры делят один публичный адрес между многими - проброс портов не поможет. Пользуйтесь локальной сетью, адресом IPv6 (если он есть с обеих сторон), VPN/ретранслятором или попросите публичный "белый" IP. CGNAT: деякі провайдери ділять одну публічну адресу між багатьма - проброс портів не допоможе. Користуйтеся локальною мережею, адресою IPv6 (якщо вона є з обох боків), VPN/ретранслятором або попросіть публічну "білу" IP.
  • IP changed: home IPs rotate. On the same Wi-Fi the phone re-finds the PC by itself; from the internet, reopen Share Manager to see the current address, or set up Dynamic DNS on the router. IP сменился: домашние адреса меняются. В той же Wi-Fi телефон находит ПК сам; из интернета - откройте Share Manager снова, чтобы увидеть текущий адрес, или настройте Dynamic DNS на роутере. IP змінився: домашні адреси змінюються. У тій самій Wi-Fi телефон знаходить ПК сам; з інтернету - відкрийте Share Manager знову, щоб побачити поточну адресу, або налаштуйте Dynamic DNS на роутері.
