ALWAYS-ON · FOLDER SHARE SERVER

Keep your folders reachable from your phone, even when nobody is signed inПапки доступны с телефона, даже когда в систему никто не вошёл

The Server edition installs a Windows service that publishes the folders you choose over SFTP. It starts with Windows, survives logoff, and restarts itself if it ever fails. Same SFTP, same QR pairing, same Android app - only the host is different.Серверная редакция ставит службу Windows, которая раздаёт выбранные вами папки по SFTP. Она стартует вместе с Windows, переживает выход из системы и перезапускается сама при сбое. Тот же SFTP, та же привязка по QR, то же приложение Android - отличается только хост.

Do you actually need this?Нужна ли она вам?

Install the Server edition only when the machine's job is to stay available: a dedicated server, a VPS, a NAS-like Windows box, an always-on home server. On an ordinary PC the regular installer already shares folders while you are signed in, needs no administrator rights, and is the better choice.Ставьте серверную редакцию только если задача машины - быть доступной постоянно: выделенный сервер, VPS, «NAS-подобная» Windows-коробка, домашний сервер. На обычном ПК обычный установщик уже раздаёт папки, пока вы в системе, не требует прав администратора и подходит лучше.

InstallУстановка

Download FastMediaSorter-<version>-windows-x64-server-setup.exe from the latest release and run it as administrator. Each release ships a .sha256 sidecar next to the installer - verify it before running:Скачайте FastMediaSorter-<версия>-windows-x64-server-setup.exe из последнего релиза и запустите от имени администратора. К каждому релизу прилагается файл .sha256 - проверьте его перед запуском:

Get-FileHash .\FastMediaSorter-<version>-windows-x64-server-setup.exe -Algorithm SHA256

Or install it with winget:Либо установите через winget:

winget install --id SerZhyAle.FastMediaSorter.Server
winget upgrade --id SerZhyAle.FastMediaSorter.Server
winget uninstall --id SerZhyAle.FastMediaSorter.Server

Requirements: Windows 10 version 1607 or newer, Windows 11, or Windows Server 2016 or newer, 64-bit, and administrator rights. The Server package contains the Share Manager and the SFTP worker only - no viewer, no video codecs, no OCR models.Требования: Windows 10 версии 1607 или новее, Windows 11 либо Windows Server 2016 или новее, 64-разрядная, и права администратора. Серверный пакет содержит только Менеджер общего доступа и SFTP-воркер - без просмотрщика, кодеков и моделей OCR.

You may not need this package at allВозможно, этот пакет вам не нужен

If the ordinary version is already installed, open the Share Manager → Manage hosting.. → Switch sharing to a Windows service... One administrator prompt performs the whole move: the settings and the host key go into the machine store, the worker is staged under %ProgramData%\FastMediaSorterCompanion\bin (a service account cannot run an executable out of a user profile), the service is registered and started, and the folders you already share are granted to it. This Server package is the same service installed straight away, for a machine that is set up without ever opening the app. The Microsoft Store build cannot register a Windows service - there, use the installer from this site.Если обычная версия уже установлена, откройте Менеджер общего доступа → Управление хостингом.. → Перевести раздачу в режим службы Windows... Одно подтверждение администратора выполняет весь переход: настройки и ключ узла переезжают в машинное хранилище, воркер размещается в %ProgramData%\FastMediaSorterCompanion\bin (служебная учётная запись не может запускать файл из профиля пользователя), служба регистрируется и стартует, а уже выбранным папкам выдаётся доступ. Серверный пакет - это та же служба, устанавливаемая сразу, для машины, которую настраивают, ни разу не открывая программу. Версия из Microsoft Store регистрировать службы не может - там используйте установщик с этого сайта.

A silent Server install refuses to run when the User edition is present, because it would migrate your state unattended. Pass /MIGRATEFROMUSER=yes to allow it explicitly - the winget package already does.Тихая установка серверной редакции остановится, если найдена пользовательская: она бы перенесла состояние без подтверждения. Передайте /MIGRATEFROMUSER=yes, чтобы разрешить это явно - пакет winget так и делает.

First-time setupПервая настройка

The service never guesses which folders to publish. After installation it is running and sharing nothing until you choose.Служба никогда не угадывает, какие папки публиковать. После установки она запущена, но не раздаёт ничего, пока вы не выберете папки.

Approve the installationПодтвердите установку

Setup asks for administrator rights once. It registers the FastMediaSorterCompanionSFTP service (delayed automatic start, running as LOCAL SERVICE), creates a machine state directory with a restricted ACL, and adds one program-scoped inbound firewall rule for the worker executable.Установщик один раз запросит права администратора. Он регистрирует службу FastMediaSorterCompanionSFTP (отложенный автозапуск, от имени LOCAL SERVICE), создаёт машинное хранилище состояния с ограниченными правами и добавляет одно входящее правило брандмауэра для файла воркера.

Pick the foldersВыберите папки

The Share Manager opens at the end of setup. Add the folders to publish and tick the ones that should be visible on the phone. Use Configure.. for read-only access, a PIN, allowed media types and a destination folder for copies.Менеджер общего доступа откроется в конце установки. Добавьте публикуемые папки и отметьте галочкой те, что должны быть видны на телефоне. Через Настроить.. задайте доступ только для чтения, PIN, разрешённые типы медиа и папку для копий.

Grant the service access to those foldersВыдайте службе доступ к этим папкам

The service runs as LOCAL SERVICE, which is not you - a folder inside your user profile is invisible to it until it is granted read access. In the Share Manager open Manage hosting.. and use Grant the service access to the shared folders. It adds a single read-and-execute entry per folder and records exactly what it added, so removing the server role can take back only that.Служба работает от имени LOCAL SERVICE - это не вы, и папка внутри вашего профиля ей не видна, пока не выдано право на чтение. В Менеджере общего доступа откройте Управление хостингом.. и нажмите Выдать службе доступ к общим папкам. Добавляется одна запись «чтение и выполнение» на папку, и записывается ровно то, что было добавлено - поэтому удаление роли сервера снимет только это.

Pair the phoneПривяжите телефон

Start sharing, then press Share to get the QR code or the .fmscfg file. On the phone: FastMediaSorter → Add resource → SFTP/FTP → Import from companion.Запустите раздачу и нажмите Поделиться, чтобы получить QR-код или файл .fmscfg. На телефоне: FastMediaSorter → Добавить ресурс → SFTP/FTP → Импорт из компаньона.

Verify it really survives a rebootПроверьте, что всё переживает перезагрузку

This is the test that matters, and it is the one most easily skipped. Reboot the machine and do not sign in. From the phone, open the paired resource. If it lists files, the whole chain works. From another PC you can also check the service state:Это главная проверка, и её чаще всего пропускают. Перезагрузите машину и не входите в систему. С телефона откройте привязанный ресурс. Если файлы видны - вся цепочка работает. С другого ПК состояние службы можно проверить так:

sc query FastMediaSorterCompanionSFTP

What the four states meanЧто означают четыре состояния

The Hosting console keeps these apart on purpose, because they fail differently and a phone that cannot connect looks the same in all four:Консоль хостинга намеренно разделяет их: они ломаются по-разному, а телефон, который не подключается, во всех четырёх случаях выглядит одинаково:

  • Service installedСлужба установлена - the registration exists. It may still be stopped.регистрация существует. Служба при этом может быть остановлена.
  • Service runningСлужба работает - the process is alive and answering the control channel.процесс жив и отвечает на канал управления.
  • SFTP servingРаздача SFTP работает - the SFTP listener is up. A running service is not automatically serving.SFTP-слушатель поднят. Работающая служба сама по себе ещё не раздаёт.
  • No folders configuredПапки не выбраны - everything is healthy and there is simply nothing to serve.всё исправно, просто раздавать нечего.

The console also shows which host is answering right now - the Windows service or this program's own background process - and the shared state directory both of them use.Консоль также показывает, кто отвечает прямо сейчас - служба Windows или фоновый процесс самой программы - и общее хранилище состояния, которым пользуются оба.

Switching between editionsПереключение между редакциями

Both directions preserve the host key, so a successful migration keeps the same host-key fingerprint and paired phones do not need re-pairing. If the identity cannot be validated, the migration stops before the service is registered rather than minting a replacement key.В обе стороны ключ узла сохраняется, поэтому успешный перенос сохраняет тот же отпечаток ключа, и привязанные телефоны не нужно привязывать заново. Если ключ не удаётся проверить, перенос останавливается до регистрации службы, а не создаёт новый ключ.

User → ServerПользовательская → серверная

Run the Server installer. It stops the user-session worker, copies and validates the state into the machine store, sets the ACLs and the firewall rule, then registers and starts the service. The viewer stays installed and keeps working.Запустите серверный установщик. Он остановит воркер пользовательского сеанса, скопирует и проверит состояние в машинное хранилище, настроит права и правило брандмауэра, затем зарегистрирует и запустит службу. Просмотрщик остаётся установленным и продолжает работать.

Server → UserСерверная → пользовательская

Share Manager → Manage hosting.. → Return to the User edition.., or uninstall the Server package. The service is stopped and deleted, the folder permissions this product added are taken back, and the state stays where the user-session worker can pick it up.Менеджер общего доступа → Управление хостингом.. → Вернуться к пользовательской редакции.., либо удалите серверный пакет. Служба останавливается и удаляется, выданные этим продуктом права на папки снимаются, а состояние остаётся там, где его подхватит воркер пользовательского сеанса.

Permissions, network and limitsПрава, сеть и ограничения

  • Network paths do not work.Сетевые пути не работают. LOCAL SERVICE presents anonymous credentials on the network, so a \\server\share root cannot be served under it - no permission change on your side can fix that. Use a local path.LOCAL SERVICE выходит в сеть с анонимными учётными данными, поэтому корень вида \\сервер\папка под ней раздать нельзя - никакая настройка прав с вашей стороны это не изменит. Используйте локальный путь.
  • The firewall rule is program-scoped,Правило брандмауэра привязано к программе, not port-scoped - it keeps working when the listen port changes - and it covers the domain, private and public profiles, because a server's network is usually classified Public.а не к порту - оно продолжает работать при смене порта прослушивания - и охватывает профили «домен», «частная» и «общедоступная», поскольку сеть сервера обычно считается общедоступной.
  • Root confinement still applies.Ограничение корнями остаётся в силе. The service account decides what the worker can open; it never lets a phone browse outside the folders you configured.Учётная запись службы определяет, что воркер может открыть; она никогда не позволяет телефону выйти за пределы выбранных вами папок.
  • Access from the internetДоступ из интернета still needs a port forward or a working UPnP, exactly as in the User edition. The Share Manager can test it from outside; if it reports CGNAT, port forwarding cannot help.по-прежнему требует проброса порта или работающего UPnP, ровно как в пользовательской редакции. Менеджер может проверить доступ снаружи; если он сообщает о CGNAT, проброс порта не поможет.

Backup and restoreРезервная копия и восстановление

Everything worth keeping lives in one directory:Всё, что стоит сохранить, лежит в одной папке:

%ProgramData%\FastMediaSorterCompanion\

It holds the host key, the SFTP credential, the folder list, the port and the usage counters. Copy it, as administrator, to restore the same identity onto a rebuilt machine - the phones reconnect without re-pairing. Two rules: keep the backup at least as protected as the original (it contains the private host key and the SFTP password, which is why the directory's permissions are restricted in the first place), and never publish it or paste its contents into a bug report.В ней ключ узла, учётные данные SFTP, список папок, порт и счётчики использования. Скопируйте её от имени администратора, чтобы восстановить ту же личность на пересобранной машине - телефоны подключатся без повторной привязки. Два правила: держите копию защищённой не хуже оригинала (в ней приватный ключ узла и пароль SFTP - именно поэтому у папки ограничены права) и никогда не публикуйте её и не вставляйте содержимое в отчёт об ошибке.

UninstallУдаление

Uninstalling stops and deletes the service before any file is removed, takes back the folder permissions it recorded, and removes the firewall rule - leaving no listening port and no orphaned service registration. The state directory is deliberately kept, because it holds the identity your phones trust. Delete it by hand only if you want every paired phone to pair again.Удаление останавливает и удаляет службу до того, как будет удалён хоть один файл, снимает записанные права на папки и убирает правило брандмауэра - не оставляя ни открытого порта, ни «осиротевшей» регистрации службы. Папка состояния намеренно сохраняется: в ней личность, которой доверяют ваши телефоны. Удаляйте её вручную только если хотите, чтобы все телефоны привязались заново.

If something goes wrongЕсли что-то пошло не так

  • Share Manager → Manage hosting.. has Start, Stop, Restart and Repair the service registration. Repair re-registers the service with the correct command line, account, start type and recovery actions, whatever an older version or a hand edit left behind.В Менеджере общего доступа → Управление хостингом.. есть Запустить, Остановить, Перезапустить и Восстановить регистрацию службы. Восстановление заново регистрирует службу с правильной командной строкой, учётной записью, типом запуска и действиями при сбое - что бы ни оставила прежняя версия или ручная правка.
  • Every elevated action appends to %ProgramData%\FastMediaSorterCompanion\install-share-service.log; the service host writes failures to service.log in the same folder.Каждое действие с правами администратора дописывается в %ProgramData%\FastMediaSorterCompanion\install-share-service.log; хост службы пишет сбои в service.log в той же папке.
  • After a reboot the service may come up before the network is ready. It retries discovery and reachability on its own with a widening delay - no restart needed - so give it a minute before assuming it is broken.После перезагрузки служба может подняться раньше, чем будет готова сеть. Она сама повторяет обнаружение и проверку доступности с нарастающей задержкой - перезапуск не нужен - поэтому подождите минуту, прежде чем считать её сломанной.
