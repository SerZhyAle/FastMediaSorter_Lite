## What this repository holds

1. **The resolver:** `src/Chrome/FormScale.vb` - a pure class (no UI, no registry, no static state) for rules S1-S4: `Px`,
   `PixelFontSize`, `PointFontSize`, `RebasePoints`, `PlatformOnScreenPixels`. Whole-file mainline only, listed in the net48
   project like its neighbours.
2. **The callers:** the Settings window resolves every font for the DPI the control reads it at (rule S4: the control's own
   `DeviceDpi`, `FontBasisDpi` in `Table_Form.ModernLayout.vb`), heals the fonts it carries at every settle point (rule S10:
   `FormScaleRecipeTable.Heal` in `src/Chrome/FormScaleRecipes.vb`, `HealSettingsFonts` / `QueueHealSettingsFonts`) and its
   devices panel keeps the ambient font (rule S7).
3. **The vectors:** `tests/Lite.Tests/TestData/form-scale-vectors/form-scale-vectors.json`, generated by
   `tools/Build-FormScaleVectors.ps1` (the formulas stated apart from the resolver; never hand-edited) and replayed by
   `FormScaleTests`. The catalog's copy is this file byte for byte: a change to the generator is an amendment to write in the
   catalog first.
4. **The probes of the rules' own measurements** (E1-E6): `docs/specifications/done/FMSWIN-0361_form-scale-format/`.
5. **Not claimed:** any other toolkit (WPF, Win32, the .NET Framework 4.8 WinForms of the fallback); that the rules cover
   Android or the web; any other product's conformance.
