## What this repository must do to stay conformant

- A change to the bars or the halo that changes what the user sees - a constant, the easing, the fade
  curve, the durations, the seam - is an **amendment in the catalog first** (a version bump and a log
  row, vectors regenerated by the reference script), then the code. This product owns the contracts, so
  it writes the amendment itself; nobody else's code moves with it.
- The math lives in one tested place citing the rules and runs the catalog vectors - not yet, see
  `specification 056` (local specification).
