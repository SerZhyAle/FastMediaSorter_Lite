## What this repository must do to stay conformant

- A change to the bars or the halo that changes what the user sees - a constant, the easing, the fade
  curve, the durations, the seam - is an **amendment in the catalog first** (a version bump and a log
  row, vectors regenerated by the reference script), then `LetterboxFillMath.vb`, then the vectors
  re-taken into `tests/Lite.Tests/TestData/letterbox-vectors/` with `PROVENANCE.txt` updated. This
  product owns the contracts, so it writes the amendment itself; nobody else's code moves with it.
- **Rung 1 of the contract's section 5 is held (2026-10-13).** Every constant of sections 2-3 lives once
  in `LetterboxFillMath.vb` under a comment citing its rule (the product's old private names are in the
  comments for traceability), and the painting code only calls it: `Main_Form.PerspectiveBackground.vb`
  (axis, fitted rectangle on the x86 branch, sampled colours, spread, uniform or perspective, trimmed
  mean, smoothing, bands and seams; only the one-line `clamp(y, 0, n - 1)` of rules 6 and 7's row
  lookup stays inline in the painters), `Imaging/EdgeSampler.vb` (the edge index and its clamp),
  `Main_Form.PerspectiveHalo.vb` (duration, ease, reach, stop alphas, underlay opacity, clock progress)
  and the two host conditions (the 5000 ms slideshow floor, the 50 ms redraw throttle). The mainline's
  fitted rectangle comes from `ZoomMath.PictureBoxZoomBounds`, which the same test holds to the same
  vectors.
- **What runs.** `LetterboxFillConformanceTests` asserts the vendored file's SHA-256 against
  `PROVENANCE.txt` first, then every group of the vectors: both constant tables; `bars.imageRect` (8,
  axis and rectangle), `edgeIndex` (4), `steppedIndices` (4), `modes` (4, spread, mode and uniform
  colour), `smoothRadius` (7), `smoothed` (1), `bands` (4, bars and seams); `halo.durationsMs` (5),
  `ease` (9), `stops` (12), `stopApproximationMaxError`, `reach` (5), `alphaRows` (5),
  `underlayOpacity` (4) and `frameSchedule` (3). Integers and strings exactly, reals to the contract's
  1e-4 (plus floating-point slack for the vectors' four printed decimals). Beyond the vectors it holds
  the host conditions, the clock progress (the last frame is exactly 1) and a source scan that keeps a
  contract number and the old private arithmetic out of the three painting files.
- **Halo gradient pixels held on 2026-10-16 (183 follow-up).** The viewer and
  `HaloGradientTests` call the same `HaloPainter.PaintFade` GDI+ painter. The test compares every pixel
  against `HaloAlphaRow`, with the contract's maximum 2 levels per RGB channel: both axes and directions,
  lengths 1/2/3/7/19/64/257/1024, growth 0/0.13/0.5/1, black/white/coloured backgrounds, a coloured bar,
  and a nonzero origin. Outside pixels remain untouched. The existing brush needed no sampling correction.
  This closes the gradient uncertainty; full bars/resampling pixel conformance and rung 3 (recorded frames
  of growth at 60 and 144 Hz) remain separate acceptance work, not claimed by this check.
- **Observed on the way, for the catalog (owner's amendment, nothing changed here).** The reference
  script rounds the stop distances to six decimals (`Get-HaloStops`) and then interpolates over the
  rounded table, so `halo.alphaRows` and `stopApproximationMaxError` were computed on stops that are
  not exactly `j/11`. Interpolating over exact `j/11` - which is what the text says and what the
  gradient brush gets - differs from the vector by up to 0.0001 at the vectors' own points (0.00013
  over a 10001-point sweep): on the contract's own 1e-4 tolerance boundary, and invisible after
  integer rounding. Either the reference should interpolate on exact distances or the contract should
  say 2e-4 for those two groups.
- The stored speed reads `medium` when missing, empty or unknown (`HaloAnimationSpeedTests`, and
  `LetterboxFillMath.HaloDurationMs` for the key, held by the vectors).
- The reduced-motion answer of `LETTERBOX-HALO` rule 9 is the same `ReduceMotionActive()` the audio
  backdrop uses: the system's "Animation effects" setting wins, the product's switch may only add
  stillness.
