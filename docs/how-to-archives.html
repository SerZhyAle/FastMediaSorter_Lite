HOW TO · ARCHIVES

Page through a ZIP or a comic book without unpacking it

A scanned book, a downloaded gallery, a CBZ comic: open the archive and the viewer treats it as a folder, so the arrows, the zoom, the slideshow and the translation overlay all work exactly as they do on disk. Archive browsing is part of the 64-bit viewer only (Windows 10 version 1607 or newer).

Open the archive

Drag a .zip, .cbz, .7z, .rar or .cbr file onto the window, open it from Explorer with Open with (the viewer does not make itself the default program for archives), or right-click the folder box and pick "Open archive..". There is no "unpack" step either way - the folder box simply starts showing the archive's own path, and the status line reports how many files it found inside.

Browse it as usual

Only supported pictures and videos become entries; the service records an archiver leaves behind - a Mac's resource forks, Thumbs.db, empty entries - are skipped, and an archive nested inside another one is not offered as a dead end. Very large archives are shown up to twenty thousand entries, and the status line says so when it had to stop there.

Leave it when you are done

Right-click the folder box and pick "Close archive" to go straight back to the folder the archive came from - or point the folder box at any other folder, open another file, or simply close the program. Each entry you actually looked at was written to a temporary directory of its own, and it is removed at that moment; anything an abrupt shutdown left behind is swept away the next time an archive is opened.

Sorting is off inside an archive

The destination-folder keys and Del do nothing here, and the status line says why: the files live inside the archive, and the program does not rewrite it. Look through the archive first, then work on the folder where the pictures really are.

When an archive is refused

A password-protected archive is a job for your archiver - open it there first. A single entry over 512 MB and an archive whose compression ratio looks like a decompression bomb are refused by name rather than silently, as is one that turns out to be damaged. ZIP, CBZ, 7z, RAR and CBR open; a solid archive is unpacked once, with a progress line, and Esc cancels it. A file named like an archive but built as another type (TAR, GZip and the like) is refused with that type named; files with other extensions, such as .tar, are not offered as archives at all.

64-bit program only

Archive browsing ships in the modern 64-bit build for Windows 10 and 11. In the 32-bit fallback an archive is just an unsupported file.

Comics on the phone too

A folder of archives can be published to your Android device over the built-in SFTP service, so the same collection is readable from the sofa.
