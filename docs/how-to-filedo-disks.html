HOW TO · FILEDO DISK SHARING

Share FileDO .fdd virtual disks with your phone

Fast Media Sorter & Sharing for Windows can publish your FileDO .fdd virtual disk containers directly to paired Android devices and SFTP clients. FileDO registers the disk via a local named pipe, and Fast Media Sorter handles container mounting and encrypted SFTP delivery without creating SMB network shares or opening network sockets in FileDO itself. It needs the Share Manager - the Full install type, 64-bit Windows 10 version 1607 or newer - and the optional FileDO virtual disk host component, which no install type ticks for you.

Complete client transparency (DISK-SHARE contract)

To paired phones and SFTP clients, a shared FileDO virtual disk looks exactly like a standard shared folder. No new status text, hidden virtual disk markers, or unique error codes exist for disk roots (rules 25-28). If a disk is closed or locked, it appears to clients identically to an ordinary folder whose path is temporarily unavailable.

Step-by-step setup and sharing

Tick the optional FileDO virtual disk host

When installing Fast Media Sorter & Sharing for Windows, check the optional FileDO virtual disk host. Without it, the worker reports that disk sharing is unavailable, and FileDO's dialog will notify you that disk sharing cannot proceed. The bundled filedo.exe is taken strictly from the latest FileDO GitHub release (GitHub/winget desktop build, never the Microsoft Store MSIX package, which cannot mount containers) and verified with SHA256 (in payload/filedo/filedo.exe, filedo.sha256, and release.json, rules 2-5).

Start Share Manager

Launch Fast Media Sorter & Sharing and open Share Manager - Fast Media Sorter & Sharing from the viewer or tray icon. Fast Media Sorter acts as the host and holder for shared disks, so its worker must be running and ready to answer local named pipe requests before FileDO can register containers. The first time, press Enable server features.. there (it asks for administrator approval once - see the Android guide).

Register a disk from FileDO or Share Manager

In FileDO's Disk Manager, select a registered .fdd container and choose Share with Fast Media Sorter & Sharing.. (Ctrl+Shift+S). Alternatively, open Share Manager → .fdd disks.. → Connect .fdd.. to choose a container directly. Specify the root name seen by phones. Access is read and write unless you tick Read-only; sealed containers are always enforced as read-only.

Observe the single holder rule

Only one holder can control a container at any moment: none, FileDO, FMS Service (Server edition service), or FMS Session (User edition session worker). If the disk is already mounted locally in FileDO, FileDO cleanly disconnects it upon confirmation before handing it to FMS. If a disk is held by FMS, FileDO will refuse local mount attempts and show who holds it.

Autostart and protected encryption keys

The Autostart column in .fdd disks.. shows Yes or No for every disk; - means the worker does not support this setting. The main resource list also marks FileDO rows with autostart enabled. Use Autostart.. to change it; both lists update automatically. Autostart describes the setting, while State shows whether the disk is open, closed or has failed. Select a disk to read any restore error below the table.

Autostart is an explicit opt-in for each disk. For encrypted disks, entering the password enables automatic reopening after reboots without transmitting credentials to phones. The key is encrypted via Windows DPAPI: machine-protected under Server edition (FastMediaSorterCompanionSFTP) or user-protected under User edition. It is never stored in the container, never written to log files, and is destroyed immediately if autostart is toggled off, sharing is stopped, or the container password changes.

Pair your phone over SFTP

Open the Android FastMediaSorter app, select Add resource → SFTP/FTP → Import from companion, and scan the QR code from Share Manager. The open FileDO disk appears alongside standard shared folders, allowing smooth browsing and media playback. Closing the disk keeps its registration for easy one-click reopening later; stopping sharing removes it completely.

Troubleshooting worker states

“FMS is running but disk sharing is unavailable”

Update Fast Media Sorter & Sharing for Windows and ensure the optional FileDO virtual disk host was ticked in setup. Then recheck the disk in FileDO's Disk Manager.

“The FMS worker is unavailable”

Launch Fast Media Sorter & Sharing and open Share Manager. If the program is not installed on this PC, visit the installation page to set it up.

“Worker identity could not be verified”

No credentials were sent across the named pipe. Restart the installed Fast Media Sorter host or service and retry the operation.

“The FMS reply is incomplete or incompatible”

Version mismatch between components. Update both FileDO and Fast Media Sorter & Sharing to their latest releases and retry.

FileDO project and installer trust

Like Fast Media Sorter, the desktop installer for FileDO is unsigned, and Windows SmartScreen may show an unverified publisher dialog on first run. Read FileDO's installation trust guide for details, and visit the main FileDO website. The reciprocal guide from FileDO is published at FileDO FMS Sharing Guide.
