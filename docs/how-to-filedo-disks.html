Share FileDO .fdd virtual disks with your phone Общий доступ к виртуальным дискам FileDO .fdd на телефоне Спільний доступ до віртуальних дисків FileDO .fdd на телефоні

Fast Media Sorter & Sharing for Windows can publish your FileDO .fdd virtual disk containers directly to paired Android devices and SFTP clients. FileDO registers the disk via a local named pipe, and Fast Media Sorter handles container mounting and encrypted SFTP delivery without creating SMB network shares or opening network sockets in FileDO itself. It needs the Share Manager - the Full install type, 64-bit Windows 10 version 1607 or newer - and the optional FileDO virtual disk host component, which no install type ticks for you. Fast Media Sorter & Sharing for Windows умеет открывать ваши виртуальные диски .fdd программы FileDO для сопряжённых Android-устройств и SFTP-клиентов. FileDO регистрирует диск через локальный именованный канал, а Fast Media Sorter берёт на себя монтирование контейнера и безопасную передачу по SFTP без создания общих папок SMB и без открытия сетевых портов в самом FileDO. Нужен Share Manager - тип установки Полная, 64-битная Windows 10 версии 1607 или новее - и необязательный компонент Хост виртуальных дисков FileDO, который не отмечен ни в одном типе установки. Fast Media Sorter & Sharing for Windows уміє відкривати ваші віртуальні диски .fdd програми FileDO для сполучених Android-пристроїв та SFTP-клієнтів. FileDO реєструє диск через локальний іменований канал, а Fast Media Sorter бере на себе монтування контейнера та безпечну передачу через SFTP без створення спільних тек SMB і без відкриття мережевих портів у самому FileDO. Потрібен Share Manager - тип встановлення Повна, 64-бітна Windows 10 версії 1607 або новіша - і необов'язковий компонент Хост віртуальних дисків FileDO, який не позначений в жодному типі встановлення.

Complete client transparency (DISK-SHARE contract)Полная прозрачность для клиентов (контракт DISK-SHARE)Повна прозорість для клієнтів (контракт DISK-SHARE)

To paired phones and SFTP clients, a shared FileDO virtual disk looks exactly like a standard shared folder. No new status text, hidden virtual disk markers, or unique error codes exist for disk roots (rules 25-28). If a disk is closed or locked, it appears to clients identically to an ordinary folder whose path is temporarily unavailable. Для сопряжённых телефонов и SFTP-клиентов общий диск FileDO выглядит точно так же, как обычная общая папка. Для дисковых корней не существует никаких новых статусов, скрытых служебных меток или новых кодов ошибок (правила 25-28). Закрытый или заблокированный диск выглядит для клиента точно так же, как обычная папка, путь к которой временно недоступен. Для сполучених телефонів та SFTP-клієнтів спільний диск FileDO виглядає точнісінько як звичайна спільна тека. Для дискових коренів не існує жодних нових статусів, прихованих службових позначок чи нових кодів помилок (правила 25-28). Закритий або заблокований диск виглядає для клієнта точно так само, як звичайна тека, шлях до якої тимчасово недоступний.

Tick the optional FileDO virtual disk hostОтметьте дополнительный компонент «Хост виртуальных дисков FileDO»Позначте додатковий компонент «Хост віртуальних дисків FileDO»

When installing Fast Media Sorter & Sharing for Windows, check the optional FileDO virtual disk host. Without it, the worker reports that disk sharing is unavailable, and FileDO's dialog will notify you that disk sharing cannot proceed. The bundled filedo.exe is taken strictly from the latest FileDO GitHub release (GitHub/winget desktop build, never the Microsoft Store MSIX package, which cannot mount containers) and verified with SHA256 (in payload/filedo/filedo.exe, filedo.sha256, and release.json, rules 2-5). При установке Fast Media Sorter & Sharing for Windows отметьте дополнительный компонент Хост виртуальных дисков FileDO. Без него воркер сообщает, что поддержка дисков выключена, и диалог FileDO покажет предупреждение «шаринг дисков недоступен». Встроенный filedo.exe берётся строго из последнего релиза FileDO на GitHub (настольная сборка GitHub/winget, ни в коем случае не пакет Microsoft Store MSIX, который не умеет монтировать контейнеры) и проверяется по SHA256 (файлы payload/filedo/filedo.exe, filedo.sha256 и release.json, правила 2-5). Під час встановлення Fast Media Sorter & Sharing for Windows позначте додатковий компонент Хост віртуальних дисків FileDO. Без нього воркер повідомляє, що підтримка дисків вимкнена, і діалог FileDO попередить, що «спільний доступ до дисків недоступний». Вбудований filedo.exe береться суворо з останнього релізу FileDO на GitHub (настільна збірка GitHub/winget, у жодному разі не пакет Microsoft Store MSIX, який не вміє монтувати контейнери) і перевіряється за SHA256 (файли payload/filedo/filedo.exe, filedo.sha256 та release.json, правила 2-5).

Start Share ManagerЗапустите Share ManagerЗапустіть Share Manager

Launch Fast Media Sorter & Sharing and open Share Manager - Fast Media Sorter & Sharing from the viewer or tray icon. Fast Media Sorter acts as the host and holder for shared disks, so its worker must be running and ready to answer local named pipe requests before FileDO can register containers. The first time, press Enable server features.. there (it asks for administrator approval once - see the Android guide). Запустите Fast Media Sorter & Sharing и откройте Share Manager (Менеджер общего доступа) из просмотрщика или значка в трее. Fast Media Sorter выступает хостом и владельцем общих дисков, поэтому его воркер должен работать и отвечать по локальному именованному каналу, прежде чем FileDO сможет зарегистрировать контейнер. В первый раз нажмите там Включить функции сервера.. (один раз потребуется подтверждение администратора - см. инструкцию для Android). Запустіть Fast Media Sorter & Sharing та відкрийте Share Manager (Менеджер спільного доступу) з переглядача або піктограми в треї. Fast Media Sorter виступає хостом і власником спільних дисків, тому його воркер повинен працювати й відповідати через локальний іменований канал, перш ніж FileDO зможе зареєструвати контейнер. Уперше натисніть там Увімкнути функції сервера.. (один раз знадобиться підтвердження адміністратора - див. посібник для Android).

Register a disk from FileDO or Share ManagerЗарегистрируйте диск в FileDO или Share ManagerЗареєструйте диск у FileDO або Share Manager

In FileDO's Disk Manager, select a registered .fdd container and choose Share with Fast Media Sorter & Sharing.. (Ctrl+Shift+S). Alternatively, open Share Manager → .fdd disks.. → Connect .fdd.. to choose a container directly. Specify the root name seen by phones. Access is read and write unless you tick Read-only; sealed containers are always enforced as read-only. В Диспетчере дисков FileDO выберите зарегистрированный контейнер .fdd и нажмите «Поделиться через Fast Media Sorter & Sharing..» (Ctrl+Shift+S). Либо откройте Share Manager → Диски .fdd.. → Подключить .fdd.., чтобы выбрать контейнер напрямую. Задайте имя корня, которое увидят телефоны. Доступ - чтение и запись, пока вы не отметите Только чтение; sealed-контейнеры всегда строго только чтение. У Диспетчері дисків FileDO виберіть зареєстрований контейнер .fdd і натисніть «Поділитися через Fast Media Sorter & Sharing..» (Ctrl+Shift+S). Або відкрийте Share Manager → Диски .fdd.. → Підключити .fdd.., щоб вибрати контейнер безпосередньо. Вкажіть назву кореня, яку побачать телефони. Доступ - читання та запис, доки ви не позначите Лише читання; sealed-контейнери завжди суворо лише для читання.

Observe the single holder ruleПравило одного владельца (Holder)Правило одного власника (Holder)

Only one holder can control a container at any moment: none, FileDO, FMS Service (Server edition service), or FMS Session (User edition session worker). If the disk is already mounted locally in FileDO, FileDO cleanly disconnects it upon confirmation before handing it to FMS. If a disk is held by FMS, FileDO will refuse local mount attempts and show who holds it. У контейнера может быть только один владелец одновременно: none (никто), FileDO, FMS Service (служба Windows в серверной редакции) или FMS Session (воркер в пользовательском сеансе). Если диск уже смонтирован локально в FileDO, FileDO запросит подтверждение и корректно отключит его перед передачей в FMS. Если диск держит FMS, попытка смонтировать его в FileDO будет отклонена с указанием текущего владельца. У контейнера може бути лише один власник одночасно: none (ніхто), FileDO, FMS Service (служба Windows у серверній редакції) або FMS Session (воркер у сеансі користувача). Якщо диск уже змонтовано локально у FileDO, FileDO запитає підтвердження і коректно відключить його перед передачею в FMS. Якщо диск тримає FMS, спроба змонтувати його у FileDO буде відхилена із зазначенням поточного власника.

Autostart and protected encryption keysАвтозапуск и безопасное хранение ключейАвтозапуск та безпечне зберігання ключів

Autostart is an explicit opt-in for each disk. For encrypted disks, entering the password enables automatic reopening after reboots without transmitting credentials to phones. The key is encrypted via Windows DPAPI: machine-protected under Server edition (FastMediaSorterCompanionSFTP) or user-protected under User edition. It is never stored in the container, never written to log files, and is destroyed immediately if autostart is toggled off, sharing is stopped, or the container password changes. Автозапуск настраивается отдельно для каждого диска с явного согласия пользователя. Для зашифрованного диска ввод пароля позволяет автоматически открывать его после перезагрузки без передачи секретов на телефон. Ключ защищается Windows DPAPI: машинным хранилищем под службой Server edition (FastMediaSorterCompanionSFTP) или пользовательским хранилищем под User edition. Ключ никогда не пишется в сам контейнер или в логи и немедленно уничтожается при отключении автозапуска, прекращении шаринга или смене пароля. Автозапуск налаштовується окремо для кожного диска за явної згоди користувача. Для зашифрованого диска введення пароля дозволяє автоматично відкривати його після перезавантаження без передачі секретів на телефон. Ключ захищається Windows DPAPI: машинним сховищем під службою Server edition (FastMediaSorterCompanionSFTP) або сховищем користувача під User edition. Ключ ніколи не записується в сам контейнер чи в журнали і негайно знищується у разі вимкнення автозапуску, припинення спільного доступу чи зміни пароля.

Pair your phone over SFTPПодключите телефон по SFTPПідключіть телефон через SFTP

Open the Android FastMediaSorter app, select Add resource → SFTP/FTP → Import from companion, and scan the QR code from Share Manager. The open FileDO disk appears alongside standard shared folders, allowing smooth browsing and media playback. Closing the disk keeps its registration for easy one-click reopening later; stopping sharing removes it completely. В приложении FastMediaSorter на Android выберите Добавить ресурс → SFTP/FTP → Импорт из компаньона и отсканируйте QR-код из Share Manager. Открытый диск FileDO появится рядом с обычными общими папками, позволяя просматривать и открывать медиафайлы. Закрытие диска сохраняет его регистрацию для быстрого повторного открытия в один клик; прекращение шаринга удаляет его полностью. У застосунку FastMediaSorter на Android виберіть Додати ресурс → SFTP/FTP → Імпорт із компаньйона та відскануйте QR-код із Share Manager. Відкритий диск FileDO з'явиться поруч зі звичайними спільними теками, дозволяючи переглядати та відкривати медіафайли. Закриття диска зберігає його реєстрацію для швидкого повторного відкриття в один клік; припинення спільного доступу видаляє його повністю.
