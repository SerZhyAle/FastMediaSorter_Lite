查看器窗口

用途说明

查看器窗口是媒体与文件管理器的主窗口。它每次显示文件夹中的一张图片或一个视频，并用一个按键把文件分拣到各个文件夹。在 64 位版本中，若在设置的「文件」页勾选了「整理文档」或「整理其他文件」，文档和其他文件会以预览的形式加入同一列表；按 F3 打开图片面板，它也可以作为文件管理器，管理本地文件夹、服务器和已连接的设备。启动程序或用本程序打开媒体文件时，会打开该窗口。

操作顺序

  1. 按 F4，或在「文件夹：」框中输入路径后按 Enter。
  2. 用方向键、Space 和 P 浏览文件。
  3. 按数字键把文件移到对应的文件夹，或按 Shift 加上排数字键进行复制。
  4. 按 Del 删除文件。
  5. 按 F2 打开设置。

界面元素

打开文件夹

F4 会打开文件选择窗口；所选文件会显示出来，它所在的整个文件夹则成为浏览列表。「文件夹：」框接受文件夹路径，输入后按 Enter。未打开任何内容时，帮助卡片会列出主要按键，F1 可显示或隐藏它。空白画面上还有「初始设置」按钮，用于启动欢迎步骤。

悬浮面板与状态栏

两排工具栏按钮和一条状态栏悬浮在图片上方，鼠标静止时会逐渐淡出。面板角上的图钉可把面板固定在原位；设置「常规」页中的「保持悬浮面板可见」会让所有面板始终可见。状态栏显示消息，例如文件操作的结果。

移动悬浮面板

每个悬浮面板在图钉旁都有一个移动手柄「移动面板」：两排工具栏按钮、状态栏、窗口控制和视频的播放控制（播放控制只能上下移动）；目标表格则拖动它的表头。拖动手柄即可把面板放到想要的位置。面板在任何时刻都完整留在窗口内，拖动时如此，缩小窗口时也如此；窗口再次变大后，它会回到你选的位置。把面板放在离常规位置几个像素以内，它会自动回到那里。任何面板都不能放在窗口控制或播放控制上方。不用鼠标时，按 F10，选中手柄，按 Enter 或 Space，用方向键移动面板（Shift 步幅更大），再按 Enter、Space 或 Esc 结束。点击手柄会打开一个菜单，把这个面板或所有面板放回原位；设置「常规」页中的「将面板恢复到原位」按钮作用相同，状态栏会说明是否有面板移动过。

浏览文件

Space 和 PgDn 显示下一个文件，P 和 PgUp 显示上一个；上、下方向键一次跳过十个文件，Home 和 End 分别转到第一个和最后一个文件。除非滚轮被设为缩放，否则滚轮也可以逐个浏览文件。

移动、复制和删除

数字键 1..9 或 0 会把当前文件移到绑定在该键上的文件夹；Shift 加上排数字键（不是 NumPad）则复制该文件。文件夹在设置的「目标」页中绑定。U 键把最近移动的文件移回来。Del 会把文件送入回收站（「文件」页中的「删除到回收站」选项），Shift+Del 则永久删除；网络驱动器和U盘没有回收站，程序会事先提示。F3 打开「图片面板」。

幻灯片与显示

S 启动幻灯片，I 或 F5 启动随机幻灯片，Y 跳到随机文件；间隔和顺序在设置的「图片」页中设置。R 旋转图片，F7 切换全屏。

缩放与图片菜单

在 64 位版本中，NumPad 的灰色按键区用于缩放：+ 和 - 在鼠标光标处放大和缩小，/ 使图片适应窗口，* 以 100 % 显示。「图片」页中的「用滚轮缩放」选项可让滚轮用于缩放。

视频

单击可暂停或继续播放视频，右键打开视频菜单。在 64 位版本中，A 切换音轨，V 切换字幕；仅当文件提供可选项时，工具栏上才会出现「轨道」按钮。

设置与按键列表

F2 或工具栏上的「设置」按钮可打开设置。完整的按键列表在：「文件」页，「按键与关联」组，「键盘快捷键」按钮。
