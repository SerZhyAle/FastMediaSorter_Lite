SFTP 共享设置

用途说明

SFTP：端口、连接数限制、仅局域网策略和 Windows 服务。交换服务器：地址、TLS、账户、设备、邀请、服务、日志和远程管理。

操作顺序

SFTP 端口通过应用按钮更改。切换窗口保留草稿。关闭时：是应用，否放弃，取消继续编辑。出错时保留草稿。更改端口后更新连接代码和路由器转发规则。
