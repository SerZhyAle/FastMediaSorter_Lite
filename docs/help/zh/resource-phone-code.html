手机连接

用途说明

显示一个二维码，手机扫描后可把文件夹的设置发送到这台电脑。它从资源列表「更多」菜单中的「显示手机连接码..」打开。

操作顺序

  1. 打开「显示手机连接码..」。
  2. 用手机扫描二维码；手机必须能通过本地网络访问这台电脑。
  3. 手机发送它的连接码，窗口显示「已接收连接码」并关闭，随后开始导入。
  4. 如果手机无法访问这台电脑，请把它的连接码（文本或二维码截图）放到这台电脑的剪贴板上，然后点击「从剪贴板粘贴..」。

界面元素

二维码

二维码代表本地网络上的一个一次性地址和一个一次性令牌。只有在窗口打开期间，窗口才会在该地址上监听，关闭时即停止；监听的只有这一个地址，而不是每个网络适配器。如果监听器无法启动，状态栏会显示「无法启动本地接收服务」。

地址框与复制

二维码下方的只读框以文本形式显示同一个地址。「复制」会带着隐私标记（不进入剪贴板历史，不进行云同步）把它放到剪贴板，因为其中的令牌能让持有者向这个窗口交一个连接码。在浏览器中打开该地址的人只会看到一个简短的页面，说明这是一个一次性地址。

从剪贴板粘贴

「从剪贴板粘贴..」从剪贴板读取文本或手机二维码的截图，并用与键入文本相同的读取器检查。如果它不是连接码，状态栏会说明原因，窗口保持打开，等待手机。

连接码的处理

最先到达的连接码（来自手机或剪贴板）会占用该窗口；第二个会被丢弃。窗口关闭，并运行与「从文件导入..」相同的导入：先是需要确认的摘要，如果连接码需要密码则询问密码，然后状态栏显示「已添加或更新的资源数」和数量。

等待与关闭

等待时，状态栏显示「正在等待手机连接..」。「关闭」只是结束等待；Enter 和 Esc 都选择它，所以手机的连接码绝不会因按键而被接收。
