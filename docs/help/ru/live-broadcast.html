Прямой эфир

Назначение

Вставьте код FMSBCAST1:, ссылку или URL потока либо выберите файл .fmsbcast. Отметьте обычный URL как прямой эфир только для живого источника; иначе он откроется как обычное медиа. Нажмите «Подключиться» и введите пароль зрителя, если он запрошен. Недавний адрес может перестать работать после остановки вещателя или смены порта. Автоматический приём Cast включается отдельно и явно.
