Conexão do telefone

Finalidade

Mostra um código QR que um telefone escaneia para enviar a este computador as configurações de uma pasta. A janela se abre em «Mostrar código para o telefone..» no menu «Mais» da lista de recursos.

Nesta ordem

  1. Abra «Mostrar código para o telefone..».
  2. Escaneie o código QR com o telefone; o telefone precisa alcançar este computador na rede local.
  3. O telefone envia o seu código, a janela diz «Código recebido» e se fecha, e a importação começa.
  4. Se o telefone não alcança o computador, coloque o código dele na área de transferência deste computador, como texto ou como captura do código QR, e pressione «Colar da área de transferência..».

Os elementos

O código QR

O código representa um endereço de uso único na sua rede local com um token de uso único. A janela escuta nesse endereço só enquanto está aberta e para quando se fecha; apenas esse endereço é escutado, não todos os adaptadores de rede. Se a escuta não consegue iniciar, a linha de status diz «Falha ao iniciar a recepção local».

A caixa do endereço e Copiar

A caixa somente leitura abaixo do código mostra o mesmo endereço como texto. «Copiar» o coloca na área de transferência com as marcas de privacidade (sem histórico da área de transferência, sem sincronização na nuvem), porque o token que ele contém permite a quem o tiver entregar um código a esta janela. Quem abre o endereço em um navegador vê só uma página curta dizendo que é um endereço de uso único.

Colar da área de transferência

«Colar da área de transferência..» lê da área de transferência um texto, ou uma captura do código QR do telefone, e o verifica com o mesmo leitor do texto digitado. Se não for um código, a linha de status diz por quê, e a janela continua aberta para o telefone.

O que acontece com o código

O primeiro código que chega, do telefone ou da área de transferência, ocupa a janela; um segundo é descartado. A janela se fecha e roda a mesma importação de «Importar de arquivo..»: um resumo para confirmar, uma pergunta sobre a senha se o código precisar dela e, depois, «Recursos adicionados ou atualizados» com um número na linha de status.

Espera e Fechar

Durante a espera, a linha de status diz «Aguardando conexão do telefone..». «Fechar» apenas encerra a espera; Enter e Esc escolhem ambos este botão, de modo que um toque de tecla nunca aceita o código do telefone.
