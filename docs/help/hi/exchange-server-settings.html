यह किस लिए है

SFTP: पोर्ट, कनेक्शन सीमा, स्थानीय नेटवर्क और Windows सेवा। एक्सचेंज सर्वर: पता, TLS, खाते, डिवाइस, आमंत्रण, सेवा, लॉग और दूरस्थ प्रशासन।

इस क्रम में

ट्रे या घटक लिंक से खोलें। विंडो खोलने और बंद करने से सर्वर शुरू या बंद नहीं होता। दूरस्थ लॉगिन के लिए स्थानीय सर्वर आवश्यक नहीं है।
