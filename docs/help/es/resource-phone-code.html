Conexión del teléfono

Para qué sirve

Muestra un código QR que un teléfono escanea para enviar a este equipo la configuración de una carpeta. Se abre desde «Mostrar código para el teléfono..» en el menú «Más» de la lista de recursos.

En este orden

  1. Abra «Mostrar código para el teléfono..».
  2. Escanee el código QR con el teléfono; el teléfono debe llegar a este equipo en la red local.
  3. El teléfono envía su código, la ventana dice «Código recibido» y se cierra, y empieza la importación.
  4. Si el teléfono no llega al equipo, ponga su código en el portapapeles de este equipo, como texto o como captura del código QR, y pulse «Pegar desde el portapapeles..».

Los elementos

El código QR

El código representa una dirección de un solo uso en su red local con un token de un solo uso. La ventana escucha en esa dirección solo mientras está abierta y deja de hacerlo al cerrarse; se escucha únicamente esa dirección, no todos los adaptadores de red. Si la escucha no puede iniciarse, la línea de estado dice «No se pudo iniciar la recepción local».

El cuadro de la dirección y Copiar

El cuadro de solo lectura bajo el código muestra la misma dirección como texto. «Copiar» la pone en el portapapeles con las marcas de privacidad (sin historial del portapapeles, sin sincronización en la nube), porque el token que contiene permite a quien lo tenga entregar un código a esta ventana. Quien abre la dirección en un navegador solo ve una página breve que dice que es una dirección de un solo uso.

Pegar desde el portapapeles

«Pegar desde el portapapeles..» lee del portapapeles un texto, o una captura del código QR del teléfono, y lo comprueba con el mismo lector que el texto escrito. Si no es un código, la línea de estado dice por qué y la ventana sigue abierta para el teléfono.

Qué ocurre con el código

El primer código que llega, del teléfono o del portapapeles, ocupa la ventana; un segundo se descarta. La ventana se cierra y se ejecuta la misma importación que con «Importar de archivo..»: un resumen para confirmar, una pregunta por la contraseña si el código la necesita y, después, «Recursos añadidos o actualizados» con un número en la línea de estado.

Espera y Cerrar

Mientras espera, la línea de estado dice «Esperando la conexión del teléfono..». «Cerrar» solo termina la espera; Intro y Esc eligen ambos este botón, de modo que pulsar una tecla nunca acepta el código del teléfono.
