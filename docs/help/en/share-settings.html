Manager settings

What this is for

Set manager startup, theme and language here. Your remote exchange account, publishing, clipboard and scheduled file operations belong to the manager and do not require a locally installed exchange server or enabled SFTP sharing.

In this order

Open Manager settings from the manager or tray. Choose a page, expand a group, or use Search settings. Use the component links to open SFTP or local exchange settings beside this window. Closing one window keeps the other windows, schedules and servers running.

Manager settings

The links at the lower left open or activate one window per destination. They follow installed payloads, not whether a server is running. Each window remembers its own page, group folds, scroll and size. Common theme and language editors appear only in Manager settings. F1 and ? open the current page help.
