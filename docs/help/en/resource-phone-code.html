Phone connection

What this is for

Shows a QR code that a phone scans to send a folder's settings to this computer. It opens from «Show code for phone..» in the «More» menu of the resources list.

In this order

  1. Open «Show code for phone..».
  2. Scan the QR code with the phone; the phone must reach this computer on the local network.
  3. The phone sends its code, the window says «Code received» and closes, and the import starts.
  4. If the phone cannot reach the computer, put its code on this computer's clipboard, as text or as a screenshot of the QR code, and press «Paste from clipboard..».

The elements

The QR code

The code stands for a one-time address on your local network with a single-use token. The window listens at that address only while it is open and stops when it closes; only that one address is listened on, not every network adapter. If the listener cannot start, the status line says «Failed to start local listener».

The address box and Copy

The read-only box under the code shows the same address as text. «Copy» puts it on the clipboard with the privacy markers (no clipboard history, no cloud sync), because the token in it lets whoever holds it hand a code to this window. Someone who opens the address in a browser sees only a short page saying that it is a one-time address.

Paste from clipboard

«Paste from clipboard..» reads text, or a screenshot of the phone's QR code, from the clipboard and checks it with the same reader as typed text. If it is not a code, the status line says why and the window stays open for the phone.

What happens with the code

The first code that arrives, from the phone or from the clipboard, takes the window; a second one is dropped. The window closes and the same import as «Import from file..» runs: a summary to confirm, a password question if the code needs one, then «Resources added or updated» with a count in the status line.

Waiting and Close

While it waits, the status line reads «Waiting for phone connection..». «Close» only ends the waiting; Enter and Esc both choose it, so a key never takes the phone's code.
