Viewer window

What this is for

The viewer window is the main window of the media and file manager. It shows one picture or video at a time from a folder and sorts files into folders with a single key. In the 64-bit version, documents and other files join the same list as previews when 'Sort documents' or 'Sort other files' is ticked on the 'Files' page of Settings, and F3 opens the image panel, which also works as a file manager for local folders, servers and connected devices. The window opens when you start the program or open a media file with it.

In this order

  1. Press F4, or type a path into the 'Folder:' box and press Enter.
  2. Browse with the arrow keys, Space and P.
  3. Press a digit to move the file to its folder, or Shift plus a top-row digit to copy it.
  4. Press Del to delete the file.
  5. Press F2 for Settings.

The elements

Opening a folder

F4 opens a file chooser; the file you pick is shown and its whole folder becomes the list to browse. The 'Folder:' box takes a folder path - press Enter. With nothing open, a help card lists the main keys: F1 shows or hides it. The empty screen also has the button 'Welcome setup', which starts the welcome steps.

Floating panels and status line

Two rows of toolbar buttons and a status strip float over the picture and fade out while the mouse is idle. A pin in the corner of a panel keeps it in place; 'Keep floating panels visible' on the 'General' page of Settings keeps all of them. The status line shows news, for example the result of a file operation.

Browsing files

Space and PgDn show the next file, P and PgUp the previous one; Up and Down jump ten files, Home and End go to the first and the last. The mouse wheel also steps through the files unless it is set to zoom.

Moving, copying and deleting

A digit 1..9 or 0 moves the current file to the folder bound to that key; Shift plus a top-row digit (not the NumPad) copies it. The folders are bound on the 'Destinations' page of Settings. U brings the last moved file back. Del sends a file to the Recycle Bin (option 'Delete to the Recycle Bin' on the 'Files' page), Shift+Del deletes it for good; network and flash drives have no Recycle Bin, and the program says so beforehand. F3 opens the 'Image panel'.

Slideshow and view

S starts a slideshow, I or F5 a random one, and Y jumps to a random file; the interval and order are on the 'Images' page of Settings. R rotates the picture and F7 switches full screen.

Zoom and the picture menu

In the 64-bit version the grey NumPad block zooms: + and - at the mouse cursor, / fits the picture to the window, * shows it at 100 %. The option 'Zoom with the mouse wheel' on the 'Images' page lets the wheel zoom.

Video

A click pauses or resumes a video, the right button opens the video menu. In the 64-bit version A switches the audio track and V the subtitles; the 'Tracks' button appears on the toolbar only when the file offers a choice.

Settings and the list of keys

F2 or the toolbar button 'Settings' opens Settings. The full list of keys: the 'Files' page, the group 'Keys and associations', the button 'Keyboard shortcuts'.
