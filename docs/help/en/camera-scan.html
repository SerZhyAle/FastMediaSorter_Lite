Scanning QR code with camera

What this is for

Reads the QR code shown by the phone app through a camera of this PC. It opens from 'Scan with camera..' in the phone code window and from the connection string field of the exchange account window, and the camera starts when the window is shown.

In this order

  1. Hold the phone's QR code in front of the camera.
  2. The window scans the picture by itself; when a valid code is found, the status reads 'Code received' and the window closes.
  3. Press 'Cancel' (Escape) to close without scanning.

The elements

Preview and status

The black area shows the live picture. The line under it says 'Point the camera at the phone's QR code' until a code is read.

Which camera

Only the first camera found is used. If there is none, or it cannot be started, the line reads 'Camera is unavailable', followed by the reason when there is one.

After the scan

The text of the first valid QR code is returned to the window that opened the scanner and handled there as if it was pasted; in the phone code window it fills the code field and is handed over, and Fast Media Sorter still asks its usual questions. Frames stay in memory only: this window saves and sends nothing.
