Liveübertragung

Verwendungszweck

FMSBCAST1:-Code, Link oder Stream-URL einfügen oder eine .fmsbcast-Datei wählen. Eine gewöhnliche URL nur bei einer Livequelle als live markieren; sonst wird sie als abrufbare Mediendatei geöffnet. Verbinden drücken und bei Bedarf das Zuschauerpasswort eingeben. Gespeicherte Adressen können nach Sendestopp oder Portwechsel ungültig sein. Automatische Cast-Annahme ist eine gesonderte ausdrückliche Wahl.
