Telefonverbindung

Verwendungszweck

Zeigt einen QR-Code, den ein Telefon scannt, um die Einstellungen eines Ordners an diesen Computer zu senden. Das Fenster öffnet sich über «Code für Telefon anzeigen..» im Menü «Mehr» der Ressourcenliste.

In dieser Reihenfolge

  1. Öffnen Sie «Code für Telefon anzeigen..».
  2. Scannen Sie den QR-Code mit dem Telefon; das Telefon muss diesen Computer im lokalen Netzwerk erreichen.
  3. Das Telefon sendet seinen Code, das Fenster meldet «Code empfangen» und schließt sich, und der Import beginnt.
  4. Erreicht das Telefon den Computer nicht, legen Sie seinen Code in die Zwischenablage dieses Computers, als Text oder als Screenshot des QR-Codes, und drücken Sie «Aus Zwischenablage einfügen..».

Die Elemente

Der QR-Code

Der Code steht für eine einmalige Adresse in Ihrem lokalen Netzwerk mit einem Token für den einmaligen Gebrauch. Das Fenster lauscht an dieser Adresse nur, solange es offen ist, und hört beim Schließen auf; gelauscht wird nur an dieser einen Adresse, nicht an jedem Netzwerkadapter. Kann der Empfang nicht starten, steht in der Statuszeile «Lokaler Empfang konnte nicht gestartet werden».

Das Adressfeld und Kopieren

Das schreibgeschützte Feld unter dem Code zeigt dieselbe Adresse als Text. «Kopieren» legt sie mit den Datenschutzmarkierungen in die Zwischenablage (kein Zwischenablageverlauf, keine Cloud-Synchronisierung), denn das darin enthaltene Token erlaubt jedem, der es besitzt, diesem Fenster einen Code zu übergeben. Wer die Adresse in einem Browser öffnet, sieht nur eine kurze Seite, die sagt, dass es sich um eine einmalige Adresse handelt.

Aus Zwischenablage einfügen

«Aus Zwischenablage einfügen..» liest Text oder einen Screenshot des QR-Codes des Telefons aus der Zwischenablage und prüft ihn mit demselben Leser wie getippten Text. Ist es kein Code, nennt die Statuszeile den Grund, und das Fenster bleibt für das Telefon offen.

Was mit dem Code geschieht

Der erste Code, der eintrifft, vom Telefon oder aus der Zwischenablage, belegt das Fenster; ein zweiter wird verworfen. Das Fenster schließt sich, und derselbe Import wie bei «Aus Datei importieren..» läuft: eine Zusammenfassung zur Bestätigung, bei Bedarf eine Frage nach dem Kennwort, dann «Hinzugefügte oder aktualisierte Ressourcen» mit einer Zahl in der Statuszeile.

Warten und Schließen

Während des Wartens steht in der Statuszeile «Warten auf Telefonverbindung..». «Schließen» beendet nur das Warten; Eingabetaste und Esc wählen beide diese Schaltfläche, sodass ein Tastendruck den Code des Telefons nie übernimmt.
