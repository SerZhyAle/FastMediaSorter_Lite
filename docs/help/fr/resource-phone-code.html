Connexion du téléphone

Objectif

Affiche un code QR qu'un téléphone scanne pour envoyer à cet ordinateur les paramètres d'un dossier. La fenêtre s'ouvre depuis «Afficher le code pour le téléphone..» dans le menu «Plus» de la liste des ressources.

Dans cet ordre

  1. Ouvrez «Afficher le code pour le téléphone..».
  2. Scannez le code QR avec le téléphone ; le téléphone doit joindre cet ordinateur sur le réseau local.
  3. Le téléphone envoie son code, la fenêtre indique «Code reçu» et se ferme, et l'import démarre.
  4. Si le téléphone ne peut pas joindre l'ordinateur, mettez son code dans le presse-papiers de cet ordinateur, sous forme de texte ou de capture d'écran du code QR, et appuyez sur «Coller depuis le presse-papiers..».

Les éléments

Le code QR

Le code représente une adresse à usage unique sur votre réseau local avec un jeton à usage unique. La fenêtre n'écoute à cette adresse que tant qu'elle est ouverte et s'arrête à sa fermeture ; seule cette adresse est écoutée, pas chaque carte réseau. Si l'écoute ne peut pas démarrer, la ligne d'état indique «Impossible de démarrer l'écoute locale».

La zone d'adresse et Copier

La zone en lecture seule sous le code affiche la même adresse sous forme de texte. «Copier» la place dans le presse-papiers avec les marqueurs de confidentialité (pas d'historique du presse-papiers, pas de synchronisation cloud), car le jeton qu'elle contient permet à quiconque le détient de remettre un code à cette fenêtre. Quelqu'un qui ouvre l'adresse dans un navigateur ne voit qu'une courte page indiquant qu'il s'agit d'une adresse à usage unique.

Coller depuis le presse-papiers

«Coller depuis le presse-papiers..» lit dans le presse-papiers un texte ou une capture d'écran du code QR du téléphone et le vérifie avec le même lecteur que le texte saisi. Si ce n'est pas un code, la ligne d'état en donne la raison et la fenêtre reste ouverte pour le téléphone.

Ce qui se passe avec le code

Le premier code qui arrive, du téléphone ou du presse-papiers, occupe la fenêtre ; un deuxième est écarté. La fenêtre se ferme et le même import que «Importer depuis un fichier..» s'exécute : un récapitulatif à confirmer, une question sur le mot de passe si le code en demande un, puis «Ressources ajoutées ou mises à jour» avec un nombre dans la ligne d'état.

Attente et Fermer

Pendant l'attente, la ligne d'état indique «En attente de la connexion du téléphone..». «Fermer» ne fait que mettre fin à l'attente ; Entrée et Esc choisissent tous deux ce bouton, de sorte qu'une touche n'accepte jamais le code du téléphone.
