Numérisation du code QR avec la caméra

Objectif

Lit le code QR affiché par l'application du téléphone à l'aide d'une caméra de ce PC. Elle s'ouvre depuis «Scanner avec la caméra..» dans la fenêtre du code du téléphone et depuis la zone de la chaîne de connexion de la fenêtre du compte d'échange ; la caméra démarre à l'affichage de la fenêtre.

Dans cet ordre

  1. Tenez le code QR du téléphone devant la caméra.
  2. La fenêtre scanne l'image d'elle-même ; quand un code valide est trouvé, l'état indique «Code reçu» et la fenêtre se ferme.
  3. Cliquez sur «Annuler» (Échap) pour fermer sans scanner.

Les éléments

Aperçu et état

La zone noire affiche l'image en direct. La ligne dessous indique «Pointez la caméra vers le code QR du téléphone» tant qu'aucun code n'est lu.

Quelle caméra

Seule la première caméra trouvée est utilisée. S'il n'y en a aucune ou si elle ne peut pas démarrer, la ligne indique «La caméra n'est pas disponible», suivie de la raison quand il y en a une.

Après la numérisation

Le texte du premier code QR valide est renvoyé à la fenêtre qui a ouvert le scanner et y est traité comme s'il avait été collé ; dans la fenêtre du code du téléphone, il remplit la zone du code et est transmis, et Fast Media Sorter pose toujours ses questions habituelles. Les images restent uniquement en mémoire : cette fenêtre n'enregistre ni n'envoie rien.
