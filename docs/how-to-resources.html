HOW TO · RESOURCES

Open a server or a network share like a folder

A family NAS, a PC that shares folders with the Share Manager, any SFTP server, a network share that wants a password: add it once, and its pictures and videos page through like files on disk - with the key to the server checked every time. It is a feature of the 64-bit viewer (Windows 10 version 1607 or newer); the 32-bit fallback for Windows 7 and 8.1 has no resources.

Add the server

Open Settings (F2) → Server and resources → Resources and press "Add..": the address, the port (22 by default), the user, the password and the folder on the server. The same list lives in the folder menu under "Resources" - "Manage resources..". A network share that needs a login is the second type in the same window. Already have a file from the Share Manager? Press "Import from file.." - or "Import from clipboard" for the text of a code - and everything, including the server's key, comes in at once. You can also drop the .fmscfg file on the viewer window.

Open it

Choose the resource in the list and press "Open" - or pick it from the "Resource" button on the toolbar (it appears with the first saved resource and opens the last few in one click), from the "Resources" submenu of the folder menu, where the last few you used wait one click away. Typing sftp://user@host:port/folder in the folder box and pressing Enter does the same, and the program opens it again on the next start if that was the folder you left. The first time, a server added by hand shows the fingerprint of its key and asks whether to trust it; the default answer is No. A file from the Share Manager brings the key with it, so that very first connection is already checked.

Browse and sort as usual

Pictures, video, audio and documents open as if they were on this PC: the program fetches the file it is about to show and the next one, and throws the copies away when you leave. RE asks the server again. Del, 0-9, Shift+digit, F6 and U act on the server's own files; a move is proven by content before the original is touched, so a dropped connection never loses a file. SFTP deletion is permanent even when the Windows Recycle Bin setting is enabled. A move removes the server original after verifying the copy and checking that the source has not changed; a failed or unverified removal is reported as an incomplete move. A folder the owner shared as read-only says so instead of failing half-way.

The exported file is an access key

Hand it only to the person who needs it: whoever holds it can open the server.

Hand the server to another computer

Select the resource in Settings → Server and resources → Resources and press "Export..": the program makes the same .fmscfg file the Share Manager produces, with the server's key already inside, so on the other computer - or on this one, or on the phone - it imports verified and opens without the trust question. Save it to a file or copy it to the clipboard as text or as a code. By default the file goes out without the password: the receiver is asked for it once. An unverified server and a Windows network folder cannot be exported - the program says why.

Sort straight into a server folder

A 0-9 destination can be a folder of a saved server: in Settings → Destinations, double-click the slot's folder and pick the resource instead of "A folder on this PC..", then type a subfolder after the address if you want one. The slot shows the resource's name; the first key press connects (it asks for the password once if none is remembered), and the file is sent, read back and compared before the original is deleted. A slot works only with a server whose key the program already knows - open the resource once first - and never with one shared read-only. Taking a move back with U verifies the returned file and removes the server copy if it is unchanged. Permanent SFTP deletion cannot be undone.

If the key changes

A server whose key is not the one remembered is refused, and both fingerprints are shown: a reinstalled server looks exactly like an impostor. If you are sure of the server, open the resource with "Edit.." and use "Forget the server key.." - a deliberate button, never a prompt that can be dismissed by accident.

Folders locked with a PIN

A shared folder that the Share Manager locked with a PIN makes the whole file refuse to import, because the viewer cannot open it unlocked. The password is kept only encrypted for your Windows account (or in memory, if you untick "Remember the password (protected by Windows)").

Where sharing settings live

Settings are in two windows. Manager settings holds the SFTP sharing group - the SFTP port, LAN-only policy and Hosting page, shown while that component is installed - beside general preferences, remote-account access, publishing and schedules. The installed local exchange server has its own settings window. The link at the lower left opens the other window without closing the current one. Opening settings starts no server. Earlier builds showed SFTP sharing in a window of its own.
