HOW TO · RESOURCES

Open a server or a network share like a folderОткрыть сервер или сетевую папку как обычную папкуВідкрийте сервер або мережеву теку як звичайну теку

A family NAS, a PC that shares folders with the Share Manager, any SFTP server, a network share that wants a password: add it once, and its pictures and videos page through like files on disk - with the key to the server checked every time. It is a feature of the 64-bit viewer (Windows 10 version 1607 or newer); the 32-bit fallback for Windows 7 and 8.1 has no resources.Домашний NAS, компьютер, раздающий папки через Share Manager, любой SFTP-сервер, сетевая папка с паролем: добавьте её один раз - и картинки с видео листаются как файлы на диске, а ключ сервера проверяется при каждом подключении. Это возможность 64-битного просмотрщика (Windows 10 версии 1607 и новее); в 32-битной резервной сборке для Windows 7 и 8.1 ресурсов нет.Домашній NAS, комп'ютер, що роздає теки через Share Manager, будь-який SFTP-сервер, мережева тека, яка вимагає пароль: додайте її один раз - і зображення та відео гортаються як файли на диску, а ключ сервера перевіряється щоразу. Це можливість 64-бітного переглядача (Windows 10 версії 1607 і новіше); у 32-бітній резервній збірці для Windows 7 і 8.1 ресурсів немає.

Add the serverДобавьте серверДодайте сервер

Open Settings (F2) → Server and resources → Resources and press "Add..": the address, the port (22 by default), the user, the password and the folder on the server. The same list lives in the folder menu under "Resources" - "Manage resources..". A network share that needs a login is the second type in the same window. Already have a file from the Share Manager? Press "Import from file.." - or "Import from clipboard" for the text of a code - and everything, including the server's key, comes in at once. You can also drop the .fmscfg file on the viewer window.Откройте Настройки (F2) → Сервер и ресурсы → Ресурсы и нажмите «Добавить..»: адрес, порт (по умолчанию 22), пользователь, пароль и папка на сервере. Тот же список - в меню папки, «Ресурсы» - «Управление ресурсами..». Сетевая папка с паролем - второй тип в том же окне. Есть файл из Share Manager? Нажмите «Импорт из файла..» - или «Импорт из буфера» для текста кода, - и всё, включая ключ сервера, добавится сразу. Файл .fmscfg можно и просто перетащить на окно просмотрщика.Відкрийте Налаштування (F2) → Сервер і ресурси → Ресурси і натисніть «Додати..»: адреса, порт (типово 22), користувач, пароль і тека на сервері. Той самий список є в меню теки під «Ресурси» - «Керування ресурсами..». Мережева тека, яка потребує логін, - другий тип у тому самому вікні. Уже маєте файл із Share Manager? Натисніть «Імпорт із файлу..» - або «Імпорт із буфера» для тексту коду - і все, разом із ключем сервера, додасться одразу. Файл .fmscfg також можна просто перетягнути на вікно переглядача.

Open itОткройтеВідкрийте його

Choose the resource in the list and press "Open" - or pick it from the "Resource" button on the toolbar (it appears with the first saved resource and opens the last few in one click), from the "Resources" submenu of the folder menu, where the last few you used wait one click away. Typing sftp://user@host:port/folder in the folder box and pressing Enter does the same, and the program opens it again on the next start if that was the folder you left. The first time, a server added by hand shows the fingerprint of its key and asks whether to trust it; the default answer is No. A file from the Share Manager brings the key with it, so that very first connection is already checked.Выберите ресурс в списке и нажмите «Открыть» - или найдите его в одну кнопку «Ресурс» на панели инструментов (она появляется вместе с первым сохранённым ресурсом и открывает последние в один щелчок), в подменю «Ресурсы» меню папки. То же делает адрес sftp://пользователь@сервер:порт/папка, набранный в поле каталога, и Enter; если вы ушли с этой папки, при следующем запуске программа откроет её снова. В первый раз сервер, добавленный вручную, покажет отпечаток своего ключа и спросит, доверять ли ему; ответ по умолчанию - «Нет». Файл из Share Manager приносит ключ с собой, поэтому проверка идёт уже при первом подключении.Виберіть ресурс у списку й натисніть «Відкрити» - або виберіть його кнопкою «Ресурс» на панелі інструментів (вона з'являється разом із першим збереженим ресурсом і відкриває кілька останніх одним клацанням), або в підменю «Ресурси» меню теки, де кілька останніх використаних чекають на одне клацання. Те саме робить адреса sftp://user@host:port/folder, введена в поле теки, і натискання Enter; якщо ви залишили програму на цій папці, під час наступного запуску вона відкриє її знову. Уперше сервер, доданий уручну, покаже відбиток свого ключа й запитає, чи довіряти йому; відповідь за замовчуванням - «Ні». Файл із Share Manager приносить ключ із собою, тому вже саме перше підключення перевіряється.

Browse and sort as usualЛистайте и разбирайте как обычноГортайте й сортуйте як зазвичай

Pictures, video, audio and documents open as if they were on this PC: the program fetches the file it is about to show and the next one, and throws the copies away when you leave. RE asks the server again. Del, 0-9, Shift+digit, F6 and U act on the server's own files; a move is proven by content before the original is touched, so a dropped connection never loses a file. SFTP deletion is permanent even when the Windows Recycle Bin setting is enabled. A move removes the server original after verifying the copy and checking that the source has not changed; a failed or unverified removal is reported as an incomplete move. A folder the owner shared as read-only says so instead of failing half-way.Картинки, видео, звук и документы открываются так, будто лежат на этом компьютере: программа подгружает файл, который собирается показать, и следующий, а копии удаляет, когда вы уходите. RE заново спрашивает сервер. Del, 0-9, Shift+цифра, F6 и U действуют на файлы самого сервера; перемещение проверяется по содержимому до того, как оригинал тронут, поэтому оборванное соединение не теряет файлов. Папка, которую владелец раздал только для чтения, честно об этом говорит, а не падает на полпути.Зображення, відео, звук і документи відкриваються так, ніби лежать на цьому комп'ютері: програма підвантажує файл, який збирається показати, і наступний, а копії видаляє, коли ви йдете. RE знову питає сервер. Del, 0-9, Shift+цифра, F6 і U діють на файли самого сервера; переміщення перевіряється за вмістом до того, як оригінал буде чіпано, тому розірване з'єднання не втрачає файлів. Тека, яку власник роздав лише для читання, прямо про це каже, а не зривається посеред дії.

The exported file is an access keyЭкспортированный файл - ключ доступаЕкспортований файл - ключ доступу

Hand it only to the person who needs it: whoever holds it can open the server.Передавайте его только тому, кому он нужен: у кого он есть, тот может открыть сервер.Передавайте його лише тому, кому він потрібен: хто його має, той може відкрити сервер.

Hand the server to another computerПередайте сервер на другой компьютерПередайте сервер на інший комп'ютер

Select the resource in Settings → Server and resources → Resources and press "Export..": the program makes the same .fmscfg file the Share Manager produces, with the server's key already inside, so on the other computer - or on this one, or on the phone - it imports verified and opens without the trust question. Save it to a file or copy it to the clipboard as text or as a code. By default the file goes out without the password: the receiver is asked for it once. An unverified server and a Windows network folder cannot be exported - the program says why.Выберите ресурс в Настройки → Сервер и ресурсы → Ресурсы и нажмите «Экспорт..»: программа приготовит тот же файл .fmscfg, что делает Share Manager, с уже проверенным ключом сервера внутри, - на другом компьютере, на этом же или на телефоне он импортируется проверенным и откроется без вопроса о доверии. Сохраните его в файл или скопируйте в буфер как текст или код. По умолчанию файл уходит без пароля: получателя спросят его один раз. Сервер с неподтверждённым ключом и сетевая папка Windows не экспортируются - программа скажет, почему.Виберіть ресурс у Налаштування → Сервер і ресурси → Ресурси і натисніть «Експорт..»: програма підготує той самий файл .fmscfg, що створює Share Manager, з уже перевіреним ключем сервера всередині, тож на іншому комп'ютері - або на цьому ж, або на телефоні - він імпортується перевіреним і відкривається без запитання про довіру. Збережіть його у файл або скопіюйте в буфер як текст чи як код. Типово файл іде без пароля: одержувача один раз попросять його ввести. Сервер із непідтвердженим ключем і мережева тека Windows не експортуються - програма скаже чому.

Sort straight into a server folderСортируйте прямо в папку на сервереСортуйте просто в теку на сервері

A 0-9 destination can be a folder of a saved server: in Settings → Destinations, double-click the slot's folder and pick the resource instead of "A folder on this PC..", then type a subfolder after the address if you want one. The slot shows the resource's name; the first key press connects (it asks for the password once if none is remembered), and the file is sent, read back and compared before the original is deleted. A slot works only with a server whose key the program already knows - open the resource once first - and never with one shared read-only. Taking a move back with U verifies the returned file and removes the server copy if it is unchanged. Permanent SFTP deletion cannot be undone.Папкой назначения 0-9 может быть папка сохранённого сервера: в Настройки → Получатели дважды щёлкните по папке слота и выберите ресурс вместо «Папка на этом компьютере..», а при желании допишите после адреса подпапку. Слот показывает имя ресурса; первое нажатие подключается (один раз спросит пароль, если он не запомнен), файл отправляется, читается обратно и сверяется до того, как удалить оригинал. Слот работает только с сервером, ключ которого программа уже знает, - сначала откройте ресурс один раз, - и никогда с ресурсом только для чтения. Отмена перемещения клавишей U проверяет возвращённый файл и удаляет копию на сервере, если она не изменилась. Удаление из SFTP безвозвратно: общая настройка Корзины на него не влияет, восстановить удалённый оригинал нельзя. При перемещении оригинал удаляется после проверки копии и исходника; если удаление не удалось или его результат неизвестен, программа сообщает о незавершённом перемещении.Текою призначення 0-9 може бути тека збереженого сервера: у Налаштування → Отримувачі двічі клацніть по папці слота й виберіть ресурс замість «Папка на цьому комп'ютері..», потім за бажання допишіть підтеку після адреси. Слот показує назву ресурсу; перше натискання підключається (один раз запитає пароль, якщо його не запам'ятано), а файл надсилається, зчитується назад і порівнюється до того, як оригінал буде видалено. Слот працює лише із сервером, ключ якого програма вже знає - спершу відкрийте ресурс один раз - і ніколи із сервером, роздаваним лише для читання. Скасування переміщення клавішею U перевіряє повернений файл і видаляє копію на сервері, якщо вона не змінилася. Видалення із SFTP незворотне: загальне налаштування Кошика на нього не впливає, відновити видалений оригінал неможливо. Під час переміщення оригінал видаляється після перевірки копії та джерела; якщо видалення не вдалося або результат невідомий, програма повідомляє про незавершене переміщення.

If the key changesЕсли ключ изменилсяЯкщо ключ змінився

A server whose key is not the one remembered is refused, and both fingerprints are shown: a reinstalled server looks exactly like an impostor. If you are sure of the server, open the resource with "Edit.." and use "Forget the server key.." - a deliberate button, never a prompt that can be dismissed by accident.Сервер, чей ключ не совпал с запомненным, не пускается, и показываются оба отпечатка: переустановленный сервер выглядит точно так же, как подделка. Если вы уверены в сервере, откройте ресурс через «Изменить..» и нажмите «Забыть ключ сервера..» - это осознанная кнопка, а не вопрос, который можно закрыть случайно.Сервер, чий ключ не збігається із запам'ятаним, відхиляється, і показуються обидва відбитки: перевстановлений сервер виглядає точно так само, як підробка. Якщо ви певні щодо сервера, відкрийте ресурс через «Змінити..» і скористайтеся «Забути ключ сервера..» - це свідома кнопка, а не запитання, яке можна закрити випадково.

Not yetПока нельзяПоки що ні

A shared folder that the Share Manager locked with a PIN makes the whole file refuse to import, because the viewer cannot open it unlocked. The password is kept only encrypted for your Windows account (or in memory, if you untick "Remember the password (protected by Windows)").Общая папка, закрытая в Share Manager PIN-кодом, заставляет отказаться от импорта всего файла: просмотрщик не умеет открывать её без замка. Пароль хранится только в зашифрованном виде для вашей учётной записи Windows (или в памяти, если снять «Запомнить пароль (защищён средствами Windows)»).Спільна тека, яку Share Manager закрив PIN-кодом, змушує відмовитися від імпорту всього файлу, бо переглядач не може відкрити її без замка. Пароль зберігається лише в зашифрованому вигляді для вашого облікового запису Windows (або в пам'яті, якщо зняти позначку «Запам'ятати пароль (захищено засобами Windows)»).

Where sharing settings liveГде находятся настройки общего доступаДе знаходяться налаштування спільного доступу

In builds with separate settings windows, SFTP sharing settings owns the SFTP port, LAN-only policy and Hosting page. General preferences, remote-account access, publishing and schedules remain in Manager settings. The installed local exchange server has its own settings window. Links at the lower left open the other installed component without closing the current window. Opening settings starts no server. Earlier builds keep these pages together.В сборках с отдельными окнами порт SFTP, локальная сеть и страница хостинга находятся в настройках общего доступа SFTP. Общие параметры, удалённая учётная запись, публикация и расписания остаются в настройках менеджера. Установленный локальный сервер обмена настраивается отдельно. Ссылки слева внизу открывают другой установленный компонент, сохраняя текущее окно. Открытие настроек не запускает сервер. В прежних сборках страницы объединены.У збірках з окремими вікнами порт SFTP, локальна мережа й сторінка хостингу знаходяться в налаштуваннях спільного доступу SFTP. Загальні параметри, віддалений обліковий запис, публікація й розклади залишаються в налаштуваннях менеджера. Установлений локальний сервер обміну налаштовується окремо. Посилання зліва внизу відкривають інший установлений компонент, зберігаючи поточне вікно. Відкриття налаштувань не запускає сервер. У попередніх збірках сторінки об’єднані.
