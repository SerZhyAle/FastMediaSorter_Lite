HOW TO · KEYS & VIEW

Every key, and how to make the picture fill the screen

The program is built around single keys, so a folder can be reviewed with one hand. Nothing here has to be memorized at once - F1 shows the short version inside the program at any time.

Move through the folder

Space → PgDnNext file
P ← PgUp BackspacePrevious file
Space / ← / →While a video or an audio track plays: pause or play, and seek 10 seconds - 64-bit viewer only
↑ / ↓Back or forward 10 files
Shift+PgUp / PgDnBack or forward 100 files
H / EFirst file / last file
NJump to a file number
F4Choose a file from a list
YA random file from the folder

Sort the current file

1..9, 0Move it to the destination folder on that number
Shift+1..0Copy it to the same folder instead - top-row digits only - 64-bit viewer only
Del or DTo the Recycle Bin
Shift+DelDelete permanently, past the bin
UUndo the last operations
F6Rename the file

Look closer

grey + / −Zoom in and out at the mouse cursor - 64-bit viewer only
grey /Fit the picture to the window - 64-bit viewer only
grey *Show it at 100% - 64-bit viewer only
Mouse wheelFlips files by default; Zoom with the mouse wheel (Settings → Images / Basic settings) switches it to zoom - 64-bit viewer only
R / Shift+RRotate the view clockwise / counter-clockwise
TRecognize and translate the text, once OCR is enabled

Fill the screen

F7Full screen - the toolbar stays, floating over the picture; F does the same in the 64-bit viewer
F11Nothing but the picture - no toolbar at all
EscLeave full screen; pressed again, closes the program
SSlideshow; pressing it again shortens the interval
I or F5Slideshow in random order
F3The thumbnail panel of the folder; G opens it in the 64-bit viewer

Video

Click on the picturePause and resume
Right mouse buttonThe menu of everything you can do with the video
ANext audio track - 64-bit viewer only
VNext subtitle track - 64-bit viewer only

Windows and help

F1The short help over the picture
F2Settings
Middle mouse buttonOn a picture: the menu of every action - rotate, zoom, edit, rename, move, delete - 64-bit viewer only
Make the keys your own

In the 64-bit program (Windows 10 1607+; the 32-bit fallback does not have it), F2 → Files → Keys and associations → Keyboard shortcuts reassigns the actions to the keys you prefer. System combinations, F11 and Esc stay with the program.

What the 32-bit build does not have

Zoom on the grey numpad keys, Shift+digit copying, the audio and subtitle keys, the mouse menus and the shortcut editor ship in the 64-bit build only (Windows 10 1607+, including 11). The fallback for Windows 7 and 8.1 keeps the historical keys, and its own F1 help never advertises the rest.
