HOW TO · FAST MEDIA SORTER

Review and sort a media folder without losing your flow

Open one folder, keep your eyes on the photo or video, and send each file where it belongs with a key or mouse action. The files remain on your PC.

Open the folder you want to review

Start Fast Media Sorter and choose a folder or open a media file in Explorer. The viewer builds a list of supported files from that folder, so you can move through it continuously.

Navigate while the file stays in view

Use the arrow keys or the viewer controls for the next and previous file. For images, use the numpad zoom controls when you need to inspect detail: NumPad +/− zoom, NumPad / fits the image, and NumPad * returns to 100%. These numpad keys are in the 64-bit viewer only (Windows 10 1607+); the 32-bit fallback does not have them.

Assign destination folders once

Open Settings with F2, then choose Destinations. Put the folders you use most often on the numbered rows. This is your sorting palette: for example, "keep", "edit", "send", and "archive".

Move or copy the current file

Press the number assigned to a destination to send the current file there. Hold Shift and press the same top-row digit when the source must remain in place - the file is copied instead of moved, decided at the moment of the action rather than by a mode you have to remember to switch off. Copying with Shift + digit is in the 64-bit viewer only (Windows 10 1607+); the 32-bit fallback does not have it. Deleting sends the file to the Recycle Bin, and U takes back the last operations - but on a network share or a memory stick Windows keeps no bin at all, and the app tells you so before it asks.

Review photos and video in the same pass

Images and videos share the same folder workflow. In the 64-bit viewer, video plays through the built-in LibVLC engine, and whether it is already on your PC depends on the install type: the Full type and the portable ZIP carry it, so playback works offline from the first file; the Compact type leaves it out, and the first time you open a video the program asks whether to download it (a No leaves that video unplayed). The Video page of the settings sets autoplay, what happens when a video ends (including Loop) and whether the position is remembered; the default volume and Start muted are on the Audio page.

Turn an animation into a real video

In the 64-bit viewer only (Windows 10 1607+; the 32-bit fallback does not have it), an animated WEBP, APNG or GIF gets an extra toolbar button, Convert to video - also Convert to video.. in the picture's middle-click menu - that writes an ordinary MP4 next to it, with a seek bar, a pause and full colour, and then deletes the animation. The encoder (FFmpeg, free software under the GPL, about 110 MB) is not bundled: the first conversion asks whether to download it and a No simply cancels. Because the original is deleted permanently, past the Recycle Bin, the viewer names both files first and warns when a transparent picture is about to be flattened onto black; nothing is deleted until the video exists, and an existing name.mp4 is never overwritten.

The second view of a slow format is instant

Animated WEBP, AVIF and HEIC have no Windows codec, so the 64-bit viewer decodes them itself - seconds of work for a large animation, which is what the "Loading.." badge is telling you about. That work is now kept on disk and reused while the file is unchanged, so the badge appears once per file instead of once per view. Settings → Storage (Decode cache, MB) sets its limit (512 MB by default; 0 switches the cache off), shows how much space it takes and empties it on request. JPEG, PNG and BMP are never cached - Windows opens those in milliseconds. The decode cache is in the 64-bit viewer only (Windows 10 1607+); the 32-bit fallback does not have it.

Use OCR only when text needs translation

Once OCR is set up, press T on an image to recognize its text and show the translation over it; the settings, languages and limits are in the OCR guide.

Safe first pass

Start with a test folder, or press Shift + a top-row digit so that every sort is a copy, until the destination keys feel natural; U takes back the last operations. Leave Ask before deleting (Files / Basic settings) at its default while you are learning the layout.

If something goes wrong

Open F2 → About and press Send the logs to the author; what goes into the archive and what stays on your PC is explained in the setup guide.

Need your folders on Android?

The 64-bit app can publish selected PC folders through its built-in SFTP service. Follow the separate guide; only folders you explicitly add are exposed.
