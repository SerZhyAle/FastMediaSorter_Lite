HOW TO · IMAGE EDITOR

Mark up a picture and crop it without leaving the viewer

Circle the important part, hide a name or a number, cut off the empty edges - then save over the original or next to it. The editor is a separate window, so no stray keypress can move or delete the file behind it. It is part of the 64-bit viewer only (Windows 10 version 1607 or newer).

Open the editor on a still image

With a photo on screen, press the Edit toolbar button (an icon without a caption; its tooltip reads Open the picture in the editor), or click the picture with the middle mouse button and take the first item of the menu, Edit... The button appears only for still images - there is nothing to edit in a video or a running animation.

Pick a tool, a colour and a thickness

The toolbar buttons show icons only - hover one for its name and key. The tools are Brush, Rectangle and Filled rectangle, Ellipse and Filled ellipse, plus Crop. The colour swatches are there for a quick pick, and the full palette is one button away (Choose a colour). Thickness is counted in the picture's own pixels, so a line looks the same after you zoom out.

  • Hold Shift while dragging a shape to keep it a perfect square or circle.
  • Ctrl+Z or the Undo button takes back the last stroke.

Crop by frame, then confirm

Choose Crop and drag a frame; its corners and sides can be pulled, and the whole frame can be moved. Press Enter or Apply crop to cut, or Esc to drop the frame and keep the picture whole. The crop is a normal step in the history - undo takes it back like any stroke.

Saving over the original cannot be undone

Save replaces the file you opened, and the old version is not kept anywhere - not even in the Recycle Bin. A JPEG is also re-compressed when it is written, which is irreversible, so the editor asks once per session before it does (the Do not ask for confirmation setting on the Files page silences that question). To keep the original, use Save as.. instead.

Save over the original, or as a new file

Save replaces the file you opened; the write goes to a temporary file first and only then swaps in, so a failure can never leave half a photo. Save as.. writes a new file and is offered whenever replacing is impossible - a read-only file, a format that cannot be written, or a file another program is holding. The status line says which of those it is instead of just refusing.

Know what happens to the file

PNG, JPEG, BMP, TIFF and WEBP can be written. The date the photo was taken and the rest of the EXIF data are carried over where the format can hold them, together with the colour profile, XMP and IPTC data, with three corrections: the small preview thumbnail embedded in the EXIF is dropped (it would keep showing the picture as it was before the edit), the stored pixel size is rewritten to the new size, and the orientation tag is made to match the pixels actually written. If the original's metadata cannot be read, the picture is still saved, without it. GIF, ICO and a few others are deliberately read-only here, and Save as.. in another format is the way out.

The editor works on the original

It reads the file's own bytes rather than what is on screen, so a rotation you did with R in the viewer is not baked in and a WEBP is not quietly turned into something else. What you save is the picture you opened, plus your edits.

64-bit program only

The editor ships in the modern 64-bit build for Windows 10 and 11. The 32-bit fallback for Windows 7 and 8.1 remains a viewer and sorter; it does not write pixels back to disk.
