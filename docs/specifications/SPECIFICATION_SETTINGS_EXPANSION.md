# Спецификация: расширенные настройки Fast Media Sorter

**Статус:** проект для реализации.  
**Цель:** добавить перечисленные настройки в .NET 10-окно без потери текущих
профилей и без превращения формы в длинный список редко используемых флажков.

## 1. Общие правила

- Все параметры хранятся в существующем профиле пользователя
  `HKCU\Software\VB and VBA Program Settings\SZA\FastMediaSorter`.
- Изменение применяется сразу, если не помечено как «при следующем запуске».
- Для каждой логической настройки в современном окне: checkbox слева, название
  сразу за ним, короткое пояснение ниже. Выбор/число располагается рядом с
  названием, а не у правого края карточки.
- Независимые короткие параметры на широком окне располагаются в две колонки.
- Новые ключи имеют безопасные defaults и не требуют миграции старого профиля.
- «Программа» далее означает Fast Media Sorter Lite; «следующий файл» — файл из
  текущей выборки с учётом фильтра и порядка сортировки.

## 2. Карта разделов окна

| Раздел | Новые настройки |
|---|---|
| Файлы | Совпадение имён, действие после Copy/Move, вложенные папки, типы файлов, горячие клавиши |
| Просмотр | Масштаб интерфейса, масштаб нового изображения, уменьшение анимации, таблица получателей |
| Слайд-шоу | Порядок случайности, ручная навигация, скрываемые элементы UI |
| Видео | Автозапуск, запоминание позиции, панель управления, одиночный клик, окончание, языки дорожек |
| Общие и данные | Поведение при запуске, предел OCR-кэша, размер истории, экспорт/импорт |

## 3. Файлы и сортировка

### 3.1. Совпадение имён при Copy/Move

**Настройка:** «Если файл с таким именем уже есть в папке-получателе». Это
уточняет неоднозначный пункт «Совпадение имён».

| Значение | Поведение |
|---|---|
| `Ask` — default | Диалог с именем, размером и датой обоих файлов; действия «Заменить», «Пропустить», «Сохранить оба», «Отмена». |
| `Skip` | Операция для данного файла завершается как пропуск, исходник не меняется. |
| `Rename` | Создаётся имя `name (2).ext`, затем `(3)` и т. д.; исходник не перезаписывается. |
| `Replace` | Целевой файл заменяется атомарно настолько, насколько позволяет файловая система. До действия показывается предупреждение при первом использовании. |

- Ключ: `NameCollisionPolicy`; значения: `ask`, `skip`, `rename`, `replace`.
- При пакетной операции выбор «Для всех» действует только в рамках данной очереди.
- Для `Move` исходник удаляется только после успешного помещения целевого файла.

### 3.2. После копирования или перемещения

**Настройка:** «После успешной операции с файлом».

| Значение | Поведение |
|---|---|
| `Next` — default | Показать следующий доступный файл. |
| `Stay` | Оставить текущий файл открытым; для Move показать короткое сообщение, что файл уже перенесён. |
| `CloseIfEmpty` | Как `Next`; если выборка пуста, очистить просмотрщик. |

- Ключ: `AfterFileOperation`; `next`, `stay`, `closeIfEmpty`.
- Ошибка, отмена или пропуск никогда не запускают автоматическую навигацию.

### 3.3. Просмотр вложенных папок

**Настройка:** «Включать вложенные папки».

- Checkbox, default `false`, ключ `IncludeSubfolders`.
- При включении сканируются все подпапки выбранной папки; симлинки/точки
  повторной обработки не обходятся, чтобы не возникали циклы и выход за пределы
  выбранного дерева.
- В статусе показываются число папок и файлов. Отмена сканирования оставляет
  предыдущую успешную выборку.

### 3.4. Типы файлов

**Настройка:** «Показывать типы файлов» — компактная строка с кнопкой
«Настроить…», открывающей диалог с группами «Изображения», «Видео», «Аудио» и
«Другие поддерживаемые».

- Включённые по умолчанию — все форматы, которые приложение уже умеет открыть.
- Пользователь может отключить целую группу или отдельное расширение;
  расширения нормализуются как lowercase с точкой (`.jpg`).
- Ключ: `IncludedExtensions`, JSON-массив. Пустой массив означает «все
  поддерживаемые», а не «ничего».
- Фильтр применяется при следующем сканировании папки и к вложенным папкам.

### 3.5. Настраиваемые горячие клавиши

**Настройка:** «Сочетания клавиш» с отдельным компактным диалогом, а не длинной
таблицей на основной странице.

- Таблица: действие, сочетание, «Сбросить». Захват комбинации происходит в
  отдельном поле; `Esc` отменяет запись.
- Нельзя назначить одно сочетание двум активным действиям. Конфликт показывает
  действие-владельца и предлагает обменять/очистить назначение.
- Не переназначаются системные и оконные сочетания: `Alt+F4`, `Alt+Tab`,
  `Ctrl+Alt+Del`, `Win+*`; `F11` и `Esc` остаются резервными для полноэкранного
  режима и выхода.
- Ключ: `CustomHotkeys`, JSON-объект `{ actionId: "Ctrl+Shift+…" }`.
- Номера папок-получателей `0…9` остаются отдельными действиями и сохраняют
  существующее сопоставление `0 -> MoveOn0`.

## 4. Просмотр и доступность

### 4.1. Масштаб интерфейса

Выбор: `Системный` (default), `90 %`, `100 %`, `110 %`, `125 %`, `150 %`.

- Ключ: `InterfaceScalePercent`, `0` для системного масштаба.
- Настройка меняет базовый шрифт и метрики современного интерфейса; применяется
  после подтверждения «Перезапустить окно настроек» и без bitmap-масштабирования.
- Не заменяет DPI Windows и не влияет на размер изображения.

### 4.2. Масштаб нового изображения

| Значение | Поведение |
|---|---|
| `Fit` — default | Вписать новое изображение в область просмотра. |
| `ActualSize` | Открыть в 100 %. |
| `RememberPerFolder` | Восстанавливать последний масштаб для текущей папки; если записи нет — Fit. |

- Ключ: `NewImageScaleMode`; значения `fit`, `actual`, `perFolder`.
- Папочные значения хранятся в ограниченном LRU-списке из 50 записей
  `FolderZoomHistory` и не влияют на ручной zoom уже открытого файла.

### 4.3. Уменьшение анимации

Checkbox «Уменьшать анимацию», default `false`, ключ `ReduceMotion`.

- При включении: без анимации перспективного ореола, fade панели видео и
  плавных переходов; результат и раскладка остаются теми же.
- Если Windows сообщает `ClientAreaAnimation = false`, настройка считается
  включённой на время сессии без перезаписи пользовательского выбора.

### 4.4. Таблица получателей поверх медиа

Существующий checkbox показа дополняется раскрываемой строкой «Вид таблицы»:

| Параметр | Диапазон / default | Ключ |
|---|---|---|
| Положение | верхний левый (default), верхний правый, нижний левый, нижний правый | `RecipientsOverlayPosition` |
| Ширина | 180…520 px, default 280 | `RecipientsOverlayWidth` |
| Размер текста | 9…18 pt, default 11 | `RecipientsOverlayFontSize` |
| Непрозрачность | 40…100 %, default 88 | `RecipientsOverlayOpacity` |
| Видимые строки | 3…11, default 10 | `RecipientsOverlayVisibleRows` |

- Нельзя вывести панель за границы медиа: положение и размер ограничиваются
  областью просмотра; маленькое окно временно сужает панель.
- Изменения применяются к уже показанной панели сразу. Полный список остаётся
  доступен прокруткой, если видимых строк меньше 11.

## 5. Слайд-шоу

### 5.1. Порядок случайности

Выбор `SlideshowRandomOrder`:

| Значение | Поведение |
|---|---|
| `Natural` — default | Обычный порядок файлов; «случайность» отключена. |
| `Random` | Каждый переход выбирает случайный файл, повторы допустимы. |
| `ShuffleCycle` | Формируется перемешанный цикл без повторов; после показа всех файлов создаётся новый цикл. Текущий файл не выбирается первым в новом цикле, если файлов больше одного. |

- Смена выбора во время активного слайд-шоу начинает новый порядок со следующего
  перехода. Добавление/удаление файлов пересоздаёт цикл безопасно.

### 5.2. Ручная навигация и интерфейс

| Настройка | Default | Ключ | Поведение |
|---|---:|---|---|
| Останавливать слайд-шоу при ручной навигации | Да | `StopSlideshowOnManualNavigation` | Любая ручная следующая/предыдущая, выбор файла, колесо или hotkey останавливают таймер. |
| Скрывать интерфейс во время слайд-шоу | Нет | `SlideshowUiMode` | `none`, `toolbar`, `toolbarAndStatus`; движение мыши или клавиша временно показывает скрытое. |

- Контекстные меню и критические уведомления не скрываются. Выход из слайд-шоу
  восстанавливает интерфейс сразу.

## 6. Видео

### 6.1. Воспроизведение и завершение

| Настройка | Значения / default | Ключ |
|---|---|---|
| Автоматически запускать видео | Да | `VideoAutoplay` |
| Запоминать позицию просмотра | Да | `RememberVideoPosition` |
| Действие одиночного клика | `pauseResume` (default), `nextFile` | `VideoSingleClickAction` |
| После окончания видео | `stay` (default), `nextFile`, `repeat` | `VideoEndAction` |

- Позиция сохраняется по абсолютному пути, времени изменения и размеру файла;
  изменившийся файл начинается с начала. Лимит истории — 200 записей LRU,
  `VideoPositionHistory`.
- Если пользователь выбрал «После окончания: повторить», эта настройка имеет
  приоритет над общим checkbox «Повторять видео» только для этого события;
  checkbox остаётся устаревшим синонимом `VideoEndAction=repeat` и при миграции
  преобразуется в него.
- `nextFile` во время слайд-шоу делегирует выбор текущему порядку слайд-шоу.

### 6.2. Панель управления

| Настройка | Диапазон / default | Ключ |
|---|---|---|
| Задержка скрытия панели | 1…15 с, default 3 с | `VideoControlsHideDelaySec` |
| Всегда показывать при паузе | Да | `ShowVideoControlsWhenPaused` |

- Задержка отсчитывается после движения мыши вне панели и после начала
  воспроизведения. Наведение на панель или drag ползунка её не скрывают.
- При паузе панель остаётся видимой независимо от таймера, если включён default.

### 6.3. Предпочтительные языки дорожек

Два выпадающих списка: «Язык звука» и «Язык субтитров»: `Не выбирать`
(default), системный язык, любой язык из поддерживаемого каталога; для субтитров
есть дополнительное `Всегда выключены`.

- Ключи: `PreferredAudioLanguage`, `PreferredSubtitleLanguage`;
  значение `::off::` используется только для субтитров.
- Выбор применяется при старте каждого видео, если соответствующая дорожка есть;
  иначе LibVLC оставляет собственный выбор. Ручной выбор из меню «Дорожки»
  обновляет предпочтение.

## 7. Запуск, история и данные

### 7.1. Запуск программы

**Настройка:** «При запуске открывать»:

| Значение | Default | Поведение |
|---|---:|---|
| Стартовую страницу | Да | Без папки и файла; текущее нейтральное поведение. |
| Последнюю папку | Нет | Открыть последнюю существующую папку, без автоматического выбора файла. |
| Последний файл | Нет | Открыть последний существующий файл и его папку. |

- Ключ: `StartupOpenMode`; `home`, `lastFolder`, `lastFile`.
- Несуществующий путь тихо пропускается с понятным статусом; приложение не
  задерживает старт сетевым сканированием.

### 7.2. История

| Параметр | Диапазон / default | Ключ |
|---|---|---|
| Недавние файлы | 0…200, default 50 | `RecentFilesLimit` |
| Недавние папки | 0…200, default 100 | `RecentFoldersLimit` |

- В настройках есть строка «Недавние файлы и папки» с кнопкой «Открыть историю».
  Диалог позволяет открыть запись, удалить одну или очистить историю.
- При уменьшении лимита старые записи удаляются немедленно. Пустой/несуществующий
  путь удаляется при следующем чтении или открытии истории.

### 7.3. Максимальный размер дискового OCR-кэша

Выбор: `100 МБ`, `250 МБ` (default), `500 МБ`, `1 ГБ`, `Без ограничения`.

- Ключ: `OcrDiskCacheMaxMb`, `0` для без ограничения.
- После записи в кэш применяется LRU-очистка до лимита; активный файл и
  выполняющаяся запись не удаляются. Отключённый дисковый кэш ничего не пишет.
- В строке показываются текущий размер и действие «Очистить кэш» с подтверждением.

### 7.4. Экспорт и импорт настроек

- В разделе «О программе»/«Данные» — две кнопки: «Экспортировать настройки» и
  «Импортировать настройки».
- Формат: читаемый UTF-8 JSON с `schemaVersion`, именами ключей и значениями;
  расширение `.fms-settings.json`.
- Экспорт **не включает API-ключи, пароли SFTP, историю файлов и позиции видео**.
  Для них отдельный явно опасный checkbox «Включить личные данные» с
  предупреждением; секреты остаются DPAPI-защищёнными и импортируются только на
  том же пользователе Windows.
- Импорт сначала валидирует схему и показывает сводку изменений. Пользователь
  выбирает «Заменить» или «Объединить»; вторая опция не стирает неизвестные
  локальные ключи. До записи создаётся backup текущего профиля в JSON.
- После импорта немедленно применяются безопасные UI-параметры; параметры запуска
  и масштаб интерфейса помечаются как требующие перезапуска окна/программы.

## 8. Обязательные проверки

1. Collision policy ни при каком исходе не удаляет источник Move до успешного
   создания целевого файла.
2. Сканирование подпапок не зацикливается на junction/symlink и корректно
   отменяется.
3. Shuffle cycle показывает каждый файл ровно один раз до следующего цикла.
4. Ручная навигация останавливает слайд-шоу только при включённой настройке.
5. Панель получателей не выходит за границы области медиа при любом DPI и размере
   окна.
6. Пауза видео удерживает controls на экране по default; выход к изображению
   скрывает video-only controls, включая «Дорожки».
7. Запомненная видеопозиция не применяется к изменившемуся файлу.
8. Кэш не превышает выбранный предел после завершения записи (кроме временного
   размера активной записи), а «Очистить» не удаляет настройки OCR.
9. Экспорт без личных данных не содержит API-ключей, путей истории, SFTP-секретов
   или позиций просмотра.
10. Импорт некорректного/неподдерживаемого JSON не меняет текущий профиль.

## 9. Вне объёма этой спецификации

- Распознавание визуальных дубликатов или анализ содержимого файлов.
- Синхронизация профиля через облако.
- Изменение существующего протокола Android/SFTP.
- Переработка движка OCR или добавление другого OCR-движка.
