Privacy Policy

Last updated: 6 October 2026

Fast Media Sorter & Sharing for Windows collects no personal data. It has no user accounts, no advertising, and no telemetry or analytics. It runs entirely on your own device, and the developer receives no data about you or your use of the app - unless you choose to send your logs yourself (see Diagnostic logs) - honestly, we wouldn't know what to do with it anyway.

What the app accesses, and why

  • Your media files. The app reads, displays, copies, moves, renames and deletes the image and video files in the folders you open - that is its core purpose. It only ever touches files and folders you point it at (including network shares you browse to). It has seen your meme folder and judged nothing.
  • Servers and network shares you add yourself. A folder on an SFTP server, or a network share that needs a login, is opened only after you add it (by hand, or by importing the file the Share Manager makes). The app then opens a direct, outbound connection to the address you gave it and to nothing else - it never listens for connections for this and never contacts the developer. Three small things are kept on your PC, in your Windows account: the server's address and user name, the server's SSH key fingerprint (so a server pretending to be yours is refused), and the password, encrypted with Windows (DPAPI) so it can be read only by you on this PC. If you untick "Remember", the password is held in memory until the program closes and is never written anywhere. Files you open from a server are copied into a private cache folder that is deleted when you leave the resource or close the program. Passwords are never included in the logs package you may choose to send.
  • Folder sharing - optional, opt-in. If you enable it, the bundled Share Manager companion runs a local SFTP server so your own phone can browse the folders you choose. The access password and the server host key are generated and kept only on your PC, and files are served directly between your own devices - never through us or any third party. While a share is on, any device on your current network (home, office, or a public Wi-Fi) can reach the PC on the share port; access needs the password embedded in the QR/config you share, so treat that code as a key and do not post it publicly. A LAN only switch keeps the share off the internet; idle connections close after a few hours, and you can cap how many devices connect at once. If you turn on internet access, the app asks the public service check-host.net to confirm your forwarded port is reachable, which reveals your public address and port to that service for the check. With internet access on, the app also asks your own router to forward the share port (UPnP or NAT-PMP), and while a share runs the PC announces itself on your local network (mDNS) so a paired phone can find it again when its address changes; neither of those leaves your network. The app keeps local-only connection counters (this is not telemetry and never leaves your PC).
  • FileDO disks - optional, opt-in. If you connect a .fdd container for sharing, the server mounts it on this PC and publishes its contents to authorized SFTP clients. A selected Windows drive letter is a local alias for the current signed-in session; it does not create an SMB share. An encrypted disk is unlocked on the PC. Its password is sent only to the verified local worker and FileDO, never in command arguments or logs. Disk autostart is a separate choice: only after explicit consent is its credential stored in protected Windows storage on this PC. Disabling autostart or removing the disk from sharing deletes that stored key. Mounting requires administrator rights; enabling ordinary folder sharing does not silently elevate the server or change a service account. See the FileDO disk sharing guide.
  • Always-on sharing - a Windows service, only if you ask for it. It comes either from the separate Server edition download or from the Share Manager's own "Switch sharing to a Windows service.." (Manager settings → Hosting); it is never installed by default, and either way Windows asks for administrator approval first. The same folder sharing is then hosted by a Windows service instead of by your signed-in session, so the folders you chose stay reachable from boot even when nobody is logged on. Nothing about what is collected changes - there is still no telemetry, and files still go straight between your own devices - but the exposure window does: the share is up whenever the machine is, not only while you are using it. The service runs as LOCAL SERVICE, which is given read access to each folder you share (and write access only where you allowed writing) and nothing else. Its host key, password and settings live in a machine folder, %ProgramData%\FastMediaSorterCompanion, that only administrators, the service and your account can open. "Remove the server role" in the Share Manager, or uninstalling the Server edition, stops and removes the service, takes back those folder permissions and removes the firewall rule; uninstalling the ordinary edition offers to do the same for a service its Share Manager set up (a silent uninstall, such as winget uninstall, cannot ask and leaves it in place). The host key is kept unless you delete that folder, so your paired phones still work if you reinstall.
  • Network - only when you use a feature that needs it. The on-image translation feature is off until you enable and configure it. When you use it, the app sends the recognized text to the translation endpoint you choose - a local Ollama model on your own machine, or a LibreTranslate server you specify - to receive the translated text. OCR (text recognition) runs fully offline. Apart from that, the app makes no network requests except to fetch an optional component you ask for: additional OCR language packs from the public Tesseract data repository; the OCR and video playback runtimes from nuget.org, when a build did not bring them along; FFmpeg - the video encoder behind "Replace with video" - from its published Windows builds; the Ollama installer from ollama.com, and translation models through your own Ollama, when you press the button for them; and doc-html-translate through winget, when you press its install button. Each happens only after you press that button or say yes to a prompt that names what is being fetched; nothing about your files, your paths or your usage is sent with any of them. If a runtime needs the Microsoft Visual C++ Redistributable and it is missing, the app says so and can open Microsoft's download in your browser - it never downloads or runs that installer itself.
  • API keys (if you set one). If a translation provider you configure needs an API key, it is stored encrypted on your device using Windows DPAPI and is sent only to that provider's endpoint when translating.

Local files the app writes

  • Settings. Preferences and hotkeys are stored in the Windows registry (in the Microsoft Store build these live inside the app's package container).
  • Settings import backups (64-bit program). Before importing a profile, the app saves your current preferences, including folder histories and playback positions, in a protected folder under %LOCALAPPDATA%\SZA\FastMediaSorter\settings-backups (inside the app's local data root in the Microsoft Store build). These local rollback copies exclude passwords and API keys. The import stops if a private backup cannot be created; nothing is saved beside the imported file or in a shared temporary folder. Backups are not deleted automatically. You can restore one through Settings → Import settings, or delete old copies yourself when you no longer need them.
  • OCR data and caches. Downloaded Tesseract language packs, a downloaded copy of FFmpeg, the translation cache and the decode cache (decoded copies of the WEBP, AVIF and HEIC files you have opened, kept so the second view is instant) are stored under %LOCALAPPDATA%\SZA\FastMediaSorter. These never leave your device, and both caches can be emptied or switched off in Settings.

Data sharing

None with the developer - the kind of "none" that is actually none, and no telemetry or analytics ever. The only things that leave your device do so at your explicit choice and go where you direct them, not to us: the text you translate goes to the translation endpoint you configured; shared files go directly to your own phone over SFTP; if you enable internet access, your public address and port are shown to check-host.net solely to test reachability; and the log archive reaches the developer only if you send it yourself from your own mail program.

This website

The program itself contacts none of the addresses below. They belong to the product website - the home page, the guides and the install-trust page - and your browser contacts them when it opens those pages. This privacy page loads nothing from any of them. No analytics, tag-manager or advertising address is contacted by any page of the site.

  • fonts.googleapis.com and fonts.gstatic.com (Google Fonts) - the stylesheet and the two font files of the site's lettering, loaded on the pages that use it. They receive your IP address and your browser's user agent, as any web server does; nothing else is sent.
  • api.github.com (GitHub) - one request on the home page and its twelve language pages, asking for the latest release so that the download link points at it. It receives your IP address and your browser's user agent; nothing else is sent.

Diagnostic logs

The app writes a plain-text log of its own work next to the program (or, when that folder is not writable, under your local application data). It never leaves your device on its own. Settings → About has a "Send the logs to the author" button: it packs those logs and a report of your version, Windows details and settings into an archive, shows you what went in, and opens a new message in your own mail program with the archive attached. Nothing is transmitted until you send that message yourself, and you can open the archive and inspect it first. The logs contain the paths and names of the files you opened; your translation API key is never included.

Children's privacy

The app collects no data from anyone, including children.

Open source

Fast Media Sorter & Sharing for Windows is open source - you can review exactly what it does, no hidden surprises, at github.com/SerZhyAle/FastMediaSorter_Lite.

Политика конфиденциальности

Последнее обновление: 6 октября 2026 г.

Fast Media Sorter & Sharing for Windows не собирает персональные данные. В нём нет учётных записей, рекламы, телеметрии и аналитики. Программа работает целиком на вашем устройстве, и разработчик не получает никаких данных ни о вас, ни о том, как вы пользуетесь программой - если только вы сами не решите отправить свои логи (см. Диагностические логи) - честно говоря, мы бы всё равно не знали, что с ними делать.

К чему обращается программа и зачем

  • Ваши медиафайлы. Программа читает, показывает, копирует, перемещает, переименовывает и удаляет файлы изображений и видео в открытых вами папках - в этом её главное назначение. Она трогает только те файлы и папки, на которые вы ей указали (включая сетевые папки, которые вы открываете). Она видела вашу папку с мемами и ни в чём вас не осудила.
  • Серверы и сетевые папки, которые вы добавляете сами. Папка на SFTP-сервере или сетевая папка, требующая вход, открывается только после того, как вы её добавите (вручную или импортом файла, который создаёт Менеджер общего доступа). После этого программа открывает прямое исходящее соединение с адресом, который вы указали, и больше ни с чем - она никогда не принимает для этого входящие соединения и никогда не связывается с разработчиком. На вашем ПК, в вашей учётной записи Windows, хранятся три небольшие вещи: адрес сервера и имя пользователя, отпечаток SSH-ключа сервера (чтобы сервер, выдающий себя за ваш, был отклонён) и пароль, зашифрованный средствами Windows (DPAPI), так что прочитать его можете только вы на этом ПК. Если снять флажок "Запомнить пароль (защищён средствами Windows)", пароль хранится в памяти до закрытия программы и нигде не записывается. Файлы, которые вы открываете с сервера, копируются в закрытую папку кэша, которая удаляется, когда вы выходите из ресурса или закрываете программу. Пароли никогда не попадают в пакет логов, который вы можете решить отправить.
  • Общий доступ к папкам - по желанию, только по вашему согласию. Если вы его включите, встроенный Менеджер общего доступа запускает локальный SFTP-сервер, чтобы ваш собственный телефон мог просматривать выбранные вами папки. Пароль доступа и ключ хоста сервера создаются и хранятся только на вашем ПК, а файлы передаются напрямую между вашими устройствами - никогда не через нас и не через третьих лиц. Пока общий доступ включён, любое устройство в вашей текущей сети (домашней, офисной или общественного Wi-Fi) может обратиться к ПК на порт общего доступа; для доступа нужен пароль, встроенный в QR-код или конфигурацию, которыми вы делитесь, поэтому относитесь к этому коду как к ключу и не публикуйте его. Переключатель Только локальная сеть не выпускает общий доступ в интернет; неактивные соединения закрываются через несколько часов, а число одновременно подключённых устройств можно ограничить. Если вы включите доступ из интернета, программа обращается к публичному сервису check-host.net, чтобы проверить, что ваш проброшенный порт доступен, и на время проверки этот сервис узнаёт ваш публичный адрес и порт. При включённом доступе из интернета программа также просит ваш собственный роутер пробросить порт общего доступа (UPnP или NAT-PMP), а пока общий доступ работает, ПК объявляет о себе в локальной сети (mDNS), чтобы сопряжённый телефон мог найти его снова, когда адрес изменится; ни то, ни другое не выходит за пределы вашей сети. Программа ведёт только локальные счётчики соединений (это не телеметрия, и они никогда не покидают ваш ПК).
  • Диски FileDO - по желанию, только по вашему согласию. Если вы подключаете контейнер .fdd для общего доступа, сервер монтирует его на этом ПК и публикует его содержимое для авторизованных SFTP-клиентов. Выбранная буква диска Windows - это локальный псевдоним для текущего сеанса вашего входа; SMB-ресурс при этом не создаётся. Зашифрованный диск разблокируется на ПК. Его пароль передаётся только проверенному локальному обработчику и FileDO, но не в аргументах команд и не в логах. Автозапуск диска - отдельный выбор: только после явного согласия его учётные данные сохраняются в защищённом хранилище Windows на этом ПК. Отключение автозапуска или удаление диска из общего доступа удаляет этот сохранённый ключ. Для монтирования нужны права администратора; включение обычного общего доступа к папкам не повышает права сервера втихую и не меняет учётную запись службы. См. руководство по общему доступу к дискам FileDO.
  • Всегда включённый общий доступ - служба Windows, только если вы сами об этом попросите. Она появляется либо из отдельной загрузки Серверной редакции, либо из пункта Менеджера общего доступа «Перевести раздачу в режим службы Windows..» (Настройки менеджера → Хостинг); по умолчанию она не устанавливается никогда, и в любом случае Windows сначала запрашивает подтверждение администратора. Тот же общий доступ к папкам тогда обслуживается службой Windows, а не вашим сеансом входа, поэтому выбранные вами папки остаются доступны с момента загрузки, даже когда в системе никто не вошёл. То, что собирается, не меняется - по-прежнему никакой телеметрии, и файлы по-прежнему идут напрямую между вашими устройствами - но меняется окно уязвимости: общий доступ работает всё то время, пока включён компьютер, а не только пока вы им пользуетесь. Служба работает от имени LOCAL SERVICE, которой выдаётся доступ на чтение к каждой папке, которой вы делитесь (и доступ на запись только там, где вы разрешили запись), и больше ничего. Её ключ хоста, пароль и настройки хранятся в системной папке %ProgramData%\FastMediaSorterCompanion, которую могут открыть только администраторы, служба и ваша учётная запись. Пункт «Удалить роль сервера» в Менеджере общего доступа или удаление Серверной редакции останавливает и удаляет службу, возвращает эти разрешения на папки и удаляет правило брандмауэра; удаление обычной редакции предлагает сделать то же самое для службы, которую настроил её Менеджер общего доступа (тихое удаление, например winget uninstall, не может спросить и оставляет службу на месте). Ключ хоста сохраняется, если вы не удалите эту папку, так что ваши сопряжённые телефоны продолжат работать, если вы переустановите программу.
  • Сеть - только когда вы используете функцию, которой она нужна. Функция перевода текста на картинке выключена, пока вы её не включите и не настроите. Когда вы ею пользуетесь, программа отправляет распознанный текст на конечную точку перевода, которую выбираете вы - локальная модель Ollama на вашем собственном компьютере или указанный вами сервер LibreTranslate - и получает переведённый текст. OCR (распознавание текста) работает полностью офлайн. Кроме этого, программа не выполняет сетевых запросов, кроме загрузки необязательного компонента, который вы запросили: дополнительные языковые пакеты OCR из публичного репозитория данных Tesseract; среды выполнения OCR и воспроизведения видео с nuget.org, если сборка не принесла их с собой; FFmpeg - видеокодировщик, на котором работает «Заменить видео» - из его опубликованных сборок для Windows; установщик Ollama с ollama.com и модели перевода через ваш собственный Ollama, когда вы нажимаете соответствующую кнопку; и doc-html-translate через winget, когда вы нажимаете кнопку его установки. Каждая такая загрузка происходит только после того, как вы нажмёте эту кнопку или ответите «да» на запрос, в котором названо, что именно загружается; вместе с любой из них ничего о ваших файлах, ваших путях или о том, как вы пользуетесь программой, не отправляется. Если для среды выполнения нужен Microsoft Visual C++ Redistributable, а его нет, программа сообщит об этом и может открыть загрузку Microsoft в вашем браузере - сам этот установщик она никогда не скачивает и не запускает.
  • Ключ API (если вы его задаёте). Если настроенному вами провайдеру перевода нужен ключ API, он хранится на вашем устройстве в зашифрованном виде с помощью Windows DPAPI и отправляется только на конечную точку этого провайдера при переводе.

Локальные файлы, которые записывает программа

  • Настройки. Предпочтения и горячие клавиши хранятся в реестре Windows (в сборке из Microsoft Store они находятся внутри контейнера пакета приложения).
  • Резервные копии при импорте настроек (64-разрядная программа). Перед импортом профиля программа сохраняет ваши текущие предпочтения, включая историю папок и позиции воспроизведения, в защищённую папку в %LOCALAPPDATA%\SZA\FastMediaSorter\settings-backups (в сборке из Microsoft Store - внутри корня локальных данных приложения). Эти локальные копии для отката не содержат паролей и ключей API. Импорт прекращается, если не удаётся создать закрытую резервную копию; ничего не сохраняется рядом с импортируемым файлом или в общей временной папке. Резервные копии не удаляются автоматически. Вы можете восстановить одну из них через Настройки → Импорт настроек или удалить старые копии сами, когда они перестанут быть нужны.
  • Данные и кэши OCR. Загруженные языковые пакеты Tesseract, загруженная копия FFmpeg, кэш переводов и кэш декодирования (декодированные копии открывавшихся вами файлов WEBP, AVIF и HEIC, которые хранятся, чтобы второй просмотр был мгновенным) находятся в %LOCALAPPDATA%\SZA\FastMediaSorter. Они никогда не покидают ваше устройство, а оба кэша можно очистить или отключить в Настройках.

Передача данных

Разработчику - ничего, причём такое «ничего», которое действительно ничего, и никакой телеметрии или аналитики никогда. Единственное, что покидает ваше устройство, делает это по вашему явному выбору и идёт туда, куда вы укажете, а не к нам: переводимый вами текст уходит на настроенную вами конечную точку перевода; общие файлы идут напрямую на ваш собственный телефон по SFTP; если вы включаете доступ из интернета, ваш публичный адрес и порт показываются check-host.net исключительно для проверки доступности; а архив логов попадает к разработчику, только если вы сами отправите его из своей почтовой программы.

Этот сайт

Сама программа не обращается ни к одному из адресов ниже. Они относятся к сайту продукта - главной странице, руководствам и странице доверия к установке - и ваш браузер обращается к ним, когда открывает эти страницы. Эта страница политики ничего из них не загружает. Ни одна страница сайта не обращается к адресам аналитики, менеджера тегов или рекламы.

  • fonts.googleapis.com и fonts.gstatic.com (Google Fonts) - таблица стилей и два файла шрифтов для начертания сайта; загружаются на страницах, которые его используют. Они получают ваш IP-адрес и user agent вашего браузера, как любой веб-сервер; больше ничего не передаётся.
  • api.github.com (GitHub) - один запрос на главной странице и её двенадцати языковых страницах: он спрашивает последний выпуск, чтобы ссылка для скачивания вела на него. Получает ваш IP-адрес и user agent вашего браузера; больше ничего не передаётся.

Диагностические логи

Программа ведёт текстовый журнал своей работы рядом с программой (или, если эта папка недоступна для записи, в локальных данных вашего приложения). Сам по себе он никогда не покидает ваше устройство. В Настройки → О программе есть кнопка «Отправить логи автору»: она упаковывает эти логи и отчёт о вашей версии, сведениях о Windows и настройках в архив, показывает вам, что туда попало, и открывает новое письмо в вашей собственной почтовой программе с приложенным архивом. Ничего не передаётся, пока вы не отправите это письмо сами, а архив можно открыть и проверить заранее. В логах есть пути и имена открывавшихся вами файлов; ключ API вашего перевода в них никогда не включается.

Конфиденциальность детей

Політика конфіденційності

Останнє оновлення: 6 жовтня 2026 р.

Fast Media Sorter & Sharing for Windows не збирає персональних даних. У ній немає облікових записів, реклами, телеметрії та аналітики. Програма працює цілком на вашому пристрої, і розробник не отримує жодних даних ні про вас, ні про те, як ви користуєтеся програмою - хіба що ви самі вирішите надіслати свої журнали (див. Діагностичні журнали) - чесно кажучи, ми б усе одно не знали, що з ними робити.

До чого звертається програма і навіщо

  • Ваші медіафайли. Програма читає, показує, копіює, переміщує, перейменовує та видаляє файли зображень і відео у відкритих вами теках - у цьому її головне призначення. Вона торкається лише тих файлів і тек, на які ви їй вказали (зокрема мережевих тек, які ви відкриваєте). Вона бачила вашу теку з мемами і нікого не засудила.
  • Сервери та мережеві теки, які ви додаєте самі. Тека на SFTP-сервері або мережева тека, що потребує входу, відкривається лише після того, як ви її додасте (вручну або імпортом файлу, який створює Менеджер спільного доступу). Після цього програма відкриває пряме вихідне з'єднання з адресою, яку ви вказали, і більше ні з чим - вона ніколи не приймає для цього вхідних з'єднань і ніколи не зв'язується з розробником. На вашому ПК, у вашому обліковому записі Windows, зберігаються три невеликі речі: адреса сервера та ім'я користувача, відбиток SSH-ключа сервера (щоб сервер, який видає себе за ваш, було відхилено) і пароль, зашифрований засобами Windows (DPAPI), тож прочитати його можете лише ви на цьому ПК. Якщо зняти прапорець "Запам'ятати пароль (захищено засобами Windows)", пароль зберігається в пам'яті до закриття програми і ніде не записується. Файли, які ви відкриваєте із сервера, копіюються до закритої теки кешу, яку видаляють, коли ви виходите з ресурсу або закриваєте програму. Паролі ніколи не потрапляють до пакета журналів, який ви можете вирішити надіслати.
  • Спільний доступ до тек - за бажанням, лише за вашою згодою. Якщо ви його ввімкнете, вбудований Менеджер спільного доступу запускає локальний SFTP-сервер, щоб ваш власний телефон міг переглядати обрані вами теки. Пароль доступу та ключ хоста сервера створюються і зберігаються лише на вашому ПК, а файли передаються напряму між вашими пристроями - ніколи не через нас і не через третіх осіб. Поки спільний доступ увімкнено, будь-який пристрій у вашій поточній мережі (домашній, офісній чи громадському Wi-Fi) може звернутися до ПК на порт спільного доступу; для доступу потрібен пароль, вбудований у QR-код або конфігурацію, якими ви ділитеся, тож ставтеся до цього коду як до ключа і не публікуйте його. Перемикач Лише локальна мережа не випускає спільний доступ в інтернет; неактивні з'єднання закриваються за кілька годин, а кількість одночасно підключених пристроїв можна обмежити. Якщо ви ввімкнете доступ з інтернету, програма звертається до публічного сервісу check-host.net, щоб перевірити, що ваш прокинутий порт доступний, і на час перевірки цей сервіс дізнається вашу публічну адресу та порт. Коли доступ з інтернету ввімкнено, програма також просить ваш власний роутер прокинути порт спільного доступу (UPnP або NAT-PMP), а поки спільний доступ працює, ПК оголошує про себе в локальній мережі (mDNS), щоб сполучений телефон міг знайти його знову, коли адреса зміниться; ні те, ні інше не виходить за межі вашої мережі. Програма веде лише локальні лічильники з'єднань (це не телеметрія, і вони ніколи не залишають ваш ПК).
  • Диски FileDO - за бажанням, лише за вашою згодою. Якщо ви підключаєте контейнер .fdd для спільного доступу, сервер монтує його на цьому ПК і публікує його вміст для авторизованих SFTP-клієнтів. Вибрана літера диска Windows - це локальний псевдонім для поточного сеансу вашого входу; SMB-ресурс при цьому не створюється. Зашифрований диск розблоковується на ПК. Його пароль передається лише перевіреному локальному обробнику та FileDO, а не в аргументах команд і не в журналах. Автозапуск диска - окремий вибір: лише після явної згоди його облікові дані зберігаються в захищеному сховищі Windows на цьому ПК. Вимкнення автозапуску або вилучення диска зі спільного доступу видаляє цей збережений ключ. Для монтування потрібні права адміністратора; увімкнення звичайного спільного доступу до тек не підвищує права сервера нишком і не змінює обліковий запис служби. Див. посібник зі спільного доступу до дисків FileDO.
  • Завжди ввімкнений спільний доступ - служба Windows, лише якщо ви самі про це попросите. Вона з'являється або з окремого завантаження Серверної редакції, або з пункту Менеджера спільного доступу «Перевести роздачу в режим служби Windows..» (Налаштування менеджера → Хостинг); за замовчуванням вона не встановлюється ніколи, і в будь-якому разі Windows спершу запитує підтвердження адміністратора. Той самий спільний доступ до тек тоді обслуговується службою Windows, а не вашим сеансом входу, тож обрані вами теки залишаються доступними від моменту завантаження, навіть коли в системі ніхто не ввійшов. Те, що збирається, не змінюється - як і раніше жодної телеметрії, і файли, як і раніше, ідуть напряму між вашими пристроями - але змінюється вікно вразливості: спільний доступ працює весь час, поки ввімкнено комп'ютер, а не лише поки ви ним користуєтеся. Служба працює від імені LOCAL SERVICE, якій надається доступ на читання до кожної теки, якою ви ділитеся (і доступ на запис лише там, де ви дозволили запис), і більше нічого. Її ключ хоста, пароль і налаштування зберігаються в системній теці %ProgramData%\FastMediaSorterCompanion, яку можуть відкрити лише адміністратори, служба та ваш обліковий запис. Пункт «Видалити роль сервера» в Менеджері спільного доступу або видалення Серверної редакції зупиняє і видаляє службу, повертає ці дозволи на теки та видаляє правило брандмауера; видалення звичайної редакції пропонує зробити те саме для служби, яку налаштував її Менеджер спільного доступу (тихе видалення, наприклад winget uninstall, не може запитати і залишає службу на місці). Ключ хоста зберігається, якщо ви не видалите цю теку, тож ваші сполучені телефони й надалі працюватимуть, якщо ви перевстановите програму.
  • Мережа - лише коли ви користуєтеся функцією, якій вона потрібна. Функція перекладу тексту на зображенні вимкнена, поки ви її не ввімкнете й не налаштуєте. Коли ви нею користуєтеся, програма надсилає розпізнаний текст на кінцеву точку перекладу, яку обираєте ви - локальну модель Ollama на вашому власному комп'ютері або вказаний вами сервер LibreTranslate - і отримує перекладений текст. OCR (розпізнавання тексту) працює повністю офлайн. Окрім цього, програма не виконує мережевих запитів, окрім завантаження необов'язкового компонента, який ви запросили: додаткові мовні пакети OCR із публічного репозиторію даних Tesseract; середовища виконання OCR і відтворення відео з nuget.org, якщо збірка не принесла їх із собою; FFmpeg - відеокодувальник, на якому працює «Замінити відео» - з його опублікованих збірок для Windows; інсталятор Ollama з ollama.com і моделі перекладу через ваш власний Ollama, коли ви натискаєте відповідну кнопку; та doc-html-translate через winget, коли ви натискаєте кнопку його встановлення. Кожне таке завантаження відбувається лише після того, як ви натиснете цю кнопку або відповісте «так» на запит, у якому названо, що саме завантажується; разом із будь-яким із них нічого про ваші файли, ваші шляхи чи те, як ви користуєтеся програмою, не надсилається. Якщо для середовища виконання потрібен Microsoft Visual C++ Redistributable, а його немає, програма повідомить про це і може відкрити завантаження Microsoft у вашому браузері - сам цей інсталятор вона ніколи не завантажує і не запускає.
  • Ключ API (якщо ви його задаєте). Якщо налаштованому вами провайдеру перекладу потрібен ключ API, він зберігається на вашому пристрої в зашифрованому вигляді за допомогою Windows DPAPI і надсилається лише на кінцеву точку цього провайдера під час перекладу.

Локальні файли, які записує програма

  • Налаштування. Уподобання та гарячі клавіші зберігаються в реєстрі Windows (у збірці з Microsoft Store вони містяться всередині контейнера пакета застосунку).
  • Резервні копії під час імпорту налаштувань (64-розрядна програма). Перед імпортом профілю програма зберігає ваші поточні уподобання, зокрема історію тек і позиції відтворення, у захищену теку в %LOCALAPPDATA%\SZA\FastMediaSorter\settings-backups (у збірці з Microsoft Store - всередині кореня локальних даних застосунку). Ці локальні копії для відкоту не містять паролів і ключів API. Імпорт зупиняється, якщо не вдається створити закриту резервну копію; нічого не зберігається поруч з імпортованим файлом чи в спільній тимчасовій теці. Резервні копії не видаляються автоматично. Ви можете відновити одну з них через Налаштування → Імпорт налаштувань або видалити старі копії самі, коли вони перестануть бути потрібні.
  • Дані та кеші OCR. Завантажені мовні пакети Tesseract, завантажена копія FFmpeg, кеш перекладів і кеш декодування (декодовані копії відкритих вами файлів WEBP, AVIF і HEIC, які зберігаються, щоб другий перегляд був миттєвим) містяться в %LOCALAPPDATA%\SZA\FastMediaSorter. Вони ніколи не залишають ваш пристрій, а обидва кеші можна очистити або вимкнути в Налаштуваннях.

Передавання даних

Розробнику - нічого, причому таке «нічого», яке справді нічого, і жодної телеметрії чи аналітики ніколи. Єдине, що залишає ваш пристрій, робить це за вашим явним вибором і йде туди, куди ви вкажете, а не до нас: текст, який ви перекладаєте, іде на налаштовану вами кінцеву точку перекладу; спільні файли йдуть напряму на ваш власний телефон через SFTP; якщо ви вмикаєте доступ з інтернету, вашу публічну адресу та порт показують check-host.net виключно для перевірки доступності; а архів журналів потрапляє до розробника, лише якщо ви самі надішлете його зі своєї поштової програми.

Цей сайт

Сама програма не звертається до жодної з наведених нижче адрес. Вони належать сайту продукту - головній сторінці, посібникам і сторінці довіри до встановлення - і ваш браузер звертається до них, коли відкриває ці сторінки. Ця сторінка політики нічого з них не завантажує. Жодна сторінка сайту не звертається до адрес аналітики, менеджера тегів чи реклами.

  • fonts.googleapis.com і fonts.gstatic.com (Google Fonts) - таблиця стилів і два файли шрифтів для накреслення сайту; завантажуються на сторінках, які його використовують. Вони отримують вашу IP-адресу та user agent вашого браузера, як будь-який вебсервер; більше нічого не передається.
  • api.github.com (GitHub) - один запит на головній сторінці та її дванадцяти мовних сторінках: він питає про останній випуск, щоб посилання для завантаження вело на нього. Отримує вашу IP-адресу та user agent вашого браузера; більше нічого не передається.

Діагностичні журнали

Програма веде текстовий журнал своєї роботи поруч із програмою (або, якщо цю теку не можна записувати, у локальних даних вашого застосунку). Сам по собі він ніколи не залишає ваш пристрій. У Налаштування → Про програму є кнопка «Надіслати журнали автору»: вона пакує ці журнали та звіт про вашу версію, відомості про Windows і налаштування в архів, показує вам, що туди потрапило, і відкриває нове повідомлення у вашій власній поштовій програмі із доданим архівом. Нічого не передається, поки ви не надішлете це повідомлення самі, а архів можна відкрити й перевірити заздалегідь. У журналах є шляхи та імена відкритих вами файлів; ключ API вашого перекладу в них ніколи не включається.
