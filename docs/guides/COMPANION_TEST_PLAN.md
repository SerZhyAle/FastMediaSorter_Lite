# Сценарий ручного тестирования: Fast Media Sorter: Share Manager (Companion)

Дата: 2026-07-13. Что тестируем: новую программу Companion (Ф0-Ф5), пока Share ещё
НЕ вырезан из LITE (Stage 3 ждёт подтверждения). Идём от быстрого смоука к решающему
тесту с телефоном. Отмечай результат в скобках: [ ] не проверено / [x] ок / [!] баг.

**Где программа (уже разложена рядом с твоим FMS LITE):**
`C:\GD\i\FastMediaSorterCompanion.exe` (и `C:\GD\tc\SZA\_APP\FastMediaSorterCompanion.exe`),
рядом лежит `companion\fms-share-worker.exe`. Это **самодостаточный exe** (весь .NET
внутри, ~116 МБ) - ничего ставить не надо, просто запускай.

> Важно про «открыть из LITE»: кнопки запуска Companion из FMS LITE пока НЕТ - она
> появится на Stage 3 (держим до твоего «ok»). Сейчас Companion запускается **отдельно**,
> двойным кликом. Обратная ссылка есть: в самом Companion кнопка «Открыть Fast Media
> Sorter» открывает LITE.

## 0. Подготовка (1 мин)

- [ ] Закрой запущенные `FastMediaSorterCompanion.exe` и `fms-share-worker.exe` (Диспетчер задач), чтобы начать с чистого листа.
- [ ] Запомни: функции сервера у тебя, скорее всего, ВКЛючены (HKCU `Share_ServerFeaturesEnabled=1`). Тогда пункт 3 (гейт) проверяется отдельно.

## 1. Запуск, окно, трей (3 мин)

- [ ] Двойной клик по `C:\GD\i\FastMediaSorterCompanion.exe` при снятой галочке «Открывать окно менеджера при запуске» (по умолчанию) -> **окно НЕ открывается**: только значок в трее плюс короткая подсказка «Менеджер работает в трее». Двойной клик по значку -> окно открылось.
- [ ] В трее (справа внизу, возможно под стрелкой «^») появился синий значок «стрелки во все стороны».
- [ ] Наведи на значок -> подсказка «Fast Media Sorter: Share Manager» (или «Общий доступ включён», если раздача уже идёт).
- [ ] Правый клик по значку -> меню: **Открыть менеджер общего доступа** (жирным), **Открыть Fast Media Sorter**, разделитель, **Выход**.
- [ ] Запусти exe **второй раз** -> нового окна/значка НЕ появляется, второй процесс сам закрылся, а окно менеджера показалось (одиночный экземпляр + пробуждение через WM_COPYDATA).
- [ ] Двойной клик по значку -> окно менеджера открывается/выходит на передний план.

## 2. Главное окно - управление (level 1) (5 мин)

- [ ] Заголовок «Fast Media Sorter: Share Manager», окно **изменяемого размера** (потяни за край - контролы не обрезаются).
- [ ] Слева «Общие папки» - список с колонками Название / Папка / Доступ. Если раньше что-то раздавалось, папки уже здесь и отмечены галочками.
- [ ] Справа «Состояние сервера»: строка состояния, «Адрес: ..», «Ключ узла: ..», кнопка **Запустить/Остановить**.
- [ ] Внизу: галочка «Запускать при входе в Windows», кнопки «Открыть Fast Media Sorter» и **Поделиться..**.
- [ ] **Добавить папку..** -> выбери папку с картинками/видео -> строка появилась, отмечена, сервер поднялся (состояние «Сервер запущен», адрес вида `192.168.x.x:порт`).
- [ ] **Редактировать** (доступна только при выделенной строке; или двойной клик по строке) -> открывается «Параметры ресурса» (имя, тип, медиа-типы, условия, «только для чтения», «папка-получатель», PIN, слайд-шоу). Поменяй имя -> OK -> в колонке «Название» новое имя.
- [ ] Сними галочку у папки -> она перестаёт раздаваться (список ушёл в воркер). Верни галочку -> снова раздаётся.
- [ ] **Остановить** -> состояние «Сервер остановлен», адрес «-». **Запустить** -> снова поднялся.
- [ ] **Убрать** выбранную папку -> строка исчезла, параметры ресурса забыты.

## 3. Гейт серверных функций (если хочешь проверить) (3 мин)

> Только если готов временно выключить флаг. Иначе пропусти.

- [ ] Закрой Companion. В `regedit` в `HKCU\Software\VB and VBA Program Settings\SZA\FastMediaSorter` временно поставь `Share_ServerFeaturesEnabled` = `0` (запиши старое значение!).
- [ ] Запусти Companion, открой окно -> вместо управления показана **панель «Функции сервера выключены»** с кнопкой «Включить..». Кнопки Запустить/Поделиться/автозапуск **не видны и недоступны** (это и есть фикс гейта - раньше они торчали сбоку).
- [ ] Верни `Share_ServerFeaturesEnabled` = `1`. (Кнопку «Включить..» жать не обязательно - она вызовет UAC и добавит правило фаервола.)

## 4. Визард «Поделиться» - пакет для получателя (level 2) (5 мин)

- [ ] При запущенном сервере жми **Поделиться..** -> открывается окно «Поделиться - код доступа».
- [ ] Слева - список папок-«шар» с галочками (отмечены те, что были выбраны в главном окне). Справа - **Показать QR-код**, адрес, ключ узла, кнопки **Скопировать логин/пароль**, **Сохранить файл .fmscfg..**, **Отправить по почте..**.
- [ ] Сними/поставь галочки у папок -> QR и файл перестраиваются под выбранное подмножество (не зависает, не мигает старым кодом).
- [ ] **Показать QR-код** -> код открывается крупно в отдельном окне. Клик по коду увеличивает окно вдвое, потом ещё раз - на весь экран, следующий клик возвращает исходный размер. Окно тянется мышью за любой край и остаётся квадратным. Закрытие: Esc / Enter / крестик / правый клик по коду.
- [ ] Галочка **Только локальная сеть** -> в коде остаётся только локальный адрес (проверишь позже при импорте: нет интернет-адреса).
- [ ] Галочка **Не включать пароль в файл/QR** -> внизу показывается реальный пароль строкой «Пароль (передайте отдельно): ..».
- [ ] **Скопировать логин/пароль** -> вставь в блокнот: две строки «Логин:..» / «Пароль:..».
- [ ] **Сохранить файл .fmscfg..** -> сохрани на диск. Открой файл текстовым редактором: это валидный JSON с `accessPaths`, `roots` (только выбранные папки), `username`, `password` (пусто, если стояла галочка).
- [ ] **Отправить по почте..** -> открывается почтовый клиент по умолчанию с вложенным .fmscfg (если MAPI-клиент настроен).

## 5. Контракт readOnly - папка-получатель vs только чтение (3 мин)

> Это тот баг, который чинили: телефон не должен показывать Move/Delete там, где сервер запретит.

- [ ] Для одной папки в «Параметры ресурса» поставь **«Папка-получатель»** -> в колонке «Доступ» станет «получатель», в .fmscfg у этого root `"readOnly":false`.
- [ ] Для другой поставь **«Только для чтения»** -> «Доступ» = «чтение», в .fmscfg `"readOnly":true`.
- [ ] Обычная папка (ни то, ни другое) -> «Доступ» = «запись», `"readOnly":false` (папка по умолчанию доступна на запись - это ожидаемо).

## 6. Возобновление при запуске + автозапуск (5 мин + перезагрузка)

- [ ] Оставь одну папку раздающейся, закрой ОКНО менеджера (не «Выход») -> значок в трее остаётся, раздача идёт.
- [ ] «Выход» из меню трея -> процесс Companion закрылся; воркер может остаться (это ок).
- [ ] Снова запусти exe (двойной клик, тихо в трей). Открой окно -> раздача **сама возобновилась** (папка отмечена, сервер запущен) без ручного старта.
- [ ] Поставь галочку «Запускать при входе в Windows». В `regedit` `HKCU\..\Run` появилось значение `FastMediaSorterShare`, указывающее на **`FastMediaSorterCompanion.exe`** (а не на воркер).
- [ ] Галочка «Открывать окно менеджера при запуске» (независимая от автозапуска) по умолчанию **снята** и действует на ЛЮБОЙ запуск: `FastMediaSorterCompanion.exe --tray` и запуск без аргументов -> только значок в трее. Поставь галочку, повтори оба запуска -> оба открывают окно.
- [ ] При снятой галочке явные вызовы всё равно открывают окно: `FastMediaSorterCompanion.exe --show`, кнопка **Share Manager..** в настройках LITE (в том числе на холодном старте, когда Companion не запущен) и правый клик по папке -> «Поделиться этой папкой..».
- [ ] (Опционально) Перезагрузка -> после логона в трее сам появляется значок Companion и раздача доступна.
- [ ] Сними галочку -> значение `FastMediaSorterShare` из `Run` удалилось.

## 7. РЕШАЮЩИЙ ТЕСТ - Android (10-15 мин)

> Нужен телефон в той же Wi-Fi + приложение FastMediaSorter (Android). Клиент должен уметь `schemaVersion:2` (типизированные шары эмитят v2).

- [ ] На телефоне: Add resource -> SFTP/FTP -> **Import from companion** -> отсканируй QR (или открой сохранённый .fmscfg).
- [ ] Ресурс открывается, папки видны, **картинки листаются**.
- [ ] **Видео проигрывается с перемоткой**.
- [ ] Папка-получатель / обычная (writable): с телефона **Переместить/Удалить/Копировать** реально срабатывает (файл создаётся/удаляется на ПК). ← ключевая проверка фикса readOnly.
- [ ] Папка «только для чтения»: попытка изменить -> сервер отказывает (и клиент это показывает), а не «показал кнопку, потом ошибка».
- [ ] Закрой ОКНО менеджера во время просмотра с телефона -> телефон продолжает листать/играть (воркер жив в трее).
- [ ] Если пробовал «внешний доступ» без «только локальная сеть»: телефон в мобильной сети (не Wi-Fi) подключается по интернет-адресу/IPv6 (если проброс порта настроен).

## 8. Язык и мелочи (2 мин)

- [ ] Если в LITE переключить язык (RU/EN) и перезапустить Companion - его интерфейс на том же языке (общий флаг в реестре).
- [ ] Пробегись глазами по всем надписям: нет «полу-английских»/«полу-русских» экранов, нет `...` вместо `..`.
