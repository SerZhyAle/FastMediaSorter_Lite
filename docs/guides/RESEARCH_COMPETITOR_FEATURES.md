# Ресерч аналогов и идеи функционала для Fast Media Sorter for Windows

> Дата: 2026-06-21. Документ - результат параллельного веб-ресерча софта-аналогов
> (просмотрщики, фотоменеджеры/DAM, AI-органайзеры, дедупликаторы, видеоплееры,
> инструменты кулинга и OCR/перевода) и сопоставления их возможностей с текущим
> функционалом Fast Media Sorter for Windows. Цель - список идей того, чего у приложения ещё
> нет (или есть лишь частично), с оценкой сложности, ценности и приоритета.

## Как читать документ

- **Статус**: `Нет` - функции нет совсем; `Частично` - что-то близкое уже реализовано и идею можно достроить.
- **Сложность**: оценка трудозатрат под WinForms / .NET Framework 4.8 (Низк. / Средн. / Высок.).
- **Ценность**: польза именно для пользователя-сортировщика медиа (Низк. / Средн. / Высок.).
- **Приоритет**: `Quick-win` (дёшево и полезно), `High-impact` (главный эффект), `Nice-to-have`, `Long-term`.

Дух продукта учитывался при оценке: FastMediaSorter - лёгкий быстрый сортировщик на
горячих клавишах, а не тяжёлый редактор или каталог. Поэтому усиление потока сортировки,
навигации и дедупликации ценится выше, чем полноценное редактирование.

---

## Краткое резюме (главные выводы)

1. **Безопасность и скорость самого потока сортировки** - самый дешёвый и самый ценный
   вектор: многоуровневый Undo, удаление в Корзину, повтор последнего назначения,
   предзагрузка соседних кадров. Закрывает явные пробелы LITE, не превращая его в редактор.
2. **Дедупликация** (точные хеши -> перцептивные хеши -> авто-выбор какой оставить) -
   крупнейшая отсутствующая категория. Прямо ложится на ядро "разложить по папкам" и
   реализуема на чистом .NET / GDI+ без нейросетей.
3. **Современные форматы** (HEIC, AVIF, JPEG XL, анимированный WebP/AVIF через системные
   WIC-кодеки) и хотя бы превью RAW - вопрос выживания: иначе значимая часть файлов в
   папках просто невидима для сортировщика (фото с iPhone - HEIC, из веба - WebP/AVIF).
4. **Видео сейчас "играет, но не управляется"**: эскизы-обложки, скорость 2x-4x, resume,
   скриншот кадра и покадровая навигация дёшево превращают проигрывание в полноценный
   отбор роликов.
5. **Мягкая разметка** (флаги pick/reject, рейтинги/метки в XMP) + фильтрация списка дают
   режим "намерение сейчас, раскладка потом", дополняющий жёсткие DEL+0..9 и не ломающий
   клавиатурный дух продукта.
6. **Существующий OCR-конвейер недоиспользован**: копирование текста по хоткею, TTS,
   экспорт в sidecar - почти бесплатные quick-win'ы; индексация OCR-текста для поиска и
   манга-inpainting - амбициозные дифференциаторы на потом.
7. **Объективные метрики качества** (резкость по Лапласиану, клиппинг/зебра, гистограмма,
   лупа/100%) рисуются в уже существующем Paint-оверлее и дают автономный отбор брака без
   облака - в духе приватного офлайн-приложения.
8. **Тяжёлое пакетное редактирование** (конвертация, resize, водяные знаки, аннотации,
   неразрушающая обработка) - осознанно низкий приоритет: ценно, но противоречит
   позиционированию лёгкого быстрого сортировщика.

## 1. Quick-win'ы (дёшево, заметный эффект)

| Идея | Статус | Сложн. | Ценн. | Категория |
|------|--------|--------|-------|-----------|
| Удаление в Корзину вместо безвозвратного | Частично | Низк. | Высок. | Очистка |
| Запоминание позиции воспроизведения видео (resume) | Нет | Низк. | Средн. | Видео |
| Регулировка скорости видео (2x-4x, +/-) | Нет | Низк. | Средн. | Видео |
| Повтор последнего назначения одной клавишей | Нет | Низк. | Средн. | Сортировка |
| Открыть текущую папку/файл в Проводнике | Нет | Низк. | Средн. | Сортировка |
| Открыть текущий файл во внешнем редакторе | Нет | Низк. | Средн. | Сортировка |
| Панель свойств EXIF/IPTC текущего файла | Нет | Низк. | Средн. | Метаданные |
| Расширенные флаги CLI (слайдшоу/фуллскрин/сортировка) | Частично | Низк. | Низк. | UX |
| Копирование OCR-текста в буфер по хоткею | Нет | Низк. | Средн. | OCR |
| Озвучивание OCR/перевода (TTS) | Нет | Низк. | Низк. | OCR |
| Экспорт OCR/перевода в .txt рядом с файлом | Нет | Низк. | Низк. | OCR |

**Подробнее по ключевым:**

- **Удаление в Корзину** (`SHFileOperation` с `FOF_ALLOWUNDO`). При пакетном разборе цена
  ошибочного удаления высока; Корзина - ожидаемое безопасное поведение и страховка на
  случай закрытия программы поверх внутреннего Undo. Есть у VisiPics, dupeGuru, Duplicate Cleaner Pro.
- **Resume видео**: хранить секунду остановки по хешу пути (реестр/конфиг) и продолжать с
  того же места. Стандарт для MPC-HC, VLC, PotPlayer, mpv.
- **Скорость видео 2x-4x** через `MediaPlayer.SetRate` (LibVLC). Ускоренный просмотр
  радикально сокращает время отбора большого числа роликов.
- **Повтор последнего назначения**: хоткей "туда же, куда предыдущий", чтобы серию похожих
  файлов слать в одну папку без выбора слота (аналог двойного M/C в FastStone).
- **Открыть в Проводнике** (`explorer /select`) и **во внешнем редакторе** (настраиваемый
  путь + хоткей) - очевидные ожидаемые команды; внешний плеер видео уже есть, тут та же логика.
- **OCR в буфер / TTS / .txt-sidecar**: почти бесплатные расширения уже существующего
  OCR-конвейера. `System.Speech.SpeechSynthesizer` для TTS идёт в .NET из коробки. Этого
  нет у обычных просмотрщиков - сразу заметный дифференциатор.

## 2. High-impact (главный эффект на продукт)

| Идея | Статус | Сложн. | Ценн. | Категория |
|------|--------|--------|-------|-----------|
| Стек истории и многоуровневый Ctrl+Z для файловых операций | Частично | Средн. | Высок. | Сортировка |
| Поиск точных дубликатов по хешу файла | Нет | Средн. | Высок. | Очистка |
| Поиск визуально похожих (перцептивный хеш dHash/pHash) | Нет | Высок. | Высок. | Дедуп/AI |
| Поддержка HEIC/AVIF/JPEG XL/WebP-анимации через WIC | Частично | Средн. | Высок. | Форматы |
| Эскизы-обложки видео в панели миниатюр | Нет | Высок. | Высок. | Видео |
| Лёгкие флаги отбора pick/reject (без переноса файла) | Нет | Средн. | Высок. | Сортировка |
| Фильтрация списка по типу/дате/размеру/метке | Нет | Средн. | Высок. | Навигация |
| Авто-раскладка по папкам ГГГГ/ММ из даты съёмки EXIF | Нет | Средн. | Высок. | Сортировка |
| A/B-сравнение двух кадров с синхронным зумом | Нет | Высок. | Высок. | Просмотр |
| Лента миниатюр (filmstrip) вдоль края окна | Частично | Высок. | Высок. | Навигация |
| Предзагрузка соседних кадров в память | Частично | Средн. | Высок. | Производительность |

**Подробнее:**

- **Многоуровневый Undo/Redo.** Сейчас Undo (U) откатывает по сути одно последнее действие.
  Полноценный стек отмены перемещений/копий/удалений (с восстановлением файла в исходную
  папку и позиции в списке) - самая дешёвая страховка для быстрого разбора на горячих
  клавишах, где ошибочные нажатия DEL+цифра неизбежны.
- **Дедупликация - точные хеши.** Скан папки (и подпапок): дешёвая отсечка по размеру,
  затем SHA/MD5 только кандидатов, группировка в наборы. Чисто на .NET, безопасно, легко.
  База любой очистки медиатеки. Есть у Czkawka, dupeGuru, Duplicate Cleaner, AntiDupl.NET.
- **Дедупликация - визуально похожие.** dHash/pHash по уменьшенной серой версии, сравнение
  по регулируемому порогу Хэмминга, группировка пересжатых/ресайз/кроп копий. Реализуемо на
  GDI+ без нейросетей. Реальные библиотеки полны вариаций одного снимка, которые хеш файла
  не ловит. (Желателен дисковый кеш отпечатков - см. раздел 3.)
- **Современные форматы через WIC.** Опираться на установленные системные кодеки (HEIF/AV1
  Image Extension) для HEIC/AVIF/JPEG XL и анимированных WebP/AVIF; мягко подсказывать
  установку расширения, если кодек отсутствует. Без этого файлы с телефонов и из веба просто
  пропускаются при сортировке.
- **Эскизы-обложки видео.** Генерация кадра-превью (LibVLC snapshot или Shell
  `IThumbnailProvider`) и показ в ленте/панели миниатюр наравне с фото, с дисковым кешем.
  Сейчас видео в галерее не отличить друг от друга, что тормозит раскладку роликов.
- **Флаги pick/reject.** Хоткеи "оставить" / "в брак" помечают кадр без физического
  переноса; помеченные потом фильтруются и раскидываются/удаляются пачкой (sidecar/реестр по
  пути). Разделяет "намерение" и "действие": за один проход отделить keepers от брака, а
  целевую папку выбрать позже. Photo Mechanic, FastRawViewer, Narrative, Lightroom.
- **Фильтрация списка** поверх существующей сортировки `cmbox_Sort`: только видео / только
  изображения, по дате, размеру, рейтингу/флагу. Показать именно то, что разбираешь, вместо
  линейного перелистывания всей папки.
- **Авто-раскладка по дате EXIF.** Кнопка "разложить по папкам из даты съёмки": пакетно в
  `YYYY/YYYY-MM` по `DateTimeOriginal` (фолбэк на дату файла). Прямое усиление ядра помимо
  ручного DEL+0..9; EXIF уже читается для автоповорота.
- **A/B-сравнение.** Два кадра рядом с синхронным зумом/панорамой для выбора лучшего из
  почти-дублей (резкость, моргание, шум). У приложения уже есть два медиа-поля
  `Picture_Box_1/2` как база.
- **Лента миниатюр (filmstrip)** внизу/сбоку с подсветкой активного файла. Дополняет панель
  F3 постоянно видимой лентой; резко ускоряет навигацию и выбор файла для раскладки.
- **Предзагрузка соседних кадров** в память поверх существующей фоновой загрузки - убирает
  микропаузы при пролистывании тысяч кадров. Скорость навигации и есть ценность сортировщика.

## 3. Nice-to-have (полезно, но не первоочередное)

### Дедупликация и очистка
- **Дисковый кеш отпечатков/хешей** (ключ = путь + дата + размер) для быстрого повторного
  скана. Переиспользует подход существующего disk-cache OCR. *(Нет, Средн., Средн.)*
- **Авто-выбор какой дубль оставить** по правилам (наибольшее разрешение/размер/несжатый/
  старейший) + отправка остальных в Корзину или карантин. *(Нет, Средн., Средн.)*
- **Очистка: пустые папки и битые/мусорные файлы** (нулевые, повреждённые, неверные
  расширения) с удалением в Корзину. *(Нет, Средн., Низк.)*

### Видео
- **Скриншот текущего кадра** в PNG/JPEG (LibVLC `TakeSnapshot`), имя с таймкодом. Можно
  выдернуть обложку из ролика и сразу отправить кадр в папку. *(Нет, Средн., Средн.)*
- **Покадровая навигация и A-B повтор отрезка** (LibVLC `NextFrame` / position-loop). *(Нет, Средн., Низк.)*
- **Переключение аудиодорожек и субтитров**, подключение внешнего .srt. Для многоязычных
  коллекций язык - критерий раскладки. *(Нет, Средн., Низк.)*
- **Превью кадра при наведении на таймлайн** (предвыборка кадров LibVLC). *(Нет, Высок., Низк.)*

### Отбор и качество (рисуется в существующем Paint-оверлее)
- **Зум 100% (Actual Pixels) + цифровая лупа под курсором** для проверки резкости. *(Частично, Средн., Средн.)*
- **Авто-оценка резкости (дисперсия Лапласиана)** для ранжирования серии и пометки
  размытых в брак - без нейросетей и облака. *(Нет, Средн., Средн.)*
- **Гистограмма яркости/каналов** как полупрозрачный виджет из уже загруженного Bitmap. *(Нет, Средн., Низк.)*
- **Индикация клиппинга светов/теней (зебра)** по порогам яркости. *(Нет, Средн., Низк.)*
- **Авто-группировка серий/бёрстов** по близкому EXIF DateTime в сворачиваемые стопки. *(Нет, Средн., Средн.)*
- **Быстрый предпросмотр RAW через встроенный JPEG** (WIC/парс заголовка) - почти мгновенный
  показ CR2/NEF/DNG. Переиспользует подход `GetImageDimensions`. *(Нет, Высок., Средн.)*

### Метаданные и организация
- **Звёздные рейтинги (0-5) и цветовые метки** на цифрах с записью в XMP-sidecar/EXIF -
  совместимо с Lightroom/Bridge. *(Нет, Средн., Средн.)*
- **Пакетное переименование по EXIF/шаблону** (дата, счётчик с ведущими нулями, имя папки,
  поиск-замена). *(Нет, Средн., Средн.)*
- **Показ точки съёмки на карте по GPS** из EXIF (ссылка на OSM/мини-карта). *(Нет, Низк., Низк.)*

### Рабочие сценарии сортировки
- **Список избранных папок-получателей сверх 10 слотов** (история + закрепление). *(Нет, Средн., Средн.)*
- **Дерево папок-получателей со счётчиком** отправленных файлов за сессию. *(Нет, Средн., Низк.)*
- **Файл сразу в несколько папок** (мультиназначение, как Slidebox). *(Нет, Низк., Низк.)*

### Интерфейс / современный UX
- **Тёмная тема интерфейса** (панели/тулбар/статус) рядом с выбором фона картинки. *(Нет, Средн., Средн.)*
- **Корректный High-DPI (PerMonitorV2)** - чтобы контролы не мельчали на 4K. *(Нет, Средн., Средн.)*
- **Distraction-free режим** с переключаемыми панелями; в фуллскрине - всплывающие у краёв. *(Частично, Средн., Низк.)*
- **Слайдшоу с обходом дерева папок и случайным порядком** по всему дереву. *(Частично, Средн., Средн.)*

### Лёгкое редактирование (в духе просмотрщика, поверх Paint-инфраструктуры)
- **Кадрирование (Crop)** выделением мышью с сохранением (для JPEG по возможности без потерь). *(Нет, Средн., Средн.)*
- **Lossless-поворот JPEG** при раскладке (jpegtran-подобная трансформация по блокам + правка
  EXIF). Дополняет показ-автоповорот и R/Shift+R. *(Частично, Высок., Средн.)*
- **Размытие/пикселизация приватных областей** на скриншотах (лица, номера, личные данные). *(Нет, Средн., Средн.)*
- **Аннотации**: стрелки, рамки, линии, подписи поверх картинки. *(Нет, Высок., Низк.)*
- **Пакетное удаление метаданных (privacy strip)** - стереть EXIF/IPTC/XMP (особенно GPS)
  перед публикацией. *(Нет, Средн., Средн.)*

### OCR / перевод
- **Умное форматирование OCR-текста** (строка/абзац/таблица/URL) - переключатели как у
  PowerToys/NormCap. *(Нет, Средн., Низк.)*

## 4. Long-term (амбициозно, на будущее)

- **Поиск по тексту на изображениях (индексация OCR).** Индексировать распознанный текст в
  локальную базу и искать картинки по содержимому ("все чеки", "скриншоты со словом X").
  Переиспользует существующий OCR + дисковый кеш. Уникально для просмотрщика; найти кадр в
  неразобранной свалке до сортировки - главный сценарий FMS. *(Нет, Высок., Средн.)*
- **Перевод манги/комиксов с заменой текста в пузырях (inpainting).** Детект речевых пузырей,
  стирание оригинала с восстановлением фона и вписывание перевода с подбором шрифта - как
  профессиональный скан-перевод, а не наклейка. Сильный дифференциатор: функции нет ни у
  одного обычного просмотрщика. Расширяет существующий OCR-оверлей. *(Нет, Высок., Средн.)*
- **Пакетная конвертация и изменение размера** выделенных файлов (HEIC/WebP -> JPEG, resize)
  в фоновой очереди (как `FileOperationWorker`). Ценно, но ближе к редактору - осознанно
  низкий приоритет. *(Нет, Высок., Средн.)*

> За пределами списка остались тяжёлые DAM/AI-функции конкурентов, сознательно не
> рекомендованные как противоречащие позиционированию: распознавание лиц и группировка по
> людям, семантический поиск CLIP на естественном языке, AI-автотегирование объектов/сцен,
> AI-кулинг с детекцией закрытых глаз, иерархические теги/альбомы/умные коллекции,
> неразрушающее параметрическое редактирование, водяные знаки. Их стоит держать в поле
> зрения, но они уводят продукт из ниши лёгкого быстрого сортировщика.

## 5. Что у FastMediaSorter уже есть (контекст)

Чтобы не предлагать существующее: приложение уже умеет просмотр изображений (вкл. GIF-анимацию,
EXIF-автоповорот, HQ-бикубическое масштабирование, зум/панораму, ambilight-фон "перспектива"),
видео (нативный IE WebBrowser для H.264 + LibVLC-фолбэк, громкость/мьют, зацикливание, внешний
плеер), мощную навигацию и слайд-шоу (последовательное и случайное, ускоряющийся интервал),
сортировку по 11 горячим клавишам (DEL+0..9) с копированием/перемещением (синхронно или в
фоне) и одноуровневым Undo, переименование, копирование пути, OCR + перевод поверх изображения
(Tesseract + Ollama/LibreTranslate, дисковый кеш), регистрацию ассоциаций файлов, окно настроек
на 5 вкладок, локализацию EN/RU с автоопределением, одноэкземплярность с пробросом аргументов и
полный конвейер дистрибуции (GitHub Release ZIP+Inno EXE, winget, Microsoft Store MSIX).

Многие идеи помечены `Частично` именно потому, что опираются на уже готовую инфраструктуру:
Paint-оверлей (OCR/HUD), два медиа-поля `Picture_Box_1/2`, фоновый `FileOperationWorker`,
чтение EXIF, дисковый кеш, панель миниатюр F3, приём аргументов CLI.

## 6. Предлагаемая дорожная карта

- **Этап 1 - "Безопасный быстрый поток" (quick-win'ы + ключевой Undo).** Удаление в Корзину,
  многоуровневый Undo, повтор последнего назначения, "открыть в Проводнике/редакторе",
  resume и скорость видео, OCR-в-буфер/TTS/sidecar. Низкая стоимость, сразу ощутимо.
- **Этап 2 - "Видеть все файлы".** Современные форматы через WIC (HEIC/AVIF/JPEG XL/
  WebP-анимация), эскизы-обложки видео, предзагрузка соседних кадров, лента миниатюр.
- **Этап 3 - "Умная сортировка".** Дедуп по хешу -> перцептивный хеш + дисковый кеш +
  авто-выбор, флаги pick/reject, фильтрация списка, авто-раскладка по дате EXIF,
  A/B-сравнение, панель EXIF/IPTC.
- **Этап 4 - "Отбор и качество".** Зум 100%/лупа, резкость по Лапласиану, гистограмма,
  зебра, группировка серий, рейтинги/метки в XMP.
- **Этап 5 - "Дифференциаторы".** Индексация OCR-текста для поиска, манга-перевод с
  inpainting, тёмная тема, High-DPI.
