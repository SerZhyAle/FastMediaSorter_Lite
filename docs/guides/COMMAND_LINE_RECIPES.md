# Command line recipes

This page is generated by `tools/Build-CliDocs.ps1` from the command tables in code; edit the tables, never this file. Every command line below is an example line of a verb in the table of its program, and `docs/CLI.md` is the full reference: every verb, option, risk class and exit code. Both programs answer the same strict command line (contract `APP-COMMANDS` 0.1).

## Running a command from a script

The programs are Windows-subsystem programs, so a shell does not wait for them on its own. `start /wait` (cmd) and `Start-Process -Wait` (PowerShell) wait and give the exit code: 0 is done, 10 is a mistake in the command line, 11 is nothing running, a busy window or a missing target, 12 is the setting below being off, 2 is a result that could not be proven (no answer in time, or an older copy that does not know commands).

A command that works with files, the screen, the clipboard or the network is held by one setting, **Allow commands from other programs**, which is off until the person turns it on in the settings of the program. While it is off, such a command ends with exit 12 and does nothing; the commands of the risk class `safe` work either way.

## Find out what a program accepts

Each program prints the table it answers from, as JSON, without starting a window. The viewer:

```powershell
Start-Process .\FastMediaSorter_LITE.exe -ArgumentList 'commands --json' -RedirectStandardOutput C:\temp\fms-commands.json -Wait
```

Expect: exit 0 and the file equals docs/cli-commands.json.

The Share Manager:

```powershell
Start-Process .\FastMediaSorterCompanion.exe -ArgumentList 'commands --json' -RedirectStandardOutput C:\temp\fms-sm-commands.json -Wait
```

Expect: exit 0 and the file equals docs/cli-commands.share-manager.json.

## Schedule a copy of a folder

Scheduled file operations belong to the Share Manager and run while it runs in the signed-in session. The script opens the schedule window with the folder as its source (`schedule open` is in the risk class `safe`); the person chooses the action, the destination and the time in the window and saves. The script then reads back what is scheduled (`schedule list` is in the risk class `reads-user-data`). The answer names each operation by id, name, action, state and next run; it carries no folder, no file name and no error text.

```bat
start /wait FastMediaSorterCompanion.exe schedule open --folder D:\Photos
```

Expect: exit 0 and the window open with D:\Photos as the source.

```powershell
Start-Process .\FastMediaSorterCompanion.exe -ArgumentList 'schedule list --result C:\temp\ops.json' -Wait; Get-Content C:\temp\ops.json -Raw | ConvertFrom-Json
```

Expect: an object with an operations array.

## Schedule a daily backup of a folder

A script can create or update a daily backup operation (`schedule add` is in the risk class `writes-user-data`), queue a run now and wait for the result (`schedule run`, `writes-user-data`), read the run journal (`schedule history`, `reads-user-data`) and remove the definition without deleting backup files (`schedule remove`, `writes-user-data`). Re-running `schedule add` with the same action, source and destination updates the existing operation.

```powershell
Start-Process .\FastMediaSorterCompanion.exe -ArgumentList 'schedule add --action backup --source P:\MyProject --destination C:\GD\GIT --daily 13:00 --keep-days 7 --keep-monthly --result C:\temp\add.json' -Wait -PassThru
```

Expect: exit 0 and C:\temp\add.json holds the operation id.

```powershell
(Start-Process .\FastMediaSorterCompanion.exe -ArgumentList 'schedule run --all --wait' -Wait -PassThru).ExitCode
```

Expect: 0 when every enabled operation finished without errors.

```powershell
Start-Process .\FastMediaSorterCompanion.exe -ArgumentList 'schedule history --last 20 --result C:\temp\hist.json' -Wait; Get-Content C:\temp\hist.json -Raw | ConvertFrom-Json
```

Expect: an object with an entries array.

```bat
start /wait FastMediaSorterCompanion.exe schedule remove "MyProject"
```

Expect: exit 0 and the operation definition is deleted while backup files remain.

## Save a screenshot of the viewer window to a file

The viewer writes its own window as a PNG to the path given, used exactly as written. A folder as the path gets a file named by the date and time inside it, a relative path is relative to the folder the script runs in, and an existing file is kept unless `--overwrite` is given. `screenshot window` is in the risk class `reads-user-data`.

```powershell
Start-Process .\FastMediaSorter_LITE.exe -ArgumentList 'screenshot window --out C:\temp\viewer.png --overwrite' -Wait -PassThru
```

Expect: exit 0; C:\temp\viewer.png is the window as drawn.
