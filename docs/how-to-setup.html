Set it up once: default viewer, language, and what happens to your files

Everything below lives behind F2. The defaults are safe out of the box, so treat this as the list of things worth deciding for yourself rather than a setup you must complete. This page describes the settings window of the 64-bit viewer (Windows 10 1607+); the 32-bit fallback has a plainer window of five tabs without most of the pages and groups named here.

Find a setting and return to it

Groups open independently. Settings remember the last page, group states and approximate scroll position. Use Search settings or Ctrl+F to search names, explanations and choices; a result opens the original field. Expand all and Collapse all affect this page. Closing the window keeps applied changes. Search is temporary and excludes API keys and personal history. Profile import/export is in General / Advanced settings; window context stays on this PC.

Storage owns cache budgets and cleanup. Thumbnail size offers 96, 128, 192 or 256 px. Interface scale multiplies the Windows scale for settings, floating panels and text view. General offers a reset of additional preferences after confirmation and a backup; destinations, language, theme, sound, OCR and personal history are retained.

Make it your default viewer

On the Files page, in the Keys and associations group, Image file types claims the picture types the program can display, and Video file types does the same for the video and audio it can play. Both write to your own user profile - no administrator rights are involved - and Windows may still ask you to confirm the choice in its own default-apps screen the first time you double-click a file.

Choose the interface language

Thirteen languages ship with the 64-bit viewer (the 32-bit fallback has Russian and English only). On the very first run it follows your Windows display language, and after that your own choice wins: the two-letter button on the toolbar switches it instantly, and the same setting sits in General / Basic settings. Arabic and Urdu lay the window out right-to-left; Hindi, Bengali and Chinese switch to a font that can draw their script.

Decide what happens to a file

The Files / Basic settings group is the part worth reading before a big sorting session:

  • Name collision - ask, skip, keep both, or replace, when the destination folder already holds a file with that name.
  • After copying or moving - go to the next file, stay on the current one, or close when nothing is left.
  • Delete to the Recycle Bin and Ask before deleting - always, never, or only when the file will not reach the bin. A network share and a memory stick have no bin at all, and that is exactly when the question is worth asking.

Narrow down what you see

File types limits the list to the formats you actually care about, and Include subfolders decides whether a folder means its own files or everything beneath it. Open at startup (General / Startup) chooses what a plain launch shows - the start page, the last folder, or the last file. Right under it, Resume the last file goes further than the row above: it reopens the exact file that was on screen - not the position it held in the folder - and lets a video carry on from where it was left. It is off until you switch it on, and a file that has been deleted, renamed or left on a disconnected drive simply leaves the window empty. History sizes for recent files and folders are right there too, with a button that clears them.

Carry the setup to another PC

Export additional settings writes the additional preferences to a file and Import additional settings reads them back. Recipients, language, theme, sound and OCR are excluded. Include personal data decides whether your folder history and viewing positions travel with it; API keys and passwords never do, with or without that tick.

Comfort of viewing

The General / Appearance group carries interface scale and Reduce motion; Images / Basic settings chooses the starting scale for each image. If the window feels too small or the effects too lively on your monitor, that is where to look first.

If something goes wrong

F2 → About → Send the logs to the author packs the logs and a report of your version, Windows and settings into an archive, shows you what went in, and opens a new mail with it attached. Nothing is sent until you press Send yourself. The log sender is in the 64-bit viewer only (Windows 10 1607+); the 32-bit fallback does not have it.

Where sharing settings live

Settings are in two windows. Manager settings holds the SFTP sharing group - the SFTP port, LAN-only policy and Hosting page, shown while that component is installed - beside general preferences, remote-account access, publishing and schedules. The installed local exchange server has its own settings window. The link at the lower left opens the other window without closing the current one. Opening settings starts no server. Earlier builds showed SFTP sharing in a window of its own.
