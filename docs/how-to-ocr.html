HOW TO · OCR & TRANSLATION

Read the text on a picture and see it in your language

A scanned page, a screenshot, a photo of a sign: the viewer recognizes the text and draws the translation over each block, in place. Only the recognized text goes to the translator you choose - by default one running on your own PC - and the image itself is never uploaded.

Turn recognition on

Press F2 for Settings and open the OCR page in the list on the left. Tick Enable OCR; Run automatically next to it recognizes every image as you open it, which is worth switching on only when you are working through a whole folder of foreign text. Until OCR is enabled, T keeps its older meaning and simply rotates the picture. The 32-bit build for Windows 7 and 8.1 recognizes and translates too, but has its own older Settings window, where all of these settings sit on one tab; the names below are those of the 64-bit viewer.

Tell it what it is reading

Under Text recognition on the same page, set the Source text language - or leave Auto-detect - and press Download recognition language pack in the Language data row to fetch a pack that is not bundled. Two more settings matter when a page resists:

  • Recognition quality - Fast is the default; Best (more accurate, slower) trades speed for accuracy.
  • OCR mode - Auto (recommended) suits most pictures; Single block, Sparse text, Single line and Vertical text are there for layouts that auto reads badly.

Choose who translates

The Translation page next to it holds the translator, chosen in Translation provider. The default is Ollama - a language model running on your own machine - and the Local Ollama server row does the setup: Install Ollama, Start Ollama, then pick a Translation model and press Pull. LibreTranslate is the alternative if you already have a server: put its address in Service address. An API key, where one is needed, is stored encrypted by Windows. Finally set the Translation language - the language you want to read. Only the recognized text goes to the translator - by HTTP to the address in Service address: the local Ollama server (localhost) by default, or the LibreTranslate server you name, together with the API key if you set one. The image itself is never sent.

Press T on the image

One press recognizes the picture and shows the translation over it; the next press hides the overlay again. Shift+T switches on auto mode, where every image you open is processed without asking. The Translate toolbar button does the same as T, and a right-click on it opens these settings directly.

Make the overlay comfortable

The Translation over the image group at the bottom of the Translation page (folded until you open it) sets Panel opacity - by default the plate fully covers the original, so the translation reads cleanly; lower it if you want the picture to show through. Show translation overlay hides or restores an overlay that is already there. Cache results on disk, so the same picture is not recognized twice, is not on these pages: it is on Storage, in the Text recognition group, next to the size limit, the space in use and a Clear button (the 32-bit build keeps its own default limit and has no such setting).

It stays on your computer

Recognition is always local. With Ollama the translation is local too, so a private document is never uploaded anywhere. Only if you deliberately point Service address at an outside service does the recognized text leave the machine - and still never the image.

If nothing is recognized

Set the source language explicitly instead of auto-detect, set Recognition quality to Best (more accurate, slower), and try an OCR mode that matches the layout. A photo taken at an angle or a very small screenshot is the hard case - straighten it or open a larger copy.
