One download, both programs. FastMediaSorter_LITE.exe is the main 64-bit app - the .NET runtime is inside it, so there is nothing to install; it needs Windows 10 1607+, Windows 11 or Server 2016+. FastMediaSorter_x86.exe is the same viewer as a small 32-bit app for Windows 7/8.1 and 32-bit Windows, and needs .NET Framework 4.8. The installer sets up both and points the shortcut and file associations at whichever one runs on your PC - you never have to choose.
