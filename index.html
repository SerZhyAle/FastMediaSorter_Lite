01Compatibility and editionsСовместимость и вариантыСумісність і варіанти

One download, both programs. FastMediaSorter_LITE.exe is the main 64-bit app - the .NET runtime is inside it, so there is nothing to install; it needs Windows 10 1607+, Windows 11 or Server 2016+. FastMediaSorter_x86.exe is the 32-bit build for Windows 7/8.1 and 32-bit Windows, and needs .NET Framework 4.8. It views and sorts the same files and keeps OCR and translation, but it has no Android Folder Share - the Share Manager that feature opens is itself a 64-bit program, so it could not start on those machines - and a few newer viewing features are 64-bit only (marked below). The installer sets up both and points the shortcut and file associations at whichever one runs on your PC - you never have to choose. It stays one application: one set of settings, and starting one while the other is open simply brings that window to the front. Одна загрузка - обе программы. FastMediaSorter_LITE.exe - основная 64-битная программа: среда .NET уже внутри неё, устанавливать ничего не нужно; требуется Windows 10 1607+, Windows 11 или Server 2016+. FastMediaSorter_x86.exe - 32-битная сборка для Windows 7/8.1 и 32-битной Windows, ей нужен .NET Framework 4.8. Она показывает и сортирует те же файлы и сохраняет OCR и перевод, но в ней нет общего доступа для Android: Share Manager, который открывает эта функция, сам является 64-битной программой и не запустился бы на таких машинах. ZIP або CBZ відкривається як звичайна тека: комікс чи тека сканів гортається, крутиться у слайд-шоу, масштабується й перекладається так само, як звичайні файли. Нічого не розпаковується заздалегідь - кожна картинка дістається саме перед показом, до власної тимчасової теки, яка прибирається на виході з архіву, при закритті програми або на наступному архіві, якщо програму вбили. Сам архів лише читається, тому DEL і каталоги-отримувачі чесно відмовляються працювати. 7z, RAR та CBR поки не відкриваються. 64-бітна програма.

Animation into videoАнимация в видеоАнімація у відео

An animated WEBP, APNG or GIF is a picture file that behaves like a video and loses on every count: no seek bar, no pause, no hardware decoding, and only 256 colours. One button turns it into an ordinary MP4 beside it and replaces the original - which is deleted permanently, so the program says so first, names both files, and warns when transparency is about to be flattened onto black. The encoder (FFmpeg, GPL, about 110 MB) is not bundled: the first conversion asks whether to download it, and a No simply cancels. Анимированный WEBP, APNG или GIF - это файл-картинка, ведущий себя как видео и проигрывающий по всем статьям: ни перемотки, ни паузы, ни аппаратного декодирования, и всего 256 цветов. Одна кнопка превращает его в обычный MP4 рядом и заменяет оригинал - тот удаляется безвозвратно, поэтому программа сначала говорит об этом, называет оба имени файлов и предупреждает, если прозрачность будет залита чёрным. Кодировщик (FFmpeg, GPL, около 110 МБ) в комплект не входит: первое преобразование спросит, загрузить ли его, и «Нет» просто отменяет действие. Анімований WEBP, APNG чи GIF - це файл-картинка, що поводиться як відео і програє за всіма статтями: ані перемотки, ані паузи, ані апаратного декодування, і лише 256 кольорів. Одна кнопка перетворює його на звичайний MP4 поруч і замінює оригінал - той видаляється безповоротно, тому програма спершу каже про це, називає обидва імені файлів і попереджає, якщо прозорість буде залито чорним. Кодувальник (FFmpeg, GPL, близько 110 МБ) до комплекту не входить: перше перетворення спитає, чи завантажувати його, а «Ні» просто скасовує дію.

Video and audio can each be left out of paging entirely, so a folder of photographs stays a folder of photographs. MP3, WAV, M4A, WMA или OGG раньше шёл по видеопути и показывал чёрный прямоугольник. Видео и аудио можно вообще исключить из пролистывания, чтобы папка с фотографиями осталась папкой с фотографиями. MP3, WAV, M4A, WMA чи OGG раніше йшов відеошляхом і показував чорний прямокутник. Тепер аудіо - самостійний тип файлу: вбудована обкладинка альбому заповнює вікно, а якщо її немає, замість неї йде анімація з хвиль і частинок. Унизу - назва, виконавець та альбом так, як їх пише сам файл, а під ними кодек, бітрейт, частота дискретизації, тривалість і розмір. Власний розділ налаштувань вирішує, що робити наприкінці доріжки - наступний файл, зупинитися чи повторити, - чи лишати панель відтворення на видноті, і таймер сну до трьох годин. Slow formats open onceМедленные форматы открываются один разПовільні формати відкриваються один раз

Animated WEBP, AVIF and HEIC have no Windows codec, so the program decodes them itself - seconds of work for a large animation, which is what the "Loading.." badge is about. That work is now kept on disk and reused while the file is unchanged, so the badge appears once per file instead of once per view, and walking a folder forwards fills the cache for the walk back. Settings show how much space it takes, empty it on request and set its limit; 0 switches it off. JPEG, PNG and BMP are never cached - Windows opens those in milliseconds. Для анимированного WEBP, AVIF и HEIC в Windows нет кодека, поэтому программа декодирует их сама - для большой анимации это секунды работы, о которых и говорит значок «Загрузка..». Теперь результат сохраняется на диске и переиспользуется, пока файл не изменился, так что значок появляется один раз на файл, а не один раз на просмотр, а проход по папке вперёд наполняет кэш для прохода назад. Настройки показывают занятое место, очищают кэш по требованию и задают его предел; 0 отключает кэш. JPEG, PNG и BMP не кэшируются никогда - Windows открывает их за миллисекунды. Для анімованого WEBP, AVIF та HEIC у Windows немає кодека, тож програма декодує їх сама - для великої анімації це секунди роботи, про які й каже значок «Завантаження..». Тепер результат зберігається на диску та використовується повторно, доки файл не змінився, тому значок з'являється один раз на файл, а не один раз на перегляд, а прохід текою вперед наповнює кеш для проходу назад. Налаштування показують зайняте місце, очищають кеш на вимогу та задають його межу; 0 вимикає кеш. JPEG, PNG і BMP не кешуються ніколи - Windows відкриває їх за мілісекунди.

Perspective backgroundПерспективный фонПерспективний фон

When a photo doesn't match the shape of the window, the bars beside it are filled with colour taken from the photo's own edges instead of black - a plain average for a flat edge, or each edge row extended outwards for a detailed one. The picture ends up sitting in its own light, the way an Ambilight TV does. On the 64-bit build the "Dynamic perspective" sub-option fades those bars into the background colour the further they get from the photo, so the picture sits in a glow rather than between two solid slabs; its own "Animated" sub-option (on by default) grows that glow out of the photo edge when a new photo opens, over about a third of a second. Dynamic perspective is off by default and needs Perspective on. Когда фото не совпадает по форме с окном, полосы по бокам заполняются цветом из краёв самого фото, а не чёрным: ровный край - средний цвет, сложный - каждый ряд пикселей края продолжается наружу. Снимок оказывается в собственном свете, как у телевизора с Ambilight. В 64-битной сборке подпункт "Динамическая перспектива" растворяет эти полосы в цвете фона по мере удаления от фото, и снимок сидит в свечении, а не между двумя сплошными плитами; его собственный подпункт "Анимировать" (включён по умолчанию) выращивает это свечение от края фото при открытии нового снимка примерно за треть секунды. Динамическая перспектива по умолчанию выключена и требует включённой перспективы. Коли фото не збігається формою з вікном, смуги обабіч заповнюються кольором з країв самого фото, а не чорним: рівний край - середній колір, складний - кожен ряд пікселів краю продовжується назовні. Знімок опиняється у власному світлі, як у телевізора з Ambilight. У 64-бітній збірці підпункт "Динамічна перспектива" розчиняє ці смуги в кольорі тла в міру віддалення від фото, і знімок сидить у сяйві, а не між двома суцільними плитами; його власний підпункт "Анімувати" (увімкнений за замовчуванням) вирощує це сяйво від краю фото при відкритті нового знімка приблизно за третину секунди. Video / LibVLC engineВидео / движок LibVLCВідео / рушій LibVLC

Every clip plays through the bundled LibVLC engine - AVI, ZMBV, VP9, MKV, WMV and the rest. No external codecs, and no reliance on the retired Internet Explorer component, so video behaves the same even where Windows no longer ships it. The 64-bit build adds a control bar along the bottom - play/pause, seek bar, running time, mute and a volume slider; it appears on mouse-over, slips away after a couple of seconds and stays put while paused. A and V step through audio tracks and subtitles, and a "Tracks" button shows up only when the file really offers a choice - your pick is remembered by language, so the next episode keeps it. Right-click the file-selection button and paste an address to play video over smb://, sftp://, ftp://, http(s)://, nfs:// or rtsp:// without downloading it first. Those three extras are 64-bit only; ordinary \\server\share paths work in both builds. Любой ролик играет через встроенный движок LibVLC - AVI, ZMBV, VP9, MKV, WMV и остальное. Без внешних кодеков и без опоры на снятый с поддержки компонент Internet Explorer, поэтому видео ведёт себя одинаково даже там, где его в Windows уже нет. В 64-битной сборке снизу добавляется панель управления - пуск/пауза, полоса перемотки, время, отключение звука и регулятор громкости; она появляется при наведении мыши, уходит через пару секунд и остаётся на месте на паузе. Клавиши A и V перебирают звуковые дорожки и субтитры, а кнопка "Дорожки" появляется, только когда в файле действительно есть из чего выбрать, - выбор запоминается по языку, поэтому следующая серия его сохраняет. Правый клик по кнопке выбора файла позволяет вставить адрес и играть видео по smb://, sftp://, ftp://, http(s)://, nfs:// или rtsp:// без предварительной загрузки.
