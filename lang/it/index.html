Fast Media Sorter & Sharing for Windows

Windows desktop app

Free & open-source

Ordina foto e video con un tasto per file

Tre parti facoltative: un visualizzatore e organizzatore dei tuoi contenuti multimediali, un servizio locale di condivisione cartelle via SFTP e un Media Exchange Server (in sviluppo, non ancora rilasciato) - inizia dal visualizzatore o dal server di condivisione cartelle e aggiungi il resto solo se lo vuoi.

Sfoglia velocemente cartelle enormi di foto e video e sposta, copia, rinomina o elimina ogni file con un solo tasto.

«Sharing» nel nome significa dare i tuoi file multimediali a qualcun altro: il tuo telefono Android, un'altra copia del programma o un qualsiasi client SFTP. Resta disattivato finché non lo attivi. Share folders to Android over SFTP

#Due ingressi, tre parti facoltative

Parti da dove sei: dal visualizzatore o dal server di condivisione cartelle. Ogni parte è facoltativa e il Media Exchange Server è ancora in sviluppo.

Prima il server

Voglio un server per le mie cartelle

Apri le cartelle di questo PC su un telefono Android, in un'altra copia del programma o in qualsiasi client SFTP. L'edizione Server (setup.exe o winget, servono i diritti di amministratore) installa il servizio di condivisione cartelle come servizio di Windows che funziona senza che nessuno abbia effettuato l'accesso; il visualizzatore è un extra facoltativo, non selezionato. Non installa il Media Exchange Server (in sviluppo).

Edizione Server: condivisione senza accesso (in inglese)
In sviluppo

Media Exchange Server

In sviluppo e ancora in nessun pacchetto, quindi non c'è nulla da scaricare. È un server a parte che gestisci tu, per dispositivi che non possono raggiungersi direttamente. Non è la condivisione di cartelle, e né il visualizzatore né la condivisione locale ne hanno bisogno.

#Da sapere

  • Gratuito e open source.
  • Due build viaggiano insieme: una moderna a 64 bit per Windows 10/11 e una di riserva a 32 bit per Windows 7 e 8.1. L'installer sceglie quella giusta.
  • L'interfaccia è disponibile in 13 lingue: sia il visualizzatore sia Gestione condivisione, che seguono la stessa scelta.
  • La condivisione può funzionare 24 ore su 24: nello Share Manager la prende in carico un servizio di Windows che serve fin dall'avvio, senza utenti connessi. L'edizione Server separata installa subito lo stesso servizio, per macchine che lavorano senza schermo.
  • L'installer porta con sé il suo carico offline - codec VLC, modelli OCR e lo Share Manager - e installa tutto con o senza diritti di amministratore.

Trasmissioni per StreamsPlayer

Nel visualizzatore a 64 bit, fai clic destro su un video, un file audio o la sua cartella e scegli la trasmissione. Share Manager esporta un file .spres, un codice QR o un collegamento rapido per StreamsPlayer. Una cartella diventa un canale con una playlist fissa; Aggiorna sostituisce la lista e Revoca disattiva il collegamento. Il gateway HTTP ha un interruttore separato, disattivato per impostazione predefinita. Ogni token consente solo la lettura di una trasmissione, normalmente per 24 ore. HTTP non è cifrato: condividi il documento privatamente e attiva internet solo se necessario.

Annulla, e un vero Cestino

Canc manda il file nel Cestino, Maiusc+Canc lo scavalca, e U ripercorre le ultime 50 operazioni - rinomine ed eliminazioni comprese. Dove Windows non tiene alcun cestino, l'app lo dice invece di fingere.

Gli archivi si aprono come cartelle

Uno ZIP o CBZ si sfoglia come una cartella normale - con presentazione, zoom e traduzione. Nulla viene estratto in anticipo e nulla resta dopo.

Disegna, ritaglia, salva

Pennello, rettangolo ed ellisse, una cornice di ritaglio dal vivo con maniglie, poi salva sull'originale o accanto. I tuoi dati EXIF viaggiano con l'immagine.

Un'animazione diventa un video

Un WEBP, APNG o GIF animato diventa un normale MP4 - con barra di scorrimento, pausa e colori pieni - e sostituisce l'originale. L'encoder si scarica solo se lo chiedi, e gli stessi formati lenti ora si riaprono all'istante.

La musica ha il suo schermo

Un MP3, WAV, M4A, WMA o OGG mostra la copertina dell'album - o un'animazione di onde e particelle quando non ce n'è - con titolo, artista, album e formato in basso. Impostazioni dedicate decidono cosa succede alla fine di un brano, e un timer di spegnimento ferma la riproduzione entro tre ore.

Un server come una cartella

Un server SFTP o una condivisione di rete con accesso si apre come una cartella normale: immagini, video e documenti vengono scaricati mentre sfogli, la chiave del server viene memorizzata e la password resta cifrata per il tuo account Windows.

Immagini JPEG XL

Apri immagini JXL statiche e animate nel visualizzatore a 64 bit senza codec Windows aggiuntivi. Salva le modifiche in PNG, JPEG o WEBP; il salvataggio JXL non è disponibile.

Trasmissione in diretta

Condividi schermo, singola finestra, fotocamera, microfono o audio di sistema da Share Manager. Apri una diretta nel visualizzatore a 64 bit tramite link, codice o file .fmsbcast. La cattura inizia solo premendo Avvia.
