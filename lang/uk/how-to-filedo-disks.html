Спільний доступ до віртуальних дисків FileDO .fdd на телефоні

Fast Media Sorter & Sharing for Windows уміє відкривати ваші віртуальні диски .fdd програми FileDO для сполучених Android-пристроїв та SFTP-клієнтів. FileDO реєструє диск через локальний іменований канал, а Fast Media Sorter бере на себе монтування контейнера та безпечну передачу через SFTP без створення спільних тек SMB і без відкриття мережевих портів у самому FileDO. Потрібен Share Manager - тип встановлення Повна, 64-бітна Windows 10 версії 1607 або новіша - і необов'язковий компонент Хост віртуальних дисків FileDO, який не позначений в жодному типі встановлення.

Повна прозорість для клієнтів (контракт DISK-SHARE)

Для сполучених телефонів та SFTP-клієнтів спільний диск FileDO виглядає точнісінько як звичайна спільна тека. Для дискових коренів не існує жодних нових статусів, прихованих службових позначок чи нових кодів помилок (правила 25-28). Закритий або заблокований диск виглядає для клієнта точно так само, як звичайна тека, шлях до якої тимчасово недоступний.

Покрокове налаштування та відкриття диска

Позначте додатковий компонент «Хост віртуальних дисків FileDO»

Під час встановлення Fast Media Sorter & Sharing for Windows позначте додатковий компонент Хост віртуальних дисків FileDO. Без нього воркер повідомляє, що підтримка дисків вимкнена, і діалог FileDO попередить, що «спільний доступ до дисків недоступний». Вбудований filedo.exe береться суворо з останнього релізу FileDO на GitHub (настільна збірка GitHub/winget, у жодному разі не пакет Microsoft Store MSIX, який не вміє монтувати контейнери) і перевіряється за SHA256 (файли payload/filedo/filedo.exe, filedo.sha256 та release.json, правила 2-5).

Запустіть Share Manager

Запустіть Fast Media Sorter & Sharing та відкрийте Share Manager (Менеджер спільного доступу) з переглядача або піктограми в треї. Fast Media Sorter виступає хостом і власником спільних дисків, тому його воркер повинен працювати й відповідати через локальний іменований канал, перш ніж FileDO зможе зареєструвати контейнер. Уперше натисніть там Увімкнути функції сервера.. (один раз знадобиться підтвердження адміністратора - див. посібник для Android).

Зареєструйте диск у FileDO або Share Manager

У Диспетчері дисків FileDO виберіть зареєстрований контейнер .fdd і натисніть «Поділитися через Fast Media Sorter & Sharing..» (Ctrl+Shift+S). Або відкрийте Share Manager → Диски .fdd.. → Підключити .fdd.., щоб вибрати контейнер безпосередньо. Вкажіть назву кореня, яку побачать телефони. Доступ - читання та запис, доки ви не позначите Лише читання; sealed-контейнери завжди суворо лише для читання.

Правило одного власника (Holder)

У контейнера може бути лише один власник одночасно: none (ніхто), FileDO, FMS Service (служба Windows у серверній редакції) або FMS Session (воркер у сеансі користувача). Якщо диск уже змонтовано локально у FileDO, FileDO запитає підтвердження і коректно відключить його перед передачею в FMS. Якщо диск тримає FMS, спроба змонтувати його у FileDO буде відхилена із зазначенням поточного власника.

Автозапуск та безпечне зберігання ключів

Колонка «Автозапуск» у вікні «Диски .fdd..» показує «Так» або «Ні» для кожного диска; «-» означає, що робочий процес не підтримує це налаштування. У головному списку ресурсів також позначено рядки FileDO з увімкненим автозапуском. Кнопка «Автозапуск..» змінює налаштування; обидва списки оновлюються автоматично. Автозапуск показує налаштування, а «Стан» - чи відкрито диск, закрито або сталася помилка. Виберіть диск, щоб прочитати помилку відновлення під таблицею.

Автозапуск налаштовується окремо для кожного диска за явної згоди користувача. Для зашифрованого диска введення пароля дозволяє автоматично відкривати його після перезавантаження без передачі секретів на телефон. Ключ захищається Windows DPAPI: машинним сховищем під службою Server edition (FastMediaSorterCompanionSFTP) або сховищем користувача під User edition. Ключ ніколи не записується в сам контейнер чи в журнали і негайно знищується у разі вимкнення автозапуску, припинення спільного доступу чи зміни пароля.

Підключіть телефон через SFTP

У застосунку FastMediaSorter на Android виберіть Додати ресурс → SFTP/FTP → Імпорт із компаньйона та відскануйте QR-код із Share Manager. Відкритий диск FileDO з'явиться поруч зі звичайними спільними теками, дозволяючи переглядати та відкривати медіафайли. Закриття диска зберігає його реєстрацію для швидкого повторного відкриття в один клік; припинення спільного доступу видаляє його повністю.

Усунення несправностей та стани воркера

«FMS працює, але спільний доступ до дисків недоступний»

Оновіть Fast Media Sorter & Sharing for Windows і переконайтеся, що в інсталяторі було позначено додатковий компонент «Хост віртуальних дисків FileDO». Потім повторіть перевірку в Диспетчері дисків FileDO.

«Worker FMS недоступний»

Запустіть Fast Media Sorter & Sharing та відкрийте Share Manager. Якщо програму ще не встановлено на цьому комп'ютері, завантажте та встановіть її зі сторінки завантаження.

«Автентичність worker не підтверджена»

Облікові дані не надсилалися через неперевірений канал. Перезапустіть установлений хост або службу Fast Media Sorter і повторіть спробу.

«Відповідь FMS неповна або несумісна»

Розбіжність версій між компонентами. Оновіть обидва застосунки — FileDO та Fast Media Sorter & Sharing — до актуальних версій і повторіть спробу.

Проєкт FileDO та довіра до інсталятора

Як і Fast Media Sorter, настільний інсталятор FileDO не має комерційного цифрового підпису, тому SmartScreen Windows може показати попередження про невідомого видавця. Ознайомтеся з посібником FileDO щодо довіри до інсталятора та відвідайте головний сайт FileDO. Дзеркальний посібник з боку FileDO опубліковано на сторінці FileDO: спільний доступ через FMS.
