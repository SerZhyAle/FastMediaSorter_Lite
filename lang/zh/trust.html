为什么 Windows 会对这个下载发出警告

Fast Media Sorter for Windows 是一位独立开发者写的免费小程序。发布在 GitHub 上的版本（winget 安装的也是它们）没有代码签名，所以 Windows 会格外谨慎地对待它们，您可能会遇到一两条警告。下面说明每条警告是什么、为什么出现、到底该点哪里，以及这个程序从不做什么。

这条警告是什么

取决于您下载的是哪一种，共有三种。

  • «Windows 已保护你的电脑» - 这是 SmartScreen。第一次运行安装程序或便携版 ZIP 中的程序时出现。
  • «你要允许此应用对你的设备进行更改吗？» - 这是 Windows 的管理员权限请求。只有当您选择为所有用户安装，或打开文件夹共享时，才会出现它；第四节说明两者各自用这些权限做了什么。
  • 杀毒软件对单文件下载的警告，只有 2026 年 6 月 12 日之前的版本提供过这种下载。Microsoft Defender 将其自解压引导程序判为 Program:Script/Wacapew.A!ml。这是这类文件的已知误报；安装程序和便携版 ZIP 不受影响。

为什么会出现

没有任何东西出错，这条警告也不是错误。SmartScreen 对一个文件问两件事：它是否用 Windows 认识的证书签名，以及是否已有足够多的人运行过它。

  • 未签名。代码签名证书每年要几百美元。程序免费，也没有收入，所以没有购买证书 - 这是一个决定，不是疏忽。
  • 尚不知名。信誉是按文件计算的，因此每个新版本都从零开始。随着这个版本被下载，它会自行积累 - 所以警告在版本之间会淡去，每出一个新版本又会回来一阵子。
  • Microsoft Store 版本是例外：Microsoft 在认证时为它签名，因此那里不会出现这些。程序是同一个。

到底该点哪里

两次点击，而且这里没有任何一步会削弱您的防护。

  • SmartScreen：在对话框中点击「更多信息」，然后点击「仍要运行」。就这样。
  • 管理员请求：先读下一节，然后回答「是」。对文件夹共享的请求回答「否」，程序照样完整安装并运行 - 只是共享保持关闭。安装程序本身只有在您选择为所有用户安装时才需要这个请求。
  • 杀毒软件：如果文件被隔离，请将它还原，并为那一个安装文件夹添加例外。绝不要关闭 SmartScreen，也绝不要停用杀毒软件 - 这里都不需要，而它们会继续保护您下载的其他一切。
  • 如果您更愿意验证而不是相信：每个版本旁边都有一个 .sha256 文件，在 PowerShell 中运行 Get-FileHash <文件> -Algorithm SHA256 应当输出相同的值。源代码是公开的。

管理员权限用来做什么，以及如何收回

查看器本身从不请求管理员权限。只有当您选择为所有用户安装时，安装程序才会请求；只有当您打开文件夹共享时，共享才会请求。下面逐项列出每种用途，然后是撤销方法。

  • 为所有用户安装 - 您在安装程序中的选择。安装程序先询问是只为您安装（不需要管理员权限），还是为这台电脑上的所有账户安装。只有第二种情况 Windows 才会询问，以便把程序放进 Program Files，并把快捷方式放到每个账户都能看到的位置。
  • 文件夹共享 - 一条防火墙规则。当您打开共享时（在安装程序中，或之后在 Share Manager 中），Windows 会询问一次，并为 companion\fms-share-worker.exe 添加一条入站防火墙规则。它只允许这一个程序接收连接，不做别的。共享未打开时，没有任何东西在监听，也不会添加任何东西。
  • 常驻共享 - 一个 Windows 服务。只有在您自己要求时才会有，方式有两种：在 Share Manager 的「管理器设置」、「托管」中点「将共享切换为 Windows 服务..」，或者使用您自己下载并运行的单独 Server 安装程序。Windows 询问一次，然后做四件事：注册服务 FastMediaSorterCompanionSFTP，以 LOCAL SERVICE 身份运行；把防火墙规则指向该服务运行的那份共享程序副本；允许 LOCAL SERVICE 读取您共享的每个文件夹，并且只在您允许写入的地方写入；把共享设置、密码和主机密钥移到 %ProgramData%\FastMediaSorterCompanion，这个文件夹只有管理员、该服务和您的账户能打开。
  • 不卸载也能收回：打开 Share Manager 的「管理器设置」。「网络」中的「关闭服务器功能..」删除防火墙规则；「托管」中的「移除服务器角色」停止并删除服务，收回它对文件夹的权限，并删除防火墙规则；「托管」中的「返回用户版..」同样删除服务和文件夹权限，但会把共享连同其防火墙规则交还给您自己的会话。每个操作都会让 Windows 询问一次。
  • 或者卸载：Windows 设置「应用」中的每一项只删除它自己添加的内容。FastMediaSorter LITE 删除自己的防火墙规则（如果是只为您安装的，Windows 会为此询问一次），并提议删除其 Share Manager 注册的服务。Fast Media Sorter Folder Share Server 删除自己的服务、文件夹权限和防火墙规则。静默卸载（例如 winget uninstall）无法询问，因此会保留 Share Manager 注册的服务，只为您安装时还会保留防火墙规则；请先在 Share Manager 中关闭它们。
  • 有意保留：主机密钥、密码和文件夹列表保存在 %LOCALAPPDATA%\FastMediaSorterCompanion 中（如果共享曾以服务方式运行，则在 %ProgramData%\FastMediaSorterCompanion 中），这样重新安装后已配对的手机可以重新连接。删除该文件夹后，每部手机都需要重新配对。

这个程序从不做什么

与隐私页面以及 Microsoft Store 数据安全问卷上的说法完全一致 - 真相只有一个。

  • 没有遥测、没有分析、没有账户、没有广告。开发者收不到关于您或您如何使用程序的任何信息 - 除非您点「把日志发送给作者」，它会在您自己的邮件程序中打开一封邮件，由您检查后亲自发送。
  • 它从不自行把您的文件发送到任何地方。共享时，您的手机通过加密的 SFTP 连接直接连到您的电脑。
  • 它从不自行开放端口，也从不自行请求管理员权限。共享在您打开之前一直关闭，窗口始终显示什么可以访问、从哪里可以访问。
  • 只有在您要求、或同意一个明确说明要下载什么的提示之后，它才会下载东西：OCR 语言包、OCR 或视频播放运行库、视频编码器 FFmpeg、Ollama 安装程序或其翻译模型，或通过 winget 安装 doc-html-translate。请求中不带任何关于您文件的信息。
  • 您翻译的文本只会发送到您自己设置的翻译地址 - 您自己机器上的模型，或您指定的服务器。

只有一项第三方服务可能被访问，而且只在您为共享打开互联网访问时：程序会请 check-host.net 确认您转发的端口能否从外部响应，这会让该服务看到您的公网地址和端口。除此之外不会向它发送任何内容。另外两件事只在您自己的网络内进行：打开互联网访问后，程序会请您的路由器转发共享端口（UPnP 或 NAT-PMP）；共享运行期间，电脑会在局域网中广播自己（mDNS），以便已配对的手机重新找到它。
