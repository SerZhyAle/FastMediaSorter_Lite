Windows 上的 Fast Media Sorter

飞快地翻阅海量照片和视频文件夹，一个按键就能移动、复制、重命名或删除每个文件。

值得一提

  • 免费，开源。
  • 两个版本一起发布：面向 Windows 10/11 的现代 64 位版，以及面向 Windows 7 和 8.1 的 32 位备用版。安装程序会自动选对。
  • 界面提供 13 种语言 - 查看器与共享管理器均支持，且共用同一设置。
  • 共享可以全天候运行：在 Share Manager 中可以交给 Windows 服务，它从开机起提供服务，无人登录也照常。单独的服务器版会立刻安装同一个服务，适合无屏幕运行的机器。
  • 安装程序自带离线内容 - VLC 编解码器、OCR 模型和 Share Manager - 无论有没有管理员权限都会全部安装。

一个文件一个键

把文件夹绑定到 1-9、0 和 Del 键，然后全程不碰鼠标就整理完一个文件夹。按住 Shift 则是复制而不是移动。

幻灯片与面板

自动或随机幻灯片，还有缩略图面板，直接跳到想看的那张。

几乎什么都能播

视频走内置的 VLC 引擎 - H.264/MP4、MKV、AVI、VP9 等等。

Ambilight 背景

照片旁边的空白色块不再是黑的，而是取自照片本身的颜色。

离线 OCR 翻译

识别图片上的文字并把译文叠在原处 - 图片不会被发到任何地方。

用 SFTP 分享文件夹

把你挑选的文件夹通过 SFTP 发布，在 Android 应用里打开 - 也可以用任何 SFTP 客户端连接。默认关闭，你不开它就不动。
