Fast Media Sorter & Sharing for Windows

Windows desktop app

Free & open-source

用一个按键整理每个照片和视频文件

三个可选部分：用于媒体的查看与整理工具、通过 SFTP 共享文件夹的本地服务，以及 Media Exchange Server（开发中，尚未发布）——可以从查看器开始，也可以从文件夹共享服务器开始，其余的只在您需要时再添加。

飞快地翻阅海量照片和视频文件夹，一个按键就能移动、复制、重命名或删除每个文件。

名称中的「Sharing」指把你的媒体交给别人：你的 Android 手机、本程序的另一份副本，或任何 SFTP 客户端。你不开启它，它就保持关闭。 Share folders to Android over SFTP

先用服务器

我想为我的文件夹配一台服务器

在 Android 手机、本程序的另一份副本或任何 SFTP 客户端中打开这台电脑的文件夹。服务器版（setup.exe 或 winget，需要管理员权限）把文件夹共享服务安装为 Windows 服务，无人登录时也能运行；查看器是可选的附加项，默认不勾选。它不会安装 Media Exchange Server（开发中）。

Media Exchange Server

开发中，尚未包含在任何安装包里，因此没有可下载的内容。它是一台需要您自己运行的独立服务器，面向无法直接互相访问的设备。它不是文件夹共享，查看器和本地共享都不需要它。

#值得一提

  • 免费，开源。
  • 两个版本一起发布：面向 Windows 10/11 的现代 64 位版，以及面向 Windows 7 和 8.1 的 32 位备用版。安装程序会自动选对。
  • 界面提供 13 种语言 - 查看器与共享管理器均支持，且共用同一设置。
  • 共享可以全天候运行：在 Share Manager 中可以交给 Windows 服务，它从开机起提供服务，无人登录也照常。单独的服务器版会立刻安装同一个服务，适合无屏幕运行的机器。
  • 安装程序自带离线内容 - VLC 编解码器、OCR 模型和 Share Manager - 无论有没有管理员权限都会全部安装。

01Fast Media Sorter & Sharing for Windows - 功能

一个文件一个键

把文件夹绑定到 1-9、0 和 Del 键，然后全程不碰鼠标就整理完一个文件夹。按住 Shift 则是复制而不是移动。

幻灯片与面板

自动或随机幻灯片，还有缩略图面板，直接跳到想看的那张。

几乎什么都能播

视频走内置的 VLC 引擎 - H.264/MP4、MKV、AVI、VP9 等等。

Ambilight 背景

照片旁边的空白色块不再是黑的，而是取自照片本身的颜色。

离线 OCR 翻译

识别图片上的文字并把译文叠在原处 - 图片不会被发到任何地方。

用 SFTP 分享文件夹

把你挑选的文件夹通过 SFTP 发布，在 Android 应用里打开 - 也可以用任何 SFTP 客户端连接。默认关闭，你不开它就不动。

StreamsPlayer 广播

在 64 位查看器中，右键点击视频、音频文件或其文件夹并选择广播。Share Manager 导出 .spres 文件、二维码或快速链接，供 StreamsPlayer 导入。文件夹成为一个包含固定播放列表的频道；刷新会替换列表，撤销会停用链接。HTTP 网关有独立开关，默认关闭。每个令牌只允许读取一个广播，通常在 24 小时后过期。HTTP 未加密：请私下分享文档，仅在需要时启用互联网访问。

撤销，以及真正的回收站

Del 把文件送进回收站，Shift+Del 绕过它，U 则回退最近 50 步操作 - 包括重命名和删除。在 Windows 根本没有回收站的地方，程序会直说，而不是假装。

压缩包像文件夹一样打开

ZIP 或 CBZ 可以像普通文件夹一样浏览 - 幻灯片、缩放和翻译都在。事先不解包，事后不留痕。

在图片上绘制、裁剪、保存

画笔、矩形和椭圆，带控制点的实时裁剪框，然后覆盖原图保存或另存到旁边。EXIF 数据随图片一起走。

把动画变成真正的视频

动画 WEBP、APNG 或 GIF 会变成普通的 MP4 - 有进度条、可暂停、色彩完整 - 并取代原文件。编码器只在你要求时才下载，而这些原本很慢的格式现在第二次打开是瞬间的。

音乐也有了自己的画面

MP3、WAV、M4A、WMA 或 OGG 会显示专辑封面 - 没有封面时则显示波纹与粒子动画 - 底部列出标题、艺术家、专辑和格式。专属设置决定曲目结束时的行为，睡眠定时器最多三小时后停止播放。

把服务器当作文件夹

需要登录的 SFTP 服务器或网络共享可像普通文件夹一样打开：翻页时按需取回图片、视频和文档，服务器密钥会被记住，密码则以加密形式仅供您的 Windows 账户使用。
