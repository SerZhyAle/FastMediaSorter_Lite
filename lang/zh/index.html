01Fast Media Sorter & Sharing for Windows - Features

一个文件一个键

把文件夹绑定到 1-9、0 和 Del 键，然后全程不碰鼠标就整理完一个文件夹。按住 Shift 则是复制而不是移动。

幻灯片与面板

自动或随机幻灯片，还有缩略图面板，直接跳到想看的那张。

几乎什么都能播

视频走内置的 VLC 引擎 - H.264/MP4、MKV、AVI、VP9 等等。

Ambilight 背景

照片旁边的空白色块不再是黑的，而是取自照片本身的颜色。

离线 OCR 翻译

识别图片上的文字并把译文叠在原处 - 图片不会被发到任何地方。

用 SFTP 分享文件夹

把你挑选的文件夹通过 SFTP 发布，在 Android 应用里打开 - 也可以用任何 SFTP 客户端连接。默认关闭，你不开它就不动。

撤销，以及真正的回收站

Del 把文件送进回收站，Shift+Del 绕过它，U 则回退最近 50 步操作 - 包括重命名和删除。在 Windows 根本没有回收站的地方，程序会直说，而不是假装。

压缩包像文件夹一样打开

ZIP 或 CBZ 可以像普通文件夹一样浏览 - 幻灯片、缩放和翻译都在。事先不解包，事后不留痕。

在图片上绘制、裁剪、保存

画笔、矩形和椭圆，带控制点的实时裁剪框，然后覆盖原图保存或另存到旁边。EXIF 数据随图片一起走。

把动画变成真正的视频

动画 WEBP、APNG 或 GIF 会变成普通的 MP4 - 有进度条、可暂停、色彩完整 - 并取代原文件。编码器只在你要求时才下载，而这些原本很慢的格式现在第二次打开是瞬间的。

音乐也有了自己的画面

MP3、WAV、M4A、WMA 或 OGG 会显示专辑封面 - 没有封面时则显示波纹与粒子动画 - 底部列出标题、艺术家、专辑和格式。专属设置决定曲目结束时的行为，睡眠定时器最多三小时后停止播放。

把服务器当作文件夹

需要登录的 SFTP 服务器或网络共享可像普通文件夹一样打开：翻页时按需取回图片、视频和文档，服务器密钥会被记住，密码则以加密形式仅供您的 Windows 账户使用。
