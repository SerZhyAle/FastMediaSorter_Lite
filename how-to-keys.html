HOW TO · KEYS & VIEW

Every key, and how to make the picture fill the screenВсе клавиши и как показать картинку во весь экран

The program is built around single keys, so a folder can be reviewed with one hand. Nothing here has to be memorized at once - F1 shows the short version inside the program at any time.Программа построена на одиночных клавишах, поэтому папку можно разобрать одной рукой. Запоминать всё сразу не нужно - F1 в любой момент покажет краткую версию прямо в программе.

Make the keys your ownСделайте клавиши своими

In the 64-bit program, F2 → Files and system → Keyboard shortcuts reassigns the actions to the keys you prefer. System combinations, F11 and Esc stay with the program.В 64-битной программе F2 → Файлы и система → Сочетания клавиш позволяет переназначить действия на удобные вам клавиши. Системные сочетания, F11 и Esc остаются за программой.

What the 32-bit build does not haveЧего нет в 32-битной сборке

Zoom on the grey numpad keys, Shift+digit copying, the audio and subtitle keys, the mouse menus and the shortcut editor ship in the 64-bit build for Windows 10 and 11. The fallback for Windows 7 and 8.1 keeps the historical keys, and its own F1 help never advertises the rest.Масштаб на серых клавишах, копирование по Shift+цифра, клавиши дорожек и субтитров, меню мыши и редактор сочетаний есть в 64-битной сборке для Windows 10 и 11. Сборка для Windows 7 и 8.1 сохраняет исторические клавиши, и её собственная справка F1 не обещает лишнего.
