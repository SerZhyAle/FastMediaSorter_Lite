HOW TO · RESOURCES

Open a server or a network share like a folderОткрыть сервер или сетевую папку как обычную папку

A family NAS, a PC that shares folders with the Share Manager, any SFTP server, a network share that wants a password: add it once, and its pictures and videos page through like files on disk - with the key to the server checked every time.Домашний NAS, компьютер, раздающий папки через Share Manager, любой SFTP-сервер, сетевая папка с паролем: добавьте её один раз - и картинки с видео листаются как файлы на диске, а ключ сервера проверяется при каждом подключении.

Add the serverДобавьте сервер

Right-click the folder box, choose "Resources" - "Manage resources.." and press "Add..": the address, the port (22 by default), the user, the password and the folder on the server. A network share that needs a login is the second type in the same window. Already have a file from the Share Manager? Press "Import from file.." - or "Import from clipboard" for the text of a code - and everything, including the server's key, comes in at once. You can also drop the .fmscfg file on the viewer window.Щёлкните правой кнопкой по полю каталога, выберите «Ресурсы» - «Управление ресурсами..» и нажмите «Добавить..»: адрес, порт (по умолчанию 22), пользователь, пароль и папка на сервере. Сетевая папка с паролем - второй тип в том же окне. Есть файл из Share Manager? Нажмите «Импорт из файла..» - или «Импорт из буфера» для текста кода, - и всё, включая ключ сервера, добавится сразу. Файл .fmscfg можно и просто перетащить на окно просмотрщика.

Open itОткройте

Choose the resource in the list and press "Open" - or pick it from the "Resources" submenu, where the last few you used wait one click away. Typing sftp://user@host:port/folder in the folder box and pressing Enter does the same, and the program opens it again on the next start if that was the folder you left. The first time, a server added by hand shows the fingerprint of its key and asks whether to trust it; the default answer is No. A file from the Share Manager brings the key with it, so that very first connection is already checked.Выберите ресурс в списке и нажмите «Открыть» - или найдите его в подменю «Ресурсы», где несколько последних ждут в один щелчок. То же делает адрес sftp://пользователь@сервер:порт/папка, набранный в поле каталога, и Enter; если вы ушли с этой папки, при следующем запуске программа откроет её снова. В первый раз сервер, добавленный вручную, покажет отпечаток своего ключа и спросит, доверять ли ему; ответ по умолчанию - «Нет». Файл из Share Manager приносит ключ с собой, поэтому проверка идёт уже при первом подключении.

Browse and sort as usualЛистайте и разбирайте как обычно

Pictures, video, audio and documents open as if they were on this PC: the program fetches the file it is about to show and the next one, and throws the copies away when you leave. RE asks the server again. Del, 0-9, Shift+digit, F6 and U act on the server's own files; a move is proven by content before the original is touched, so a dropped connection never loses a file. A folder the owner shared as read-only says so instead of failing half-way.Картинки, видео, звук и документы открываются так, будто лежат на этом компьютере: программа подгружает файл, который собирается показать, и следующий, а копии удаляет, когда вы уходите. RE заново спрашивает сервер. Del, 0-9, Shift+цифра, F6 и U действуют на файлы самого сервера; перемещение проверяется по содержимому до того, как оригинал тронут, поэтому оборванное соединение не теряет файлов. Папка, которую владелец раздал только для чтения, честно об этом говорит, а не падает на полпути.

Sort straight into a server folderСортируйте прямо в папку на сервере

A 0-9 destination can be a folder of a saved server: in Settings, double-click the slot's folder and pick the resource instead of "A folder on this PC..", then type a subfolder after the address if you want one. The slot shows the resource's name; the first key press connects (it asks for the password once if none is remembered), and the file is sent, read back and compared before the original is deleted. A slot works only with a server whose key the program already knows - open the resource once first - and never with one shared read-only. Taking a move back with U brings the file home and keeps the server's copy as well, because the program cannot be sure no one changed it there in the meantime; it says so.Папкой назначения 0-9 может быть папка сохранённого сервера: в настройках дважды щёлкните по папке слота и выберите ресурс вместо «Папка на этом компьютере..», а при желании допишите после адреса подпапку. Слот показывает имя ресурса; первое нажатие подключается (один раз спросит пароль, если он не запомнен), файл отправляется, читается обратно и сверяется до того, как удалить оригинал. Слот работает только с сервером, ключ которого программа уже знает, - сначала откройте ресурс один раз, - и никогда с ресурсом только для чтения. Отмена перемещения клавишей U возвращает файл домой и оставляет копию на сервере, потому что программа не может быть уверена, что там его за это время никто не изменил; она об этом говорит.

If the key changesЕсли ключ изменился

A server whose key is not the one remembered is refused, and both fingerprints are shown: a reinstalled server looks exactly like an impostor. If you are sure of the server, open the resource with "Edit.." and use "Forget the server key.." - a deliberate button, never a prompt that can be dismissed by accident.Сервер, чей ключ не совпал с запомненным, не пускается, и показываются оба отпечатка: переустановленный сервер выглядит точно так же, как подделка. Если вы уверены в сервере, откройте ресурс через «Изменить..» и нажмите «Забыть ключ сервера..» - это осознанная кнопка, а не вопрос, который можно закрыть случайно.

Not yet, and 64-bit onlyПока нельзя, и только в 64-битной

A shared folder that the Share Manager locked with a PIN makes the whole file refuse to import, because the viewer cannot open it unlocked. The password is kept only encrypted for your Windows account (or in memory, if you untick "Remember"). The 32-bit fallback for Windows 7 and 8.1 does not have resources at all.Общая папка, закрытая в Share Manager PIN-кодом, заставляет отказаться от импорта всего файла: просмотрщик не умеет открывать её без замка. Пароль хранится только в зашифрованном виде для вашей учётной записи Windows (или в памяти, если снять «Запомнить»). В 32-битной сборке для Windows 7 и 8.1 ресурсов нет вовсе.
