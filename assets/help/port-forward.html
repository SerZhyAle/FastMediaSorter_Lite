Router admin screens are almost always in English - the terms below are what you look for, whatever your router brand.

Step by step

  1. Open your router's admin page: __ROUTER_URL__ in a browser. If it does not open, the address may be printed on a sticker under the router.
  2. Sign in. The username/password are usually on that sticker (common defaults: admin / admin, or admin / password).
  3. Find the section called Port Forwarding - it may also be named Virtual Server, NAT Forwarding, NAT, Applications & Gaming, or WAN → Virtual Server.
  4. Add a new rule with the values from the box above: external port __EXT_PORT__, internal IP __LAN_IP__, internal port __PORT__, protocol TCP. Give it any name (e.g. "FastMediaSorter").
  5. Enable the rule and click Save / Apply. Reboot the router if it asks.
  6. Back in FastMediaSorter, re-scan the QR code (or save the .fmscfg again) on the phone. The external address is already in the code - it starts working once the rule is active.
Not working?
  1. External IP changes: most home providers rotate the public address. If remote access stops, open this window again to see the new address, or set up a free Dynamic DNS (DDNS) name in your router.
  2. CGNAT: if FastMediaSorter said your provider uses CGNAT, port forwarding cannot help - ask the provider for a public/"white" IP, or use the local network only.
  3. Windows Firewall: the first time sharing runs, allow it through the Windows Defender Firewall prompt (Private + Public). Otherwise incoming connections are blocked.
  4. Double router: if you have two routers (e.g. ISP box + your own), forward the port on both, or put your router in bridge mode.

Интерфейс роутера почти всегда на английском - ниже указано, какие пункты искать, независимо от марки роутера.

Пошагово

  1. Откройте страницу настроек роутера: __ROUTER_URL__ в браузере. Если не открывается, адрес обычно есть на наклейке снизу роутера.
  2. Войдите. Логин и пароль тоже обычно на наклейке (частые по умолчанию: admin / admin или admin / password).
  3. Найдите раздел Port Forwarding (проброс портов). Он же может называться Virtual Server, NAT Forwarding, NAT, Applications & Gaming или WAN → Virtual Server.
  4. Добавьте новое правило со значениями из рамки выше: внешний порт __EXT_PORT__, внутренний IP __LAN_IP__, внутренний порт __PORT__, протокол TCP. Имя - любое (например, "FastMediaSorter").
  5. Включите правило и нажмите Save / Apply (Сохранить / Применить). Перезагрузите роутер, если он попросит.
  6. Вернитесь в FastMediaSorter и заново отсканируйте QR-код (или сохраните .fmscfg) на телефоне. Внешний адрес уже в коде - он заработает, как только правило станет активным.
Не работает?
  1. Внешний IP меняется: у большинства домашних провайдеров публичный адрес непостоянный. Если доступ пропал - откройте это окно снова и посмотрите новый адрес, либо настройте бесплатный Dynamic DNS (DDNS) в роутере.
  2. CGNAT: если FastMediaSorter написал про CGNAT у провайдера - проброс портов не поможет. Попросите у провайдера публичный ("белый") IP или пользуйтесь только локальной сетью.
  3. Брандмауэр Windows: при первом запуске общего доступа разрешите его в окне брандмауэра Windows (Частная + Публичная сеть). Иначе входящие подключения блокируются.
  4. Два роутера: если роутеров два (например, коробка провайдера + ваш) - пробросьте порт на обоих, либо переведите свой роутер в режим моста (bridge).

Інтерфейс роутера майже завжди англійською - нижче вказано, які пункти шукати, незалежно від марки роутера.

Покроково

  1. Відкрийте сторінку налаштувань роутера: __ROUTER_URL__ у браузері. Якщо не відкривається, адреса зазвичай є на наклейці знизу роутера.
  2. Увійдіть. Логін і пароль теж зазвичай на наклейці (типові за замовчуванням: admin / admin або admin / password).
  3. Знайдіть розділ Port Forwarding (проброс портів). Він також може називатися Virtual Server, NAT Forwarding, NAT, Applications & Gaming або WAN → Virtual Server.
  4. Додайте нове правило зі значеннями з рамки вище: зовнішній порт __EXT_PORT__, внутрішній IP __LAN_IP__, внутрішній порт __PORT__, протокол TCP. Назва - будь-яка (наприклад, "FastMediaSorter").
  5. Увімкніть правило та натисніть Save / Apply (Зберегти / Застосувати). Перезавантажте роутер, якщо він попросить.
  6. Поверніться у FastMediaSorter і заново відскануйте QR-код (або збережіть .fmscfg) на телефоні. Зовнішня адреса вже у коді - вона запрацює, щойно правило стане активним.
Не працює?
  1. Зовнішній IP змінюється: у більшості домашніх провайдерів публічна адреса непостійна. Якщо доступ зник - відкрийте це вікно знову й подивіться нову адресу, або налаштуйте безкоштовний Dynamic DNS (DDNS) у роутері.
  2. CGNAT: якщо FastMediaSorter написав про CGNAT у провайдера - проброс портів не допоможе. Попросіть у провайдера публічну ("білу") IP або користуйтеся лише локальною мережею.
  3. Брандмауер Windows: під час першого запуску спільного доступу дозвольте його у вікні брандмауера Windows (Приватна + Публічна мережа). Інакше вхідні з'єднання блокуються.
  4. Два роутери: якщо роутерів два (наприклад, коробка провайдера + ваш) - пробросьте порт на обох, або переведіть свій роутер у режим мосту (bridge).
