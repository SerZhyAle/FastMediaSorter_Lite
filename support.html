Support

Getting help

Fast Media Sorter & Sharing for Windows is made and supported by one person. Questions, problems and ideas are welcome.

Report a problem or ask a question

The issue tracker is the best place: a report there stays visible to everyone who meets the same problem, and the answer helps them too.

  • Open the issue tracker

Write by e-mail

If you would rather not use GitHub, write to sza@ukr.net.

What to include

  • Your Windows version, and whether you run the 64-bit program or the 32-bit fallback.
  • What you did, what you expected and what happened instead; a screenshot helps.
  • The log: on the About page of the settings, the "Send the logs to the author" button packs the program's log and opens your mail program with the archive attached. The program never sends anything itself - the message leaves when you press Send.

Before you write

  • Windows warns about an unknown publisher (SmartScreen)
  • All guides, by task
  • What's new in the latest versions
  • Privacy

What to expect

This is a one-person project: there is no support contract and no promised response time. Messages are read in the order they arrive, and a report with the steps to repeat the problem is answered fastest.
