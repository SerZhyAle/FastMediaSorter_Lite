# Fast Media Sorter for Windows

Fast Media Sorter for Windows (ранее FastMediaSorter LITE - в Microsoft Store и winget программа публикуется под прежним именем) - это приложение Windows Forms для быстрой сортировки, просмотра и управления файлами изображений и видео. Потому что папка с 4000 фотографий сама себя не разберёт. Поддерживает широкий спектр медиа-форматов и предоставляет следующие возможности:

- Быстрая навигация по большим папкам с изображениями и видео (даже по неприлично большим)
- Режимы слайд-шоу и случайного просмотра файлов
- Отслеживание недавних файлов и папок, чтобы не вспоминать, где вы остановились
- Операции с файлами: перемещение, копирование, переименование и удаление
- Панель изображений для быстрой визуальной навигации
- Автоматический поворот фото по тегу EXIF Orientation - на случай, если камеру держали боком
- Качественное (бикубическое) масштабирование - резче при уменьшении крупных изображений
- Необязательная подпись поверх изображения: имя файла и позиция (удобно в полноэкранном режиме)
- Настраиваемый интервал слайдшоу
- Регистрация приложения программой просмотра изображений и/или видеоплеером по умолчанию (для текущего пользователя, без танцев с правами администратора)
- Android Folder Share: превратите этот ПК в SFTP-сервер для собственных папок с медиа и файлами и открывайте их из Android-приложения - в домашней сети или через интернет, подключение по QR-коду (встроенный копилот для мобильной версии)
- OCR и перевод текста поверх изображения (локальные Ollama / LibreTranslate) - для картинок, что упорно говорят на чужом языке
- Настраиваемые горячие клавиши - тянуться к мыши уже немодно
- Многоязычная поддержка (английский/русский; при первом запуске берётся язык интерфейса Windows)
- Широкая поддержка видеоформатов: обычный H.264/MP4 играет прямо в окне, а всё,
  что встроенный плеер не может декодировать (AVI, ZMBV, VP9, MKV, WMV, ..),
  автоматически воспроизводится через встроенный движок **LibVLC** - без внешних
  кодеков и охоты за плагинами

## Мобильная версия 📱

Хотите сортировать медиа, не вставая с дивана? Попробуйте **FastMediaSorter v2** - мощное Android-приложение с поддержкой локальных файлов, сетевых дисков (SMB, SFTP, FTP) и облачных хранилищ (Google Drive, OneDrive, Dropbox):

🔗 **[Сайт FastMediaSorter для Android](https://serzhyale.github.io/FastMediaSorter_mob_v2/index-ru.html)** · **[GitHub](https://github.com/SerZhyAle/FastMediaSorter_mob_v2)**

Установить: **[Google Play](https://play.google.com/store/apps/details?id=com.sza.fastmediasorter)**, **[IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.sza.fastmediasorter)** или прямой **[APK со страницы релизов GitHub](https://github.com/SerZhyAle/FastMediaSorter_mob_v2/releases)**.

Возможности включают:
- Единый интерфейс для всех источников файлов (локальные, сетевые, облачные)
- Встроенный медиа-плеер и читалка EPUB
- Редактирование изображений (поворот, отражение, фильтры, настройки)
- Автоматический перевод с поддержкой OCR
- Система избранного и PIN-защита
- Продвинутые жесты и навигация с клавиатуры

**Десктоп как копилот:** Fast Media Sorter for Windows может выступать сервером для мобильного приложения. Его функция **Android Folder Share** поднимает встроенный SFTP-сервер для ваших собственных папок с медиа и файлами, и Android-приложение обращается к этому ПК напрямую - в домашней сети или через интернет - после однократного подключения по QR-коду. Смотрите пошаговое [руководство по публикации папок для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html).

## Использование

1. Выберите папку с вашими медиа-файлами (да, ту самую).
2. Перемещайтесь по файлам с помощью клавиатуры, мыши или экранных кнопок - как удобнее рукам.
3. Используйте панель и недавние файлы для быстрого доступа.
4. Перемещайте, копируйте или удаляйте файлы по необходимости. Нажали цифру - хаоса стало меньше.
5. Наслаждайтесь быстрой и эффективной сортировкой медиа и, может, наконец верните себе место на диске.

## Установка

### winget

```powershell
winget install --id SerZhyAle.FastMediaSorter
```

Пакет winget использует Inno Setup installer в тихом per-user режиме, поэтому
во время установки не показывает диалоги - просто молча делает своё дело.

### Релиз с GitHub

Скачайте свежие файлы со
[страницы релизов](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases):

- `FastMediaSorter-<version>-windows-x64-setup.exe` для самой простой установки
- `FastMediaSorter-<version>-windows-x64.zip` как portable offline-пакет

В обычном интерактивном setup можно сразу зарегистрировать программу
для распространённых форматов изображений. На Windows 10/11 система может ещё
раз попросить подтвердить выбор в разделе приложений по умолчанию.

Оба GitHub-релиза offline-ready: внутри уже есть VLC runtime и OCR языковые
пакеты, поэтому для воспроизведения медиа и OCR не нужен первый запуск с
дозагрузкой из сети.

Примечание: машинный перевод всё ещё зависит от выбранного провайдера - программа
щедрая, но переводить силой мысли не умеет. Для Ollama нужна отдельная локальная
установка модели, а облачным сервисам нужен доступ в сеть.
