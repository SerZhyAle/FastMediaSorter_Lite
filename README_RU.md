# Fast Media Sorter for Windows

Fast Media Sorter for Windows (ранее FastMediaSorter LITE - в Microsoft Store и winget программа публикуется под прежним именем) - это приложение Windows Forms для быстрой сортировки, просмотра и управления файлами изображений и видео. Потому что папка с 4000 фотографий сама себя не разберёт. Поддерживает широкий спектр медиа-форматов и предоставляет следующие возможности:

- Быстрая навигация по большим папкам с изображениями и видео (даже по неприлично большим)
- Режимы слайд-шоу и случайного просмотра файлов
- Отслеживание недавних файлов и папок, чтобы не вспоминать, где вы остановились
- Операции с файлами: перемещение, копирование, переименование и удаление
- Перенести или скопировать - решается в момент действия: цифра `1..9`/`0` переносит текущий файл в эту папку, **Shift + та же цифра верхнего ряда копирует его туда** - никакого режима, который надо заранее включить и потом не забыть выключить. Та же пара есть в панели получателей, в обоих меню на медиафайле и в таблице получателей (Shift + двойной клик). Переходить ли после копирования к следующему файлу - одна галочка в настройках, по умолчанию включена (только 64-битная программа)
- Панель получателей поверх медиа: плавающий список каталогов, назначенных на горячие клавиши - клик по строке переносит текущий файл туда, узкая зона рядом копирует его (или удаляет), чтобы сортировать одной рукой мышью (по умолчанию выключено; включается в настройках)
- Панель изображений для быстрой визуальной навигации
- Автоматический поворот фото по тегу EXIF Orientation - на случай, если камеру держали боком
- Качественное (бикубическое) масштабирование - резче при уменьшении крупных изображений
- Необязательная подпись поверх изображения: имя файла и позиция (удобно в полноэкранном режиме)
- Настраиваемый интервал слайдшоу
- Регистрация приложения программой просмотра изображений и/или видеоплеером по умолчанию (для текущего пользователя, без танцев с правами администратора)
- Общий доступ к папкам по SFTP («Android Folder Share»): превратите этот ПК в SFTP-сервер для выбранных папок и открывайте их из Android-приложения - или из любого другого SFTP-клиента - в домашней сети или через интернет, подключение по QR-коду. По умолчанию выключено; см. [Ваши папки по SFTP](#ваши-папки-по-sftp). Только в 64-битной программе
- OCR и перевод текста поверх изображения (локальные Ollama / LibreTranslate) - для картинок, что упорно говорят на чужом языке
- Фон «перспектива» (в духе Ambilight): полосы по бокам фото заливаются цветом, взятым с его собственных краёв, так что снимок стоит в своём свете, а не на чёрном. По желанию - в виде ореола, растворяющегося в фоне (64-битная программа)
- Масштаб от курсора мыши на серых клавишах NumPad, с перетаскиванием картинки (64-битная программа)
- Панель управления видео - перемотка, время, звук, громкость - плюс выбор звуковой дорожки и субтитров, запоминаемый по языку, и «Открыть URL..», чтобы играть видео прямо с `smb://`, `sftp://`, `http(s)://` и подобных (64-битная программа)
- Меню прямо на медиа: средняя кнопка на картинке, правая на видео (64-битная программа)
- Настраиваемые горячие клавиши - тянуться к мыши уже немодно
- **Интерфейс на 13 языках** - английский, русский, украинский, немецкий, итальянский, испанский, французский, португальский, арабский, хинди, бенгальский, урду и китайский. При первом запуске берётся язык интерфейса Windows; кнопка на панели переключает его в любой момент, и «Менеджер общего доступа» следует тому же выбору. Арабский и урду идут справа налево. Вычитаны автором только английский, русский и украинский - **остальные десять сделаны машиной и не вычитаны**, поправки через [issues](https://github.com/SerZhyAle/FastMediaSorter_Lite/issues) очень приветствуются. В 32-битной запасной сборке остаются только английский и русский (в Windows 7 нет шрифта для индийских письменностей), мастер установки остаётся английским.
- Широкая поддержка видеоформатов: всё (H.264/MP4, AVI, ZMBV, VP9, MKV, WMV, ..)
  играет прямо в окне через встроенный движок **LibVLC** - без внешних кодеков,
  без охоты за плагинами и без зависимости от того, стоит ли ещё в системе
  Internet Explorer

## Ваши папки по SFTP

Чтобы разобрать медиа, их не обязательно сначала куда-то копировать. **Android Folder Share**
превращает этот ПК в небольшой SFTP-сервер для выбранных вами папок: сортировщик, работающий на
другом устройстве, разбирает файлы там, где они уже лежат - ничего никуда не загружается, облачная
учётная запись не нужна, папки остаются на месте. Это обычный, стандартный SFTP-сервис, поэтому такие
папки открываются:

- **в FastMediaSorter для Android** - сценарий, ради которого всё и задумывалось: телефон сортирует
  фото и видео, лежащие на дисках этого ПК, по домашней сети Wi-Fi или через интернет, после однократного
  подключения по QR-коду (или экспортированному файлу `.fmscfg`).
- **в любом другом SFTP-клиенте** - WinSCP, FileZilla, файловый менеджер в Linux или macOS, другой ПК.
  Адрес и порт, логин, пароль и отпечаток ключа узла показаны в окне Share Manager, у каждого своя
  кнопка копирования.

Что это делает и чего сознательно не делает:

- **Видны только те папки, которые вы добавили**, каждая под заданным вами именем, и любую можно
  опубликовать только для чтения.
- **По умолчанию всё выключено.** Раздача спит, пока вы не включите **функции сервера** - галочкой при
  установке или разовой кнопкой в Share Manager, которая добавляет единственное нужное правило
  брандмауэра Windows. До этого сеть никто не слушает, и программа остаётся просто
  просмотрщиком/сортировщиком.
- **Соединение шифрованное и прямое** (SSH/SFTP), устройство - ПК напрямую. Клиент запоминает ключ узла
  этого ПК при первой привязке, так что подменённый сервер будет замечен, а не принят на веру.
- **Раздачей управляет отдельная программа** - «Fast Media Sorter: Share Manager» в трее, открывается
  правым кликом по полю папки в просмотрщике или из раздела Настройки &rarr; Файлы и система. Она сама
  64-битная - поэтому и раздача папок есть только в 64-битной программе.

Пошагово: [как пользоваться SFTP-сервисом](https://serzhyale.github.io/FastMediaSorter_Lite/how-to-sftp.html)
и подробное [руководство по публикации папок для Android](https://serzhyale.github.io/FastMediaSorter_Lite/publish-folders-android.html),
когда соединению нужно пройти через роутер.

**Вариант «всегда доступно» (по желанию):** по умолчанию папки видны, только пока вы вошли в систему и Share Manager запущен - для обычного ПК это правильно. Если же задача машины - быть доступной постоянно (выделенный сервер, VPS, домашний сервер), тот же воркер может поднимать служба Windows: она стартует с загрузкой, раздаёт без входа в систему и сама перезапускается при сбое. Путей два. Обычная установка переводится в этот режим прямо в Share Manager (**Управление хостингом.. -> Перевести раздачу в режим службы Windows..**, одно подтверждение администратора, которое заодно переносит состояние и выдаёт службе доступ к вашим папкам), либо ставится отдельная **[серверная редакция](https://serzhyale.github.io/FastMediaSorter_Lite/server.html)** (`winget install --id SerZhyAle.FastMediaSorter.Server`), которая настраивает ту же службу сразу - для машины, которую разворачивают, ни разу не открыв программу. В обоих случаях нужно однократное подтверждение администратора, и молча это не включается никогда: ни обычный установщик, ни winget, ни Store сами службу не регистрируют, а версия из Store не может этого в принципе. SFTP, привязка по QR/`.fmscfg` и приложение Android - те же самые; отличается только хост, а при переключении редакций сохраняется ключ узла, поэтому привязанные телефоны не нужно привязывать заново.

## Использование

1. Выберите папку с вашими медиа-файлами (да, ту самую).
2. Перемещайтесь по файлам с помощью клавиатуры, мыши или экранных кнопок - как удобнее рукам.
3. Используйте панель и недавние файлы для быстрого доступа.
4. Перемещайте, копируйте или удаляйте файлы по необходимости. Нажали цифру - хаоса стало меньше.
5. Наслаждайтесь быстрой и эффективной сортировкой медиа и, может, наконец верните себе место на диске.

## Две программы, одно приложение

В пакете едут **две программы просмотра рядом, в одной папке**, и установщик ставит
обе. Выбирать не нужно: ярлык и файловые ассоциации автоматически указывают на ту,
которая на вашей машине действительно запустится.

- **`FastMediaSorter_LITE.exe`** - основная программа, теперь 64-битная, на .NET 10.
  Она заменяет прежнюю на месте и сохраняет все ваши настройки. **Устанавливать
  ничего не нужно** - рантайм .NET лежит внутри самой программы, так что прежней
  строчки «нужен .NET Framework 4.8» для неё больше нет. Требуется Windows 10
  версии 1607 или новее, Windows 11 либо Windows Server 2016+.
- **`FastMediaSorter_x86.exe`** - сортировщик в виде небольшой 32-битной
  программы (~3 МБ) для Windows 7/8.1 и 32-битных Windows, где современный рантайм
  просто не заработает. Ей нужен .NET Framework 4.8 - на тех версиях Windows он либо
  уже есть, либо штатно доустанавливается. Сортировка, просмотр, OCR и перевод в ней
  никуда не делись; чего в ней нет - так это раздачи папок на Android (см. таблицу
  ниже) и того, что стало возможно благодаря современному рантайму: масштаба на серых
  клавишах, панели управления видео, выбора дорожек и субтитров, «Открыть URL..»,
  меню на картинке и видео и ореола перспективы.

Это **одно приложение**, а не два конкурента: одни настройки, одно окно. Запуск одной
программы при открытой второй просто вынесет уже открытое окно вперёд вместе с вашим
файлом - никакого второго окна и спора о том, чьи настройки сохранятся. Смежные
библиотеки (кодеки, модели OCR и перевода) у них тоже общие - каждая сама берёт те,
что подходят её разрядности.

### Что добавляет 64-битная программа

- **Анимированный WEBP теперь открывается везде.** Программа декодирует WEBP сама, а
  не полагается на кодек Windows «WebP Image Extensions», которого нет в серверных
  редакциях Windows - там анимированный WEBP раньше просто не открывался.
- **Открываются HEIC, HEIF и AVIF** - форматы, в которых iPhone сохраняет фото по
  умолчанию, а веб всё чаще отдаёт картинки. Программа декодирует их сама: не нужны
  ни расширения из Store, ни платный кодек «Расширения для видео HEVC»; повёрнутые
  телефонные снимки открываются правильной стороной вверх.
- **Видео всегда играет через встроенный движок VLC.** Отправленный на покой
  компонент Internet Explorer больше не используется, поэтому воспроизведение
  одинаково работает и там, где IE уже нет. (32-битная программа сохраняет
  классический путь.)
- **Панель управления видео**: пауза, перемотка, время, звук и громкость - вдоль
  нижнего края картинки. Появляется при наведении мыши и через пару секунд уходит, а
  на паузе остаётся на месте. (У 32-битной программы видео идёт через компонент IE,
  который рисует свои собственные кнопки.)
- **Масштаб на серых клавишах**: серые `+`/`-` приближают от курсора мыши, серая `/`
  вписывает в окно, серая `*` даёт натуральный размер. Картинку можно таскать мышью.
  Колесо по-прежнему листает файлы, пока вы не переключите его на масштаб в настройках.
- **Выбор звуковой дорожки и субтитров**: `A` переключает звук, `V` - субтитры, а
  кнопка «Дорожки» появляется только тогда, когда в файле есть из чего выбрать. Выбор
  запоминается по языку, так что следующая серия откроется так же.
- **«Открыть URL..»** - играть видео прямо с `smb://`, `sftp://`, `ftp://`,
  `http(s)://`, `nfs://` или `rtsp://`, не скачивая файл заранее.
- **Меню прямо на медиа**: средняя кнопка на картинке - всё, что с ней можно сделать;
  правая на видео - всё, что можно сделать с ним. Клик по видео ставит на паузу.
- **Ореол вместо полос** - «динамическая перспектива», подпункт фона-перспективы:
  полосы растворяются в фоне по мере удаления от фотографии. Её собственный подпункт
  выращивает этот ореол от края фото на каждом новом снимке - с одной из трёх
  скоростей (медленная, средняя по умолчанию или быстрая).

## Требования

Коротко: установщик разбирается с этим за вас (см. выше). Подробно:

| | `FastMediaSorter_LITE.exe` (основная, 64 бита) | `FastMediaSorter_x86.exe` (32 бита) |
|---|---|---|
| **Windows** | 10 версии 1607+, 11, Server 2016+ | 7, 8.1, 10, 11 - включая 32-битные |
| **Рантайм** | не нужен - он внутри программы | .NET Framework 4.8 |
| **Сортировка, просмотр, слайдшоу** | да | да |
| **OCR и перевод поверх картинки** | да | да |
| **Панель получателей** | да | да |
| **Видео** | LibVLC, с панелью управления | компонент IE (H.264) + LibVLC для остального |
| **HEIC / HEIF / AVIF** | да | нет - на Windows 7/8.1 нет кодеков для них |
| **Клавиши масштаба, выбор дорожек, «Открыть URL..», меню на медиа, ореол перспективы** | да | нет |
| **Раздача папок на Android** | да | нет - Share Manager сам является 64-битной программой и не запустится на тех версиях Windows, ради которых эта сборка и существует |

## Установка

### winget

```powershell
winget install --id SerZhyAle.FastMediaSorter
```

Пакет winget использует Inno Setup installer в тихом per-user режиме, поэтому
во время установки не показывает диалоги - просто молча делает своё дело.

### Релиз с GitHub

Скачайте свежие файлы со
[страницы релизов](https://github.com/SerZhyAle/FastMediaSorter_Lite/releases):

- `FastMediaSorter-<version>-windows-x64-setup.exe` для самой простой установки
- `FastMediaSorter-<version>-windows-x64.zip` как portable offline-пакет

Оба файла содержат **обе программы** - имена файлов при этом не изменились.

В обычном интерактивном setup можно сразу зарегистрировать программу
для распространённых форматов изображений. На Windows 10/11 система может ещё
раз попросить подтвердить выбор в разделе приложений по умолчанию.

Оба GitHub-релиза offline-ready: внутри уже есть VLC runtime и OCR языковые
пакеты, поэтому для воспроизведения медиа и OCR не нужен первый запуск с
дозагрузкой из сети.

### Что входит в пакет (и почему он большой)

Основная программа - это один exe на ~110 МБ, потому что несёт внутри собственный
рантайм .NET. Именно из-за этого веса и не нужно ничего устанавливать: рантайм едет
вместе с программой, а не требуется от вашей машины. (32-битная программа рядом
весит ~3 МБ.) Почти весь остальной объём - это опциональная **оффлайн-начинка**,
включённая в пакет, чтобы приложение работало без дозагрузки при первом запуске:

- **Видео-кодеки (VLC)** (~100 МБ) - оффлайн-воспроизведение AVI, MKV, VP9 и других
  форматов, которые встроенный проигрыватель Windows раскодировать не умеет.
- **Модели OCR и перевода** (~45 МБ) - распознавание текста на изображении без
  обращения к сети.
- **Компаньон Android Folder Share** (~120 МБ) - self-contained приложение на .NET,
  которое несёт собственный рантайм (Windows не поставляет нужный ему современный
  .NET), для раздачи папок на телефон. Он и сам является 64-битным приложением на
  .NET 10 - именно поэтому раздача папок доступна только в 64-битной программе, а на
  Windows 7/8.1 установщик его пропускает.

В пакет вложены 64-битные библиотеки - для основной программы. 32-битная программа
докачивает нужные ей 32-битные кодеки и модели OCR при первом использовании.

Интерактивный установщик показывает всё это **выбираемыми компонентами** с их
размером: снимите ненужное - и эти части либо скачаются позже по мере надобности,
либо фича просто не ставится. Установка «только просмотрщик» («Компактная») - лишь
доля полного пакета. (Тихая установка / winget всегда берут полный набор.)

Примечание: машинный перевод всё ещё зависит от выбранного провайдера - программа
щедрая, но переводить силой мысли не умеет. Для Ollama нужна отдельная локальная
установка модели, а облачным сервисам нужен доступ в сеть.
