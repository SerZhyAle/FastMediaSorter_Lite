# FastMediaSorter LITE

FastMediaSorter LITE - это приложение Windows Forms для быстрой сортировки, просмотра и управления файлами изображений и видео. Поддерживает широкий спектр медиа-форматов и предоставляет следующие возможности:

- Быстрая навигация по большим папкам с изображениями и видео
- Режимы слайд-шоу и случайного просмотра файлов
- Отслеживание недавних файлов и папок
- Операции с файлами: перемещение, копирование, переименование и удаление
- Панель изображений для быстрой визуальной навигации
- Настраиваемые горячие клавиши для эффективной работы
- Многоязычная поддержка (английский/русский)

## Использование

1. Выберите папку с вашими медиа-файлами.
2. Перемещайтесь по файлам с помощью клавиатуры, мыши или экранных кнопок.
3. Используйте панель и недавние файлы для быстрого доступа.
4. Перемещайте, копируйте или удаляйте файлы по необходимости.
5. Наслаждайтесь быстрой и эффективной сортировкой медиа!
