USER-PLAYLIST conformance vectors - vendored artifacts, not a vendored contract
===============================================================================

What this folder is
-------------------
The three Extended M3U8 vectors of the USER-PLAYLIST contract, copied here so that
UserPlaylistConformanceTests can run for anyone who clones this repository (a test that depends on
a drive letter cannot run for anybody else). The JSON vector (valid-playlist.sza-playlist.json) is
not here: this product does not read the JSON carrier (USER-PLAYLIST section 6 A).

What this folder is NOT
-----------------------
A copy of a contract. The document stays in the shared catalog and is CITED, never duplicated (see
docs/contracts/USER-PLAYLIST.md, and the first line of CLAUDE.md for where the catalog lives).
