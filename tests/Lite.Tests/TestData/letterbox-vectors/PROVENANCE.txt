LETTERBOX-BARS / LETTERBOX-HALO rung 1 vectors - vendored artifact, not a vendored contract
===========================================================================================

What this folder is
-------------------
The committed rung 1 vectors of the two LETTERBOX contracts (section 5 of the contract: "every constant
of sections 2-3 lives once in the implementation ... and the implementation's pure functions reproduce
every value in the vectors"), copied here so that LetterboxFillConformanceTests can run for anyone who
clones this repository. A test that depends on a drive letter cannot run for anybody else.

What this folder is NOT
-----------------------
A copy of a contract. LETTERBOX-BARS and LETTERBOX-HALO stay in the shared catalog and are CITED, never
duplicated (see docs/contracts/LETTERBOX-FILL.md, and the first line of CLAUDE.md for where the catalog
lives). Copying an artifact so a test can run is a different act from copying a document so a repository
can disagree with it. This product OWNS both contracts: a change to any number these vectors pin is an
amendment in the catalog first - a version bump, a log row, the vectors regenerated by the reference
script - and only then this file.

------
