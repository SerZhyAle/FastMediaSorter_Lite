STREAM-BANK rule 14 facet tables and golden vectors - vendored artifact, not a vendored contract
==============================================================================================

What this folder is
-------------------
The six files the shared catalog publishes for item P of STREAM-BANK (the closed `language` and `country` value
sets of item O, and the vectors that hold an implementation to them), copied here so that StreamFacetFoldTests can
run for anyone who clones this repository, and so that src/Streams/StreamFacetTables.vb (generated from these six
files by tools/Export-StreamFacetTables.ps1) can be checked against its source. A test that depends on a drive
letter cannot run for anybody else.

What this folder is NOT
-----------------------
A copy of a contract. STREAM-BANK stays in the shared catalog and is CITED, never duplicated (see
docs/contracts/STREAM-BANK.md, and the first line of CLAUDE.md for where the catalog lives). The tables and
vectors are generated by the owner's normalizer (FastMediaSorter Android, scripts/streams/export-facet-tables.ps1)
and are never edited by hand, here or in the catalog: a change to any row is the owner re-exporting them, and only
then are these files re-taken, together with src/Streams/StreamFacetTables.vb (run the export script, then update
the digests below).

------

redefining what "conformant" means. Re-taking the artifacts is a deliberate act and updates this file with it. The
bytes are the catalog's own (LF, UTF-8 without a byte-order mark), which is why .gitattributes marks this folder -text.
