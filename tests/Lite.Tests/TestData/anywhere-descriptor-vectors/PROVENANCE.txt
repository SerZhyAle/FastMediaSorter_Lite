ANYWHERE-ACCESS rung 1 vectors - vendored artifact, not a vendored contract
============================================================================

What this folder is
-------------------
The committed rung 1 vectors of the ANYWHERE-ACCESS contract, section 4 (the FMSSFTP1/FMSSFTP2 pairing
code and the .fmscfg rendezvousTunnel path), copied here so that FmsSftpCodeTests can run for anyone who
clones this repository. A test that depends on a drive letter cannot run for anybody else.

What this folder is NOT
-----------------------
A copy of a contract. ANYWHERE-ACCESS stays in the shared catalog and is CITED, never duplicated (see
docs/contracts/README.md and CLAUDE.md's first line for where the catalog lives). Copying an artifact so a
test can run is a different act from copying a document so a repository can disagree with it.
