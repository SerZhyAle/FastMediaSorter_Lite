HOW TO · OCR & TRANSLATION

Read the text on a picture and see it in your languageПрочитать текст на картинке и увидеть его на своём языке

A scanned page, a screenshot, a photo of a sign: the viewer recognizes the text and draws the translation over each block, in place. With the default translator, the image never leaves your PC.Скан страницы, скриншот, фотография вывески: просмотрщик распознаёт текст и рисует перевод поверх каждого блока, прямо на месте. С переводчиком по умолчанию изображение не покидает ваш компьютер.

Turn recognition onВключите распознавание

Press F2 for Settings and open the OCR section. Tick Enable OCR; Start automatically next to it recognizes every image as you open it, which is worth switching on only when you are working through a whole folder of foreign text. Until OCR is enabled, T keeps its older meaning and simply rotates the picture.Нажмите F2 - Настройки - и откройте раздел OCR. Поставьте галочку Включить OCR; соседняя Запускать автоматически распознаёт каждое открытое изображение, и включать её стоит, только когда вы разбираете целую папку с иностранным текстом. Пока OCR не включён, T сохраняет прежний смысл и просто поворачивает картинку. The 32-bit build for Windows 7 and 8.1 recognizes and translates too, but keeps all of these settings on a single OCR and translation tab.32-битная сборка для Windows 7 и 8.1 тоже распознаёт и переводит, но держит все эти настройки на одной вкладке OCR и перевод.

Tell it what it is readingСкажите, что именно он читает

Under Text recognition on the same page, set the Source text language - or leave auto-detect - and press Language data to fetch a pack that is not bundled. Two more settings matter when a page resists:В группе Распознавание текста на той же странице укажите Язык исходного текста (или оставьте автоопределение) и нажмите Языковые данные, чтобы дозагрузить пакет, которого нет в комплекте. Ещё две настройки пригодятся, когда страница сопротивляется:

  • Recognition quality - fast is the default; best is slower and more accurate.Качество распознавания - по умолчанию быстрое; лучшее работает медленнее и точнее.
  • OCR mode - auto suits most pictures; single block, sparse text, single line and vertical text are there for layouts auto reads badly.Режим OCR - авто подходит большинству картинок; один блок, разреженный текст, одна строка и вертикальный текст существуют для вёрстки, которую авто читает плохо.

Choose who translatesВыберите, кто переводит

The neighbouring Translation section holds the translator. The default is Ollama - a language model running on your own machine - and the buttons there do the whole setup: Install Ollama, Start Ollama, then pick a translation model and press Pull. LibreTranslate is the alternative if you already have a server: put its address in Service address. An API key, where one is needed, is stored encrypted by Windows. Finally set the Translation language - the language you want to read.Соседний раздел Перевод отвечает за переводчик. По умолчанию это Ollama - языковая модель, работающая на вашей же машине; кнопки там делают всю настройку: Установить Ollama, Запустить Ollama, затем выберите модель перевода и нажмите Загрузить. LibreTranslate - альтернатива, если сервер у вас уже есть: его адрес указывается в поле Адрес сервиса. Ключ API, где он нужен, хранится зашифрованным средствами Windows. Наконец, задайте Язык перевода - тот, на котором вы хотите читать.

Press T on the imageНажмите T на изображении

One press recognizes the picture and shows the translation over it; the next press hides the overlay again. Shift+T switches on auto mode, where every image you open is processed without asking. The Translate toolbar button does the same as T, and a right-click on it opens these settings directly.Одно нажатие распознаёт картинку и показывает перевод поверх неё; следующее нажатие снова прячет наложение. Shift+T включает авто-режим, в котором обрабатывается каждое открытое изображение, без вопросов. Кнопка Перевод на панели делает то же, что T, а правый щелчок по ней открывает эти настройки напрямую.

Make the overlay comfortableНастройте наложение под себя

The Translation panel group at the bottom of the same section sets Panel opacity - from a barely visible hint of the translation to a plate that fully covers the original - and Cache results on disk, so the same picture is not recognized twice; a size limit and the space in use are shown right there. Show the translation panel hides or restores an overlay that is already there.Группа Панель перевода внизу того же раздела задаёт Непрозрачность панели (от еле заметного намёка на перевод до плашки, полностью закрывающей оригинал) и Кэшировать результаты на диске, чтобы одна и та же картинка не распознавалась дважды; ограничение размера и занятое место показаны рядом. Флажок Показывать панель перевода прячет и возвращает уже готовое наложение.

It stays on your computerВсё остаётся на вашем компьютере

Recognition is always local. With Ollama the translation is local too, so a private document is never uploaded anywhere. Only if you deliberately point the endpoint at an outside service does anything leave the machine.Распознавание всегда локальное. С Ollama перевод тоже локальный, поэтому личный документ никуда не выгружается. Что-то уходит с машины только если вы сами направите endpoint на внешний сервис.

If nothing is recognizedЕсли ничего не распозналось

Set the source language explicitly instead of auto-detect, switch the OCR model to best, and try a page mode that matches the layout. A photo taken at an angle or a very small screenshot is the hard case - straighten it or open a larger copy.Укажите язык исходного текста явно вместо автоопределения, переключите модель OCR на лучшую и попробуйте режим страницы, подходящий вёрстке. Тяжёлый случай - снимок под углом или совсем мелкий скриншот: выровняйте его или откройте копию побольше.
