HOW TO · SETUP

Set it up once: default viewer, language, and what happens to your filesНастройте один раз: просмотрщик по умолчанию, язык и что происходит с файлами

Everything below lives behind F2. The defaults are safe out of the box, so treat this as the list of things worth deciding for yourself rather than a setup you must complete.Всё, что ниже, находится за клавишей F2. По умолчанию всё настроено безопасно, поэтому считайте это списком того, что стоит решить для себя, а не обязательной настройкой.

Find a setting and return to itНайдите настройку и возвращайтесь к ней

Groups open independently. Settings remember the last page, group states and approximate scroll position. Use Search settings or Ctrl+F to search names, explanations and choices; a result opens the original field. Expand all and Collapse all affect this page. Closing the window keeps applied changes. Search is temporary and excludes API keys and personal history. Profile import/export is in General / Advanced settings; window context stays on this PC.Группы раскрываются независимо. Настройки помнят последнюю страницу, состояния групп и примерную позицию прокрутки. Поиск настроек или Ctrl+F ищет названия, пояснения и варианты значений; результат открывает исходное поле. Развернуть все и Свернуть все действуют на эту страницу. Закрытие сохраняет применённые изменения. Поиск временный, ключи API и личная история в него не попадают. Импорт и экспорт профиля находятся в Общие / Дополнительные настройки; контекст окна остаётся на этом компьютере.

Storage owns cache budgets and cleanup. Thumbnail size offers 96, 128, 192 or 256 px. Interface scale multiplies the Windows scale for settings, floating panels and text view. General offers a reset of additional preferences after confirmation and a backup; destinations, language, theme, sound, OCR and personal history are retained.Хранилище содержит лимиты кэшей и их очистку. Размер миниатюр: 96, 128, 192 или 256 px. Масштаб интерфейса умножает масштаб Windows для настроек, плавающих панелей и текстового просмотра. В Общих есть сброс дополнительных настроек с подтверждением и резервной копией; получатели, язык, тема, звук, OCR и личная история сохраняются.

Make it your default viewerСделайте программой по умолчанию

On the Files and system page, Image formats claims the picture types the program can display, and Video formats does the same for the video and audio it can play. Both write to your own user profile - no administrator rights are involved - and Windows may still ask you to confirm the choice in its own default-apps screen the first time you double-click a file.На странице Файлы и система кнопка Форматы изображений закрепляет за программой те типы картинок, которые она умеет показывать, а Форматы видео - видео и звук, которые она умеет проигрывать. Обе пишут в ваш собственный профиль пользователя, права администратора не нужны, - а Windows может дополнительно попросить подтвердить выбор в своих параметрах приложений при первом двойном щелчке по файлу.

Choose the interface languageВыберите язык интерфейса

Thirteen languages ship with the program. On the very first run it follows your Windows display language, and after that your own choice wins: the two-letter button on the toolbar switches it instantly, and the same setting sits in General / Basic settings. Arabic and Urdu lay the window out right-to-left; Hindi, Bengali and Chinese switch to a font that can draw their script.В программе тринадцать языков. При самом первом запуске она следует языку интерфейса Windows, а дальше решает ваш выбор: двухбуквенная кнопка на панели переключает язык мгновенно, та же настройка есть в Общие / Основные настройки. Арабский и урду разворачивают окно справа налево; хинди, бенгальский и китайский переключаются на шрифт, умеющий рисовать их письмо.

Decide what happens to a fileРешите, что происходит с файлом

The File behaviour group is the part worth reading before a big sorting session:Группа Поведение файлов - то, что стоит прочитать перед большим разбором:

  • Name collision - ask, skip, keep both, or replace, when the destination folder already holds a file with that name.Совпадение имён - спрашивать, пропустить, сохранить оба или заменить, когда в папке-получателе уже есть файл с таким именем.
  • After a copy or a move - go to the next file, stay on the current one, or close when nothing is left.После копирования или перемещения - следующий файл, остаться на текущем или закрыть, когда файлов не осталось.
  • Delete to the Recycle Bin and Ask before deleting - always, never, or only when the file will not reach the bin. A network share and a memory stick have no bin at all, and that is exactly when the question is worth asking.Удалять в Корзину и Спрашивать перед удалением - всегда, никогда или только если файл не попадёт в Корзину. У сетевой папки и флешки Корзины нет вовсе, и именно тогда вопрос и нужен.

Narrow down what you seeСузьте то, что показывается

File types limits the list to the formats you actually care about, and Include subfolders decides whether a folder means its own files or everything beneath it. On startup open chooses what a plain launch shows - the start page, the last folder, or the last file. Right under it, Resume the last file goes further than the row above: it reopens the exact file that was on screen - not the position it held in the folder - and lets a video carry on from where it was left. It is off until you switch it on, and a file that has been deleted, renamed or left on a disconnected drive simply leaves the window empty. History sizes for recent files and folders are right there too, with a button that clears them.Пункт Типы файлов ограничивает список теми форматами, которые вам действительно нужны, а Просматривать вложенные папки решает, означает ли папка только свои файлы или всё, что лежит внутри неё. При запуске открывать выбирает, что показывает обычный запуск: стартовую страницу, последнюю папку или последний файл. Прямо под ним пункт Продолжать с последнего файла делает больше, чем строка выше: он открывает именно тот файл, который был на экране, - а не его номер в папке, - и даёт видео продолжиться с той позиции, где его оставили. По умолчанию выключен, а если файл удалён, переименован или лежит на отключённом диске, окно просто остаётся пустым. Размеры истории недавних файлов и папок - там же, вместе с кнопкой их очистки.

Carry the setup to another PCПеренесите настройки на другой компьютер

Export additional settings writes the additional preferences to a file and Import additional settings reads them back. Recipients, language, theme, sound and OCR are excluded. Include personal data decides whether your folder history and viewing positions travel with it; API keys and passwords never do, with or without that tick.Экспорт дополнительных настроек сохраняет дополнительные параметры в файл, Импорт дополнительных настроек читает их обратно. Получатели, язык, тема, звук и OCR не включаются. Флажок Включить личные данные решает, поедут ли с ним история папок и позиции просмотра; ключи API и пароли не попадают туда никогда, с флажком или без.

Comfort of viewingКомфорт просмотра

The General / Appearance group carries interface scale and Reduce animation; Images / Basic settings chooses the starting scale for each image. If the window feels too small or the effects too lively on your monitor, that is where to look first.В группе Общие / Оформление находятся масштаб интерфейса и Уменьшать анимацию; Изображения / Основные настройки задаёт масштаб нового изображения. Если окно кажется мелким, а эффекты - слишком бойкими для вашего монитора, начинать надо оттуда.

If something goes wrongЕсли что-то пошло не так

F2 → About → Send the logs to the author packs the logs and a report of your version, Windows and settings into an archive, shows you what went in, and opens a new mail with it attached. Nothing is sent until you press Send yourself.F2 → О программе → Отправить логи автору соберёт журналы и отчёт о версии, Windows и настройках в архив, покажет, что туда попало, и откроет письмо с вложением. Ничего не уходит, пока вы сами не нажмёте «Отправить».
