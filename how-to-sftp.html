HOW TO · SFTP SERVICE

Open selected PC folders in the Android appКак открыть выбранные папки ПК в приложении для Android

The built-in service creates an encrypted SFTP connection directly between your Android phone and your PC. It has no cloud account: you choose exactly which folders are shared.Встроенный сервис создаёт зашифрованное SFTP-соединение напрямую между Android-телефоном и ПК. Облачная учётная запись не нужна: вы сами выбираете, какие папки публиковать.

Requirement:Требование: SFTP sharing is available only in the 64-bit Fast Media Sorter on Windows 10 version 1607 or newer. The x86/.NET 48 fallback does not include Share Manager.SFTP-раздача доступна только в 64-битном Fast Media Sorter на Windows 10 версии 1607 или новее. В резервной x86/.NET 48 версии Share Manager отсутствует.

Open Share ManagerОткройте Share Manager

In the viewer, right-click the current folder field and choose Share this folder with phone... You can also open F2 → Android / SFTP → Manage SFTP. Both routes open the same Share Manager application.В просмотрщике щёлкните правой кнопкой по полю текущей папки и выберите Поделиться этой папкой с телефоном... Либо откройте F2 → Android / SFTP → Управление SFTP. Оба пути открывают одно приложение Share Manager.

Enable server features onceОдин раз включите функции сервера

On the first run, choose Enable server features. This requires administrator approval once so the application can create the Windows Firewall rule needed for SFTP. The viewer itself remains a normal local application.При первом запуске выберите Включить функции сервера. Один раз потребуется подтверждение администратора: приложение создаст правило брандмауэра Windows, необходимое для SFTP. Сам просмотрщик остаётся обычным локальным приложением.

Choose the folders and access policyВыберите папки и правила доступа

The folder that you opened can be added immediately. Use Add folder for more folders and tick only those that should be visible on the phone. In Options, configure read-only access, a PIN, allowed media types, and a destination for copies when appropriate.Открытая папка может быть добавлена сразу. Для других папок используйте Добавить папку и отметьте только те, которые должны быть видны на телефоне. В Настроить при необходимости задайте доступ только для чтения, PIN, разрешённые типы медиа и папку для копий.

Start sharing and pair the phoneЗапустите раздачу и подключите телефон

Start sharing, then use the Android access panel in Share Manager. On the phone open FastMediaSorter → Add resource → SFTP/FTP → Import from companion, then scan the QR code or open the exported .fmscfg file.Запустите раздачу и откройте панель Доступ с Android в Share Manager. На телефоне перейдите в FastMediaSorter → Добавить ресурс → SFTP/FTP → Импорт из компаньона, затем отсканируйте QR-код или откройте экспортированный файл .fmscfg.

Use the local network firstСначала используйте домашнюю сеть

When phone and PC use the same Wi-Fi, the local address is the simplest and safest route. The phone can rediscover the PC by its saved host-key fingerprint after a local IP address changes.Когда телефон и ПК подключены к одной Wi-Fi, локальный адрес — самый простой и безопасный вариант. После изменения локального IP-адреса телефон может снова найти ПК по сохранённому отпечатку ключа сервера.

Use internet access only when neededИспользуйте доступ из интернета только при необходимости

Share Manager can try UPnP and test whether the service is reachable from outside. If it reports CGNAT, ordinary port forwarding will not work; prefer local Wi-Fi, IPv6 where available, or a trusted VPN. For router-specific instructions, use the detailed publication guide below.Share Manager может попробовать UPnP и проверить доступность сервиса извне. Если он сообщает о CGNAT, обычный проброс порта не поможет; используйте локальную Wi-Fi, IPv6 при наличии или доверенный VPN. Для подробной настройки роутера откройте инструкцию ниже.

Keep pairing data privateХраните данные подключения приватно

A QR code or configuration file can contain the generated password. Do not publish it. Stop sharing from Share Manager or its tray icon when you no longer need access.QR-код или файл конфигурации может содержать сгенерированный пароль. Не публикуйте его. Остановите раздачу из Share Manager или его значка в трее, когда доступ больше не нужен.

If the phone cannot connectЕсли телефон не подключается
  • Check that both devices are on the same Wi-Fi.Убедитесь, что оба устройства подключены к одной Wi-Fi.
  • Make sure server features were enabled and sharing is running.Проверьте, что функции сервера включены и раздача запущена.
  • Reopen Share Manager to check the displayed address and status.Откройте Share Manager снова и проверьте показанный адрес и статус.
Need it available around the clock?Нужен доступ круглосуточно?

The sharing above works while you are signed in and Share Manager is running. If the machine's job is to stay available - a dedicated server, a VPS, an always-on home server - a separate Server edition hosts the same sharing as a Windows service that starts at boot and serves with nobody logged on. SFTP, the QR pairing and the Android app are identical, and switching preserves the host key so paired phones need no re-pairing.Раздача выше работает, пока вы вошли в систему и Share Manager запущен. Если задача машины - быть доступной постоянно (выделенный сервер, VPS, домашний сервер), отдельная серверная редакция поднимает ту же раздачу как службу Windows: она стартует с загрузкой и работает без входа в систему. SFTP, привязка по QR и приложение Android те же самые, а при переключении сохраняется ключ узла - привязанные телефоны не нужно привязывать заново.

FileDO disk sharingШаринг дисков FileDO

FileDO disks: with the optional FileDO disk component installed, start Share Manager, then register a file-backed disk from FileDO's Disk Manager using Share with Fast Media Sorter & Sharing.. (Ctrl+Shift+S). Choose a root name and read-only or read/write access; sealed disks are read-only. FileDO confirms a clean transfer of an already mounted disk and explicitly asks before disabling its local automatic mounting. Registration, opening, and FMS autostart are separate choices. Share Manager now offers .fdd disks.. → Connect .fdd..: select a container, name and access, then choose sharing without a letter or a free local Windows letter. The letter applies to the current session only. The disk list shows state, holder and open files; use Open, Close, Force close, Remove and the separate Autostart action. FileDO registrations also appear here. Mounted drive.. shares an existing drive using ordinary folder settings. Save and close a FileDO-held container before connecting it here. Container mounting requires a compatible FileDO component and an administrator-capable worker; the ordinary LocalService host cannot mount it. Do not add the worker's temporary mount path as an ordinary folder. Closing retains registration; stopping sharing also deletes the disk's saved autostart key. Pair clients with the existing QR or .fmscfg flow: they see the open disk as an SFTP folder, not a Windows SMB share. Encrypted disks are unlocked on the PC; autostart stores their credential in the host's protected store only after explicit consent. Session mode requires sign-in; the service host works without sign-in. If a transfer fails, refresh FileDO's state before retrying or restoring local mounting. Partition disks and the unverified FileDO Store control path are unavailable in this workflow. Detailed FileDO disk guide · FileDO disk guide.Диски FileDO: установите дополнительный компонент дисков FileDO и запустите Share Manager, затем зарегистрируйте файловый диск в Диспетчере дисков FileDO через «Поделиться через Fast Media Sorter & Sharing..» (Ctrl+Shift+S). Выберите имя папки и доступ только на чтение или чтение и запись; sealed-диски всегда доступны только на чтение. FileDO подтверждает безопасную передачу подключённого диска и явно спрашивает перед выключением локального автоподключения. Регистрация, открытие и автозапуск FMS выбираются отдельно. В Share Manager доступны Диски .fdd.. → Подключить .fdd..: выберите контейнер, имя, доступ и режим без буквы либо свободную локальную букву Windows. Буква действует только в текущем сеансе. Список показывает состояние, владельца и открытые файлы; доступны открытие, закрытие, отдельное принудительное закрытие, удаление из раздачи и отдельный автозапуск. Регистрации FileDO тоже видны здесь. Смонтированный диск.. публикует существующий диск через обычную настройку папки. Контейнер, открытый в FileDO, сначала сохраните и закройте там. Монтирование требует совместимого компонента FileDO и worker с правами администратора; обычная служба LocalService его не поддерживает. Не добавляйте временный путь worker как обычную папку. Закрытие сохраняет регистрацию; прекращение шаринга также удаляет ключ автозапуска диска. Сопрягайте устройства штатным QR или .fmscfg: открытый диск виден как папка SFTP, SMB-шара Windows не создаётся. Зашифрованный диск открывается на ПК; автозапуск сохраняет пароль в защищённом хранилище только после явного согласия. Сеансовый режим требует входа; служба доступна без входа. После ошибки передачи обновите состояние в FileDO перед повтором или восстановлением локального подключения. Диски в разделах и непроверенное управление из FileDO Store в этом сценарии недоступны.
